# Mesh Tools (moved) {#mesh-tools-moved}

The **Mesh Tools** sub-panel no longer exists. Its contents were split into two sub-panels of [Optimization](./Optimization.md), so that mesh work is no longer spread across two places:

| Old location | New location |
| --- | --- |
| Mesh Tools → Separate By | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Normals | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Apply Transformations | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → shape key tools | [Optimization → Shape Keys](./Optimization.md#shape-keys) |

Join Meshes and Remove Doubles also moved into **Mesh Cleanup**, they were previously under *Material Operations* (now [Materials](./Optimization.md#materials)).

The digitigrade-leg and twist-bone *generation* tools have their own [Bone Tools](./Bone-Tools.md) panel.
