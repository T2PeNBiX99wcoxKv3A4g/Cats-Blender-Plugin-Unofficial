# 翻译

**翻译**（Translation）面板把日语（及其他语言）名称翻译为英文，让你的模型在英文工具链、Unity 和 VRChat 中顺利工作。在 `5.2.3.0` 中它有了专门的独立面板，以及**可插拔的多服务后端**。

## 它如何工作

翻译始终分两个阶段进行：

1. **优先使用内置词典。** Cats 随附的词典会应用到每个名称。它是离线的、即时的，并且永远不会被限流。
2. **在线服务填补空缺。** 词典无法解析的任何内容都会发送到你选择的在线服务。结果会被缓存，因此重复的名称永远不会再次访问网络。

这意味着内置词典*始终*会被使用，服务下拉框只决定**由哪个在线服务处理剩余部分**。

自 `5.2.4.0` 起，MMD 模型多了一个中间步骤：**模型作者存储在 PMX 文件中的英文名称**（MMD Tools 显示为 *Name(Eng)*）。见下文的[作者名称](#author-names-mmd)。

## 选择服务

**翻译服务**下拉框提供：

| 服务 | 需要 | 说明 |
|---|---|---|
| **仅内置词典** | 无 | 离线。完全不进行网络请求；未翻译的文本保持原样。 |
| **Google 翻译** *（默认）* | 无 | 免费端点，无需密钥。可能被限流/暂时封锁。与旧的默认行为一致。 |
| **DeepL** | API 密钥 | 免费或 Pro DeepL 密钥。质量高，原生批量翻译。 |
| **LibreTranslate** | URL（+ 可选密钥） | 公共服务器或你自己的自托管实例。 |
| **MyMemory** | 无（邮箱可选） | 免费；添加邮箱可提高每日配额。 |

当你选择需要凭据的服务时，面板中会出现相关字段：
- **DeepL** → DeepL API 密钥
- **LibreTranslate** → LibreTranslate URL 和可选的 API 密钥
- **MyMemory** → 可选的邮箱

> 🔒 你的服务选择和凭据存储在 Cats 的**全局设置**中（见[设置](Settings#settings-file-location)），而不是 `.blend` 文件内，因此 API 密钥永远不会随你的模型一起传播。在 `5.3.1.0` 之前，API 密钥、LibreTranslate URL 和 MyMemory 邮箱也会保存到每个 `.blend` 中；用 `5.3.1.0` 或更新版本打开此类文件会移除它们（保存文件以使其生效）。如果你分享过用旧版本创建的文件，请考虑更换你的 API 密钥。

> 💡 如果在线服务不可用（没有密钥、离线或被限流），翻译会**优雅降级**到内置词典能做到的程度，而不是直接失败。

> 在线服务仅在 Blender 的 **编辑 > 偏好设置 > 系统 > 网络 > 允许在线访问** 打开时运行。关闭它时，Cats 只使用内置词典，并显示一条警告说明在线访问已禁用。**仅内置词典** 在两种情况下都能工作。

## 翻译按钮

- **全部翻译** 一键翻译下面的所有内容
- **形态键**
- **对象**
- **骨骼**
- **材质**

## 作者名称（MMD）

PMX 文件为每根骨骼、每个形态键和每个材质携带一个可选的英文名称，由模型作者写入。从 `5.2.4.0` 起 Cats 可以使用它们，这通常比任何词典或在线服务更好，因为作者知道那个形态键*具体做什么*。

- **作者名称（形态键）** 决定形态键如何使用它们：
  - **填补空缺** *（默认）* 先使用词典；作者的英文名称只用于词典无法完整翻译的形态键，并且是在询问在线服务之前。
  - **优先作者名称** 只要有作者名称就优先使用。其他一切照常经过词典和在线服务。
  - **关闭** 忽略它们，只用词典和在线服务翻译，与 `5.2.4.0` 之前相同。
- **作者名称（材质）** *（默认开启）* 使用作者的英文材质名，而不是翻译日语名称。为空、不是纯英文或被多个材质共用的名称会被跳过，并照常翻译。

**骨骼和对象从不使用作者名称。** 修复 MMD 模型依赖词典中的骨骼名称来识别绑定，因此骨骼翻译保持不变。

形态键的设置会同步到**修复 MMD 模型**的 ⚙ 模型设置中，并且修复 MMD 模型会在删除 MMD 根对象之前记录这些名称，因此之后仍然可用。翻译报告会告诉你有多少名称来自作者，[导出翻译 CSV](Settings#export-translation-csv)也会新增一个*来源*列，说明每个名称来自哪里。

> 🧪 **新增功能，测试较少。** 它在开发时针对的模型上可以工作，但还需要更多带英文名称的 MMD 模型来测试。如果某个形态键或材质得出的名称出乎你的意料，请把设置切换到**关闭**，并请报告该模型。

## 选项

- **形态键跳过词典** *（仅在线时）* 旧有行为：形态键忽略内置词典，完全用选定的在线服务翻译。只有在你依赖 Cats 0.9.0 及更早版本中精确的形态键名称时才需要。
- **跳过锁定的形态键** 锁定的形态键保持不翻译（用于保护有意命名的形态键）。

## 最佳实践

**应该：**
- ✅ 在导入 / 修复 MMD 模型之后尽早翻译
- ✅ 在设置口型同步或眼动追踪**之前**翻译
- ✅ 让缓存发挥作用，处理重复运行

**不应该：**
- ❌ 在设置好口型同步/眼动追踪*之后*再次翻译（可能破坏引用）
- ❌ 反复翻译同一个模型（可能导致词语重复）

### 何时翻译

**在以下操作之前：** 口型同步、眼动追踪、自定义形态键、与其他模型合并。
**在以下操作之后：** 导入模型、运行修复 MMD 模型。

## 重置缓存

在线翻译缓存可以从[设置](Settings)面板清除（**重置 Google 词典**）。如果某个糟糕的翻译被缓存，或者你切换了服务并希望获得全新结果，这很方便。
