# UV 工具

**UV 工具**（UV Tools）是 `5.2.3.0` 中新增的面板，提供 UV 编辑的辅助工具。它包含两个工具：**将 UV 边对齐到目标**和**查找最短缝合线路径**。

## 在哪里找到它

- 完整面板位于 **UV / 图像编辑器** 的侧栏（N 面板）中，在 **CATS** 选项卡下。打开 UV 编辑器即可看到它。
- **查找最短缝合线路径**也镜像在 **3D 视图** 的 CATS 选项卡中（位于 "UV Tools" 下），因为你实际是在那里选择顶点。

*对齐 UV 边* 仅存在于 UV 编辑器中，它需要 UV 编辑器的 2D 光标和选择。

---

## 将 UV 边对齐到目标

重塑每个选中网格上选中一条 UV 点线，使其沿着**活动**网格上选中 UV 点的线。这非常适合 **kitbashing** —— 把一个模型的 UV 布局匹配到另一个，使它们的贴图对齐。

**2D 光标**标记每条线的哪一端是「起点」，因此在沿目标插值点之前，所有线都会以相同的方向遍历。

### 如何使用

1. 在 UV 编辑器中，把 **UV 同步选择** 设为**关闭**。
2. 选中所有涉及的网格 —— **活动**的那个是*目标*。
3. 进入**编辑模式**，在每个网格上选择一条匹配的 **UV 边线**。
4. 把**2D 光标**放在线的起点端附近。
5. 按下 **将 UV 边对齐到目标**。

> 每个选中的网格都需要恰好一条干净的选中 UV 点线。如果选择存在分支或不是单条线，Cats 会警告你。

---

## 查找最短缝合线路径

选择连接两个选中顶点的最短一段**缝合线**边。方便快速选中一条缝合环进行处理。

它只沿着标记为缝合线的边遍历（广度优先搜索），因此结果始终是你两点之间边数最少的路径。

### 如何使用

1. 在你的网格上进入**编辑模式**。
2. 选择**恰好两个顶点**，每个都位于缝合线上。
3. 按下 **查找最短缝合线路径**（在 UV 编辑器和 3D 视图的 CATS 选项卡中都可用）。

路径上的边会被选中，模式切换为边选择。如果两个顶点没有通过缝合线连通，Cats 会告诉你未找到路径。
