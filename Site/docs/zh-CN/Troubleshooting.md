# 疑难解答

Cats Blender Plugin 的常见问题与解决方案。

## 快速疑难解答

> 💡 **第一步：** 在深入具体问题之前：
> 1. 确认你使用的是 **Blender 4.2 LTS 或更新版本**
> 2. 确认你拥有 **最新版本的 Cats**
> 3. 安装/更新 Cats 后**重启 Blender**
> 4. 检查 Cats 在扩展偏好设置中已**启用**

---

## 安装问题

### 安装后扩展不出现

**症状：**
- 安装了 Cats 但找不到它
- 侧栏中没有 Cats 选项卡
- 列表中不显示该扩展

**解决方案：**

1. **检查是否已启用：**
   - 编辑 > 偏好设置 > 扩展
   - 搜索 "Cats"
   - 确保复选框已勾选

2. **重启 Blender：**
   - 完全关闭 Blender
   - 重新打开 Blender
   - 再次检查

3. **确认安装：**
   - 确保你安装的是 ZIP 文件（不要解压）
   - 确认你使用了「从磁盘安装」
   - 检查你下载的是适用于 Blender 5.2 / 5.3 的 Cats 版本

4. **检查 Blender 版本：**
   - 帮助 > 关于 Blender
   - 必须是 4.2 LTS 或更新版本
   - 为你的 Blender 下载正确的 Cats 版本

5: **按 N 确保侧栏已打开**

### 安装时出现错误

**可能原因：**
- Cats 版本与你的 Blender 不匹配
- 下载损坏
- 权限问题
- 扩展冲突

**解决方案：**

1. **确认版本匹配：**
   - Blender 4.2 LTS 至 5.4 都运行当前的 Cats 发行版；Blender 4.1 及更旧版本无法加载该扩展
   - 让你的 Cats 版本与你的 Blender 版本匹配（见[版本支持](Version-Support)）

2. **重新下载：**
   - 删除不完整的下载
   - 下载全新的副本
   - 确认文件没有损坏

3. **检查权限：**
   - 确保 Blender 可以写入扩展文件夹
   - 以管理员身份运行 Blender（Windows）
   - 检查文件夹权限

4. **移除冲突的扩展：**
   - 旧的 Cats 版本
   - 不兼容的插件（例如 MMD Tools —— cats 自带最新的 MMD Tools，它们会互相冲突）
   - 移除后重启

### 侧栏中看不到 Cats 选项卡

**解决方案：**

1. **按 N：**
   - 在 3D 视口中按 **N** 键
   - 切换侧栏的可见性

2. **寻找 Cats 选项卡：**
   - 检查侧栏中的所有选项卡
   - 应该能看到 "Cats" 选项卡
   - 点击打开

3. **确认扩展已启用：**
   - 编辑 > 偏好设置 > 扩展
   - 找到 Cats
   - 检查启用复选框

## 导入/导出问题

### 模型无法导入

**症状：**
- 导入按钮没有任何反应
- 导入过程中出现错误信息
- Blender 崩溃

**解决方案：**

1. **检查文件格式：**
   - 确认是受支持的格式（.pmx、.pmd、.fbx、.vrm 等）
   - 文件没有损坏
   - 文件大小合理

2. **检查文件路径：**
   - 路径中没有特殊字符
   - 路径不太长
   - 文件没有被其他程序占用

3. **试试 Blender 自带的导入器：**
   - 文件 > 导入
   - 如果那样也失败，文件可能已损坏

4. **在控制台中检查错误：**
   - 窗口 > 切换系统控制台
   - 查找错误信息
   - 报告具体的错误

## 模型显示问题

### 模型显示为黑色或没有贴图

**症状：**
- 模型全是黑的
- 贴图不显示
- 材质看起来不对

**解决方案：**

1. **切换视口着色：**
   - 按 Z 键
   - 选择「材质预览」或「渲染」
   - 「实体」模式可能不显示贴图

2. **检查材质属性：**
   - 选中网格
   - 打开材质属性面板
   - 确认材质存在
   - 检查贴图是否已加载

3. **贴图路径：**
   - 材质可能引用缺失的贴图
   - 如有需要重新链接贴图
   - 使用 Blender 中的「查找缺失文件」

4. **创建图集之后：**
   - 图集材质是普通的原理化 BSDF，卡通/MToon 外观不会被保留
   - 在 Unity 中正确设置材质
   - 见[图集生成器问题](#atlas-generator-issues)

### 模型内外翻转

**症状：**
- 网格看起来里外颠倒
- 显示背面
- 着色看起来不对

**解决方案：**

1. **重新计算法向：**
   - [优化 → 网格清理](Optimization#mesh-cleanup)面板
   - 点击「重新计算法向」

2. **在编辑模式中检查：**
   - 按 Tab 进入编辑模式
   - 启用法向朝向（叠加层）
   - 蓝色 = 正确，红色 = 翻转

3. **如有必要翻转法向：**
   - 选中所有面
   - 使用网格清理中的「翻转法向」
   - 仅当整个网格都翻转时使用

### VRChat/Unity 中缩放错误

**症状：**
- 虚拟形象太大或太小
- 不在预期身高
- 比例错误

**解决方案：**

1. **在 Blender 中检查缩放：**
   - 使用[缩放](Scaling)面板
   - 测量实际身高
   - 缩放到正确尺寸（推荐 160-180cm）

2. **应用变换：**
   - [优化 → 网格清理](Optimization#mesh-cleanup)
   - 「应用变换」
   - 在导出前执行

3. **Unity 导入缩放：**
   - FBX 应为 1.0
   - 检查 Unity 中的导入设置
   - 不要在 Unity 中缩放，请在 Blender 中缩放

## 特定功能问题

### 眼动追踪不工作

**症状：**
- 眼睛不动
- 眨眼不工作
- 设置似乎坏了

**解决方案：**

1. **确认骨骼选择：**
   - [眼动追踪](Eye-Tracking)面板
   - 检查头部、左眼、右眼骨骼是否已选择
   - 使用正确的骨骼

2. **检查权重绘制：**
   - 眼睛必须权重到眼球骨骼
   - 推荐 100% 权重
   - 不要有权重渗漏

3. **在 Blender 中测试：**
   - 使用眼动追踪面板中的测试控件
   - 确认眼睛会移动
   - 检查眨眼形态键

4. **材质 / 图集顺序：**
   - 你是否在眼动追踪**之后**合并材质或做图集？
   - 请在材质合并和图集化**之后**设置眼动追踪
   - 可能需要重做设置

### 口型同步不工作

**症状：**
- 唇形同步时嘴巴不动
- 形态键未指定
- 预览不显示运动

**解决方案：**

1. **检查形态键指定：**
   - [口型同步](Visemes)面板
   - 确认已指定 Mouth A、O、CH
   - 使用正确的形态键

2. **确认形态键存在：**
   - 选中网格
   - 打开形态键面板
   - 确认存在嘴部形态键

3. **用预览测试：**
   - 使用口型同步面板中的预览
   - 逐个检查每个口型
   - 如有需要调整强度

4. **翻译问题：**
   - 在口型同步设置之前翻译形态键
   - 不要在设置之后翻译
   - 可能会破坏引用

### 骨骼合并导致问题

**症状：**
- 骨骼合并后模型损坏
- 权重看起来不对
- 动画失效

**解决方案：**

1. **检查合并设置：**
   - [优化](Optimization)面板
   - 从较低的合并比例（0.5）开始
   - 为安全起见启用「保留合并的骨骼」

2. **在清理前测试：**
   - 先合并骨骼
   - 充分测试
   - 只有合并效果良好时才进行清理

3. **之后确认骨架：**
   - 检查骨骼层级
   - 测试动画
   - 确认权重看起来正确

4. **如有必要撤销：**
   - Ctrl+Z 撤销
   - 尝试不同的设置
   - 或从备份继续工作

## 图集生成器问题

> 💡 旧的 **图集生成器（传统版）** 面板（Material Combiner）已在 `5.3.1.0` 中**移除**，随之消失的还有所有 Pillow 和 Material Combiner 安装问题。内置的[图集生成器](Optimization#atlas-generator)无需安装任何东西。它仍标记为 alpha，因此如果它行为异常，请连同它在 Blender 信息日志中打印的那一行一起报告。

### 我找不到图集生成器（传统版）/ Material Combiner

传统面板已不存在。请改用 **优化 > 图集生成器**。如果仍安装了 Material Combiner，它的**导入 Material Combiner 设置**按钮会把你的旧图集设置、材质勾选和层复制过来。Material Combiner 本身是第三方插件，Cats 已不再支持它。

### 图集中的贴图缺失或错误

**可能原因：**
- Cats 无法通过着色器找到材质的贴图（该行显示 ⚠ 图标）
- 程序化、混合或顶点着色的材质没有单张图像
- 磁盘上的贴图文件缺失

**解决方案：**
1. 为标记 ⚠ 的材质开启**烘焙**，让 Cycles 改为渲染它们
2. 重新链接缺失的贴图（文件 > 外部数据 > 查找缺失文件）
3. 使用**预览结果**在构建前检查将要打包的内容

### 图集颜色看起来太暗

`5.3.1.0` 之前的构建会把纯色和带色调的材质写得太暗。更新 Cats 并重新构建图集；颜色现在会与视口一致。

### 构建第二个图集改变了我第一个图集

`5.3.1.0` 之前的构建会复用名称 `Cats_Atlas_01` / `Cats_Atlas_Mat_01`，因此在同一文件中为第二个虚拟形象做图集时会覆盖第一个。现在每次构建都有各自的名称（`Cats_Atlas_01_2` 等）。更新后请重新构建受影响的图集。

### 重新打开文件后图集消失了

使用**保存到文件夹**且文件夹为空或不可写时，`5.3.1.0` 之前的构建既没有保存也没有打包图集，因此重新加载后就没了。现在保存失败时图集会被打包进 `.blend`，构建也会警告你。请设置一个可写的**文件夹**以获取 PNG 文件。

### 烘焙问题

- **「无法烘焙」错误：** 对象不在当前视图层中，例如位于被排除的集合中。请包含该集合，或取消勾选该对象的材质
- **顶点色被覆盖：** 当 Blender 的烘焙输出设置为颜色属性时，`5.3.1.0` 之前的构建会烘焙到颜色属性中。烘焙现在始终针对图像贴图；请撤销或从备份恢复顶点色
- **某材质在多个对象中的某一个上看起来不对：** 已在 `5.3.1.0` 中修复，共享烘焙材质的对象现在会一起烘焙

## 性能问题

### Cats 操作非常慢

**症状：**
- 工具需要数分钟才能完成
- 操作过程中挂起或冻结

**可能原因：**
- 模型非常复杂
- 对象/网格很多
- 电脑较慢

**解决方案：**

1. **耐心等待：**
   - 复杂操作需要时间
   - Cats 正在工作
   - 在控制台中查看进度

2. **先简化：**
   - 移除不必要的对象
   - 在操作前合并网格
   - 先清理模型

3. **关闭其他程序：**
   - 释放内存
   - 关闭浏览器等
   - 把资源留给 Blender

## 错误信息

### 「未选择骨架」（No Armature Selected）

**解决方案：**
- 选中你的骨架对象
- 必须选择骨架，而不是网格
- 在物体模式下

### 「未找到网格」（No Mesh Found）

**解决方案：**
- 确保存在网格
- 网格必须父级到骨架
- 检查对象的可见性

### 「未找到形态键」（Shape Keys Not Found）

**解决方案：**
- 确认网格有形态键
- 检查是否选中了正确的网格
- 口型同步/眼动追踪必须存在形态键

### 「未找到骨骼」（Bone Not Found）

**解决方案：**
- 确认骨骼名称
- 刷新骨骼列表
- 检查骨架中是否存在该骨骼

### 策略违规警告（Blender 5.2 / 5.3）

**症状：**
- 关于扩展策略的警告
- 关于传统方法的提醒

**这是预期行为：**
- Cats 对第三方插件使用传统方法
- 警告可以安全忽略
- 一切仍然正常工作
- 无需采取任何操作

## 获取更多帮助

### 在寻求帮助之前

1. **查看本页：** 这里涵盖了许多问题
2. **阅读相关的 Wiki 页面：** 功能特定的指南
3. **尝试搜索：** 仓库中已有的 issue
4. **确认版本：** 使用受支持的 Blender 5.2+

### 寻求帮助时

请包含：
- Blender 版本（精确）
- Cats 版本
- 你想做什么
- 实际发生了什么
- 错误信息（精确文本）
- 如相关的截图
- 如可用的控制台输出

### 在哪里获取帮助

- **仓库 issues：** 缺陷报告和问题
- **GitHub Issues：** 缺陷报告和功能请求
- **本 Wiki：** 文档和指南

### 不应报告的内容

- 使用不受支持的 Blender 版本，或非 blender.org / Steam 版本 Blender 的问题（5.2 之前的任何版本都不受支持）
- 第三方扩展问题（Material Combiner 等；Cats 不再与 Material Combiner 集成）
- 通用的 Blender 问题（请使用 Blender 论坛）
- 未经事先讨论的功能请求

## 常见工作流程问题

### 操作顺序错误

**许多问题都源于顺序错误：**

**正确的顺序：**
1. 导入模型
2. 修复 MMD（如果是 MMD 模型，且仅限全新的）
3. 翻译名称
4. 如有需要应用变换
5. **合并材质/创建图集**
6. **设置眼动追踪**
7. **设置口型同步**
8. 最终优化
9. 导出

**要点：** 在眼动追踪和口型同步**之前**合并材质 / 创建图集！

### 备份管理

**始终保留备份：**
- 在重大操作之前
- 完成各阶段之后
- 保存增量版本
- 如可能使用版本控制

**良好的备份实践：**
```
my_model_01_import.blend
my_model_02_fixed.blend
my_model_03_optimized.blend
my_model_04_rigged.blend
my_model_05_final.blend
```
