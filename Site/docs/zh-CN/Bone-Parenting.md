# 骨骼父级

骨骼父级（Bone Parenting）面板可帮助你管理和设置骨架的根骨骼，这对正确的模型绑定和动画至关重要。

## 什么是根骨骼？

根骨骼是你骨架层级中的顶层父级骨骼：
- 所有其他骨骼都是根骨骼的子级（直接或间接）
- 控制模型的整体位置与旋转
- 是正确动画的基础
- VRChat 虚拟形象的必备条件

## 为什么根骨骼很重要

设置正确的根骨骼可以确保：
- 模型在游戏中的行为正确
- 动画正常播放
- IK（反向运动学）行为正确
- 兼容 VRChat

## 根骨骼选择

面板会显示可用作根骨骼的骨骼。

### 选择根骨骼

**通常根骨骼是：**
- 位于模型中心
- 命名为 "Root"、"Hips"、"Armature" 或类似名称
- 相对于世界空间永远不应移动的骨骼
- 脊柱/髋部骨骼的父级

**常见的根骨骼名称：**
- Root
- Hips
- Armature
- Hip
- pelvis
- root_bone

## 主要操作

### 刷新根骨骼

更新根骨骼列表和层级信息。

**何时使用：**
- 导入模型之后
- 修改骨架之后
- 合并骨架之后
- 骨骼列表看起来已过期时

**如何使用：**
1. 点击 **刷新根骨骼**
2. 等待列表更新
3. 查看可用的根骨骼

### 设置根骨骼

将选中的骨骼设为骨架的根骨骼。

**它会做什么：**
- 重新组织骨骼层级
- 建立正确的父级关系
- 确保选中骨骼位于顶层
- 更新骨架结构

**如何使用：**
1. 从列表中选择所需的骨骼
2. 点击 **设置根骨骼**
3. 在 Blender 的骨骼视图中检查层级

## 工作流程

### 设置根骨骼（新模型）

1. **导入模型**
2. **打开骨骼父级面板**
3. **点击刷新根骨骼**
4. **查看可用的骨骼**
5. **选择合适的根骨骼**
6. **点击设置根骨骼**
7. **检查层级**

### 修复根骨骼问题

如果你的模型根骨骼不正确：

1. **确认正确的骨骼**（通常是 Hips 或 Root）
2. **点击刷新根骨骼**
3. **选择正确的骨骼**
4. **点击设置根骨骼**
5. **测试动画**
6. **保存更改**

### 合并骨架之后

使用 [合并与附加](Merge-and-Attach) 之后：

1. **刷新根骨骼** 以更新层级
2. **检查根骨骼是否正确**
3. 如有需要，**设置根骨骼**
4. **确认合并后的骨骼父级关系正确**

## 使用场景

### 为 VRChat 准备模型

1. 导入模型
2. 修复 MMD 模型（如有需要，仅在 MMD 和 VRM 模型上使用）
3. **设置正确的根骨骼**
4. 配置眼动追踪和口型同步
5. 导出

### 修复导入的模型

有些导入器不会正确设置根骨骼：

1. 模型出现在错误的位置
2. 动画无法正常工作
3. **解决方案：** 设置正确的根骨骼

### 合并模型之后

合并骨架时：

1. 合并后的骨架可能层级混乱
2. **刷新并设置根骨骼** 来修复
3. 确保骨骼结构干净

### 创建自定义绑定

构建自定义绑定时：

1. 创建骨骼
2. 一开始就**设置根骨骼**
3. 从根骨骼开始构建层级
4. 让结构保持有条理

## 最佳实践

### 选择根骨骼

**应该：**
- ✅ 选择居中的主要骨骼
- ✅ 选择角色中心的骨骼
- ✅ 人形绑定使用 Hips
- ✅ 确认它在逻辑上合理

**不应该：**
- ❌ 选择末端骨骼（手指、脚趾）
- ❌ 选择辅助骨骼
- ❌ 选择本应独立运动的骨骼
- ❌ 随意选择骨骼

### 何时刷新

**在以下情况之后刷新根骨骼：**
- 导入模型
- 合并骨架
- 添加或删除骨骼
- 复制骨架
- 大幅更改层级

### 设置根骨骼之后

**务必检查：**
1. 在编辑模式下打开骨架
2. 检查骨骼层级（按住 Shift 点击骨骼以查看父级）
3. 确认根骨骼没有父级
4. 确认其他骨骼都能追溯到根骨骼
5. 测试姿态模式，确保一切运动正常

## 常见问题

### 根骨骼列表为空

**可能原因：**
- 没有选中骨架
- 骨架没有骨骼
- 面板需要刷新

**解决方案：**
- 选中你的骨架对象
- 点击刷新根骨骼
- 确认骨架有骨骼

### 错误的骨骼被显示为根骨骼

**可能原因：**
- 层级未更新
- 导入问题
- 之前的设置不正确

**解决方案：**
- 点击刷新根骨骼
- 选择正确的骨骼
- 点击设置根骨骼
- 确认更改已生效

### 设置根骨骼后动画失效

**这种情况很少见，但有可能：**
- 某些动画可能需要重新烘焙
- 动画约束可能需要调整
- 通常动画会自动适应

**解决方案：**
- 设置根骨骼前保存备份
- 更改后测试动画
- 如果失效，撤销并进一步排查

### 无法为特定骨骼设置根骨骼

**可能原因：**
- 骨骼被锁定
- 骨骼上有阻止操作的约束
- 骨架处于编辑模式

**解决方案：**
- 切换到物体模式或姿态模式
- 如果骨骼被锁定，解锁它
- 移除阻止操作的约束

## 理解骨骼层级

### 层级如何工作

```
Root ("Armature" for VRC models) (top level)
├── Hips
│   ├── Spine
│   │   ├── Chest
│   │   │   ├── Neck
│   │   │   │   └── Head
│   │   │   ├── Shoulder.L
│   │   │   │   └── Arm.L
│   │   │   └── Shoulder.R
│   │   │       └── Arm.R
│   ├── Leg.L
│   └── Leg.R
```

- 每根骨骼只能有一个父级
- 每根骨骼可以有多个子级
- 根骨骼没有父级

### 为什么层级很重要

- **动画：** 子级跟随父级的旋转
- **IK：** 骨骼链需要正确的层级
- **VRChat：** 虚拟形象需要特定的层级
- **导出：** Unity 需要正确的骨骼结构
