# 网格工具（已移动） {#mesh-tools-moved}

**网格工具**子面板已不存在。它的内容被拆分为[优化](./Optimization.md)的两个子面板，这样网格相关的工作不再分散在两个地方：

| 旧位置 | 新位置 |
| --- | --- |
| 网格工具 → 按…分离 | [优化 → 网格清理](./Optimization.md#mesh-cleanup) |
| 网格工具 → 法向 | [优化 → 网格清理](./Optimization.md#mesh-cleanup) |
| 网格工具 → 应用变换 | [优化 → 网格清理](./Optimization.md#mesh-cleanup) |
| 网格工具 → 形态键工具 | [优化 → 形态键](./Optimization.md#shape-keys) |

合并网格和移除重合顶点也移到了**网格清理**中，它们以前属于 *材质操作*（现在的[材质](./Optimization.md#materials)）。

趾行腿和扭转骨骼的*生成*工具有了自己的[骨骼工具](./Bone-Tools.md)面板。
