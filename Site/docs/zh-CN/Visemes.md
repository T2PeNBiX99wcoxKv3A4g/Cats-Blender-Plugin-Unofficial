# 口型同步

口型同步面板帮助你为 VRChat 中的唇形同步和面部动画设置口型形态键。

## 什么是口型（Viseme）？

口型是与不同语音相对应的嘴部形状。它们让你的虚拟形象在你说话时能在 VRChat 中自动进行唇形同步。

VRChat 使用三种主要的口型形状：
- **Mouth A（'ah'）：** 用于元音的张嘴
- **Mouth O（'oh'）：** 用于 'o' 和 'u' 音的圆唇
- **Mouth CH：** 用于 'ch' 和 'sh' 音的闭合前突唇

## 要求

- 带有嘴部运动形态键的网格
- 命名正确的形态键（或能够指定它们）

## 网格选择

当你的场景中有多个网格时：
- **选择包含你的面部/嘴部的目标网格**
- 这通常是身体或头部网格
- 该网格必须有形态键

## 口型设置

### 预览控制

**预览口型：**
- 实时测试口型形状
- 查看每个形状的外观
- 在预览时调整数值

**停止预览：**
- 回到默认状态
- 把所有形态键重置为 0
- 退出预览模式

**预览选择：**
- 用于选择要测试的特定口型的下拉框
- 分别测试 Mouth A、Mouth O 或 Mouth CH
- 适合微调每个形状

### 形态键指定

Cats 需要知道哪些形态键对应每个口型。

#### Mouth A（'ah' 音）
- 选择张嘴的形态键
- 用于 'a'、'e' 等元音
- 通常是张口幅度最大的
- 示例名称："a"、"ah"、"mouth_open"

**如何指定：**
1. 点击 Mouth A 的下拉框
2. 从你的网格中选择合适的形态键
3. 用预览测试

#### Mouth O（'oh' 音）
- 选择圆唇的形态键
- 用于 'o' 和 'u' 音
- 嘴唇形成 O 形
- 示例名称："o"、"oh"、"mouth_o"

**如何指定：**
1. 点击 Mouth O 的下拉框
2. 选择合适的形态键
3. 用预览测试

#### Mouth CH
- 选择闭合前突唇的形态键
- 用于 'ch'、'sh' 音
- 嘴唇向前推但基本闭合
- 示例名称："ch"、"mouth_ch"、"sil"

**如何指定：**
1. 点击 Mouth CH 的下拉框
2. 选择合适的形态键
3. 用预览测试

### 形态强度

- 调整口型形状的强度/乘数
- 范围：通常为 0.0 到 2.0
- 默认：1.0（大多数情况下默认值即可）
- **较低的值：** 唇形同步更细微
- **较高的值：** 唇形同步更夸张

**如何调整：**
1. 移动滑块或输入数值
2. 用预览查看效果
3. 找到看起来自然的强度
4. 推荐范围：0.8 到 1.2

## 自动口型设置

**自动口型设置**功能会尝试自动配置口型：

**它会做什么：**
- 搜索常见的形态键名称
- 自动把它们指定到口型槽位
- 创建基础的唇形同步配置
- 设置默认的强度值

**如何使用：**
1. 点击 **自动口型设置**
2. 检查指定结果
3. 如有需要再调整
4. 用预览测试

**效果最好的情况：**
- 使用标准形态键名称的模型
- MMD 模型（修复之后）
- 来自常见来源的模型

> 💡 **提示：** 即使自动设置没有全部正确，它也是一个很好的起点。你之后可以手动调整指定。

## 工作流程

### 基础口型设置

1. 使用[快速访问](Quick-Access)**导入你的模型**
2. **打开口型同步面板**
3. **选择你的网格**（如果你有多个）
4. 先**试试自动口型设置**
5. **检查指定结果：**
   - 检查每个口型形态键
   - 如有需要再调整
6. **用预览测试：**
   - 逐个预览每个口型
   - 调整强度
7. **导出你的模型**

### 手动口型设置

如果自动设置不工作，或你需要更多控制：

1. **确认你的形态键：**
   - 前往 Blender 中的形态键面板
   - 记下哪些形态用于嘴部运动
2. **手动指定每个口型：**
   - Mouth A：张嘴形状
   - Mouth O：圆嘴形状
   - Mouth CH：闭合/前突嘴形
3. **逐个测试：**
   - 用预览确认
   - 按需调整强度

## 提示与最佳实践

### 制作良好的口型

如果从零开始制作形态键：

**Mouth A：**
- 下颌应张开
- 可见牙齿
- 舌头略微可见
- 自然的 'ah' 表情

**Mouth O：**
- 嘴唇形成 O 形
- 下颌略微张开
- 嘴唇略微向前推
- 像说 'oh' 或 'oo' 时那样

**Mouth CH：**
- 嘴唇闭合或几乎闭合
- 嘴唇向前推
- 像 'much' 或 'ssh' 的结尾
- 轻微收拢

### 测试口型

1. **先在 Blender 中测试：**
   - 使用预览功能
   - 从多个角度检查
   - 确认形状看起来自然
2. **在 VRChat 中测试：**
   - 上传并在游戏内测试
   - 询问别人看起来如何
   - 如有需要再调整

### 常见问题

**口型太细微：**
- 提高形态强度
- 检查形态键是否有足够的运动幅度
- 确认指定了正确的形态键

**口型太夸张：**
- 降低形态强度
- 检查形态键的值是不是过于极端
- 在 VRChat 中测试（可能看起来与 Blender 中不同）

**嘴巴不动：**
- 确认口型已指定
- 检查形态键是否存在于正确的网格上
- 确保在口型同步面板中选中了网格

**出现了错误的形状：**
- 检查口型指定
- 确认形态键名称
- 如有需要手动重新指定

## 高级选项

### 多个网格

如果你的虚拟形象有多个独立网格：
- 带口型的身体网格
- 带口型的头部网格
- 只能有一个网格拥有活动口型
- 选择应做动画的网格

### 自定义口型系统

有些模型使用不同的口型系统：
- 标准 3 口型（VRChat 默认）
- 15 口型（高级，本文不涉及）
- 自定义混合形状

Cats 支持标准的 3 口型系统。

## 口型系统详解

### 为什么是 3 个口型？

VRChat 的简化系统使用 3 个口型，因为：
- 对实时唇形同步效率高
- 在准确度和性能之间有良好平衡
- 比完整的音素系统更容易设置
- 与语音识别配合良好

### 它在 VRChat 中如何工作

1. VRChat 分析你的语音输入
2. 判断你在发什么音
3. 激活相应的口型形态键
4. 在形状之间混合，实现平滑动画

## 与其他工具的集成

### 材质合并之后

> ⚠ **重要：** 在合并材质并创建图集**之后**再设置口型。旧的 Material Combiner 插件如果在口型设置之后运行，可能会导致形态键错位；内置的[图集生成器](Optimization#atlas-generator)只会改变材质和 UV，但请保持同样的顺序。

**推荐的顺序：**
1. 导入模型
2. 修复 MMD 模型（如有需要，且仅限 vrm/mmd 模型）
3. 合并材质 / 创建图集
4. 设置口型
5. 设置眼动追踪
6. 导出

### 与眼动追踪

口型和[眼动追踪](Eye-Tracking)可一起工作：
- 两者都使用形态键
- 可以独立设置
- 设置后两者都要测试
- 它们之间没有冲突
