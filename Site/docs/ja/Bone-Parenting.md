# ボーンペアレンティング

ボーンペアレンティングパネルは、アーマチュアのルートボーンを管理・設定するためのパネルです。これは適切なモデルのリギングとアニメーションに欠かせません。

## ルートボーンとは

ルートボーンは、アーマチュア階層の最上位の親ボーンです。
- 他のすべてのボーンは（直接的または間接的に）ルートの子になります
- モデル全体の位置と回転を制御します
- 適切なアニメーションに不可欠です
- VRChat アバターには必須です

## ルートボーンが重要な理由

ルートボーンが正しく設定されていると、次のことが保証されます。
- ゲーム内での正しいモデルの挙動
- 適切なアニメーションの再生
- 正しい IK（インバースキネマティクス）の挙動
- VRChat との互換性

## ルートボーンの選択

パネルには、ルートボーンとして使用できるボーンの一覧が表示されます。

### ルートボーンの選び方

**一般的に、ルートボーンは次のようなものです。**
- モデルの中心にある
- "Root"、"Hips"、"Armature" などの名前が付いている
- ワールド空間に対して決して動くべきではないボーン
- 脊椎や腰のボーンの親である

**よくあるルートボーン名:**
- Root
- Hips
- Armature
- Hip
- pelvis
- root_bone

## 主な操作

### Refresh Root

ルートボーンの一覧と階層情報を更新します。

**使用するタイミング:**
- モデルをインポートした後
- アーマチュアを変更した後
- アーマチュアを結合した後
- ボーン一覧が古くなっているように見えるとき

**使用方法:**
1. **Refresh Root** をクリックします
2. 一覧が更新されるまで待ちます
3. 利用可能なルートボーンを確認します

### Set Root

選択したボーンをアーマチュアのルートとして設定します。

**動作内容:**
- ボーンの階層を再構成します
- 適切なペアレント設定を行います
- 選択したボーンが最上位になるようにします
- アーマチュアの構造を更新します

**使用方法:**
1. 一覧から目的のボーンを選択します
2. **Set Root** をクリックします
3. Blender のボーン表示で階層を確認します

## ワークフロー

### ルートボーンの設定（新しいモデル）

1. **モデルをインポートします**
2. **ボーンペアレンティングパネルを開きます**
3. **Refresh Root をクリックします**
4. **利用可能なボーンを確認します**
5. **適切なルートボーンを選択します**
6. **Set Root をクリックします**
7. **階層を確認します**

### ルートボーンの問題を修正する

モデルのルートが正しくない場合:

1. **正しいボーンを特定します**（通常は Hips または Root）
2. **Refresh Root をクリックします**
3. **正しいボーンを選択します**
4. **Set Root をクリックします**
5. **アニメーションをテストします**
6. **変更を保存します**

### アーマチュア結合後

[Merge & Attach](Merge-and-Attach) を使用した後:

1. **Refresh Root** で階層を更新します
2. **ルートが正しいか確認します**
3. **必要に応じて Set Root** を実行します
4. **結合したボーンのペアレントが正しいか確認します**

## ユースケース

### VRChat 用にモデルを準備する

1. モデルをインポートします
2. MMD モデルを修正します（必要な場合のみ、MMD および VRM モデルに使用します）
3. **適切なルートボーンを設定します**
4. アイトラッキングとリップシンクを設定します
5. エクスポートします

### インポートしたモデルを修正する

一部のインポーターはルートを正しく設定しません:

1. モデルが間違った位置に表示されます
2. アニメーションが正しく動作しません
3. **解決策:** 適切なルートボーンを設定します

### モデルの結合後

アーマチュアを統合する場合:

1. 結合したアーマチュアの階層が乱れていることがあります
2. **Refresh と Set Root** で修正します
3. ボーン構造が整理されます

### カスタムリグの作成

カスタムリグを構築する場合:

1. ボーンを作成します
2. 最初に **Set Root** を実行します
3. ルートから階層を構築します
4. 構造が整理された状態を保てます

## ベストプラクティス

### ルートボーンの選択

**すべきこと:**
- ✅ 中心となる主要なボーンを選びます
- ✅ キャラクターの中心にあるボーンを選びます
- ✅ ヒューマノイドリグでは Hips を使用します
- ✅ 論理的に妥当か確認します

**すべきでないこと:**
- ❌ 末端のボーン（指、足先）を選びます
- ❌ ヘルパーボーンを選びます
- ❌ 独立して動くべきボーンを選びます
- ❌ 無作為なボーンを使用します

### 更新のタイミング

**次の後に Refresh Root を実行します。**
- モデルのインポート
- アーマチュアの結合
- ボーンの追加や削除
- アーマチュアの複製
- 大規模な階層の変更

### ルート設定後

**必ず次を確認します。**
1. 編集モードでアーマチュアを開きます
2. ボーンの階層を確認します（ボーンを shift クリックすると親を確認できます）
3. ルートボーンに親がないことを確認します
4. 他のボーンがルートに遡れることを確認します
5. ポーズモードでテストし、すべてが正しく動くことを確認します

## よくある問題

### ルートボーンの一覧が空

**考えられる原因:**
- アーマチュアが選択されていません
- アーマチュアにボーンがありません
- パネルの更新が必要です

**解決策:**
- アーマチュアオブジェクトを選択します
- Refresh Root をクリックします
- アーマチュアにボーンがあることを確認します

### 間違ったボーンがルートとして表示される

**考えられる原因:**
- 階層が更新されていません
- インポートの問題です
- 以前の設定が正しくありません

**解決策:**
- Refresh Root をクリックします
- 正しいボーンを選択します
- Set Root をクリックします
- 変更が反映されたことを確認します

### ルート設定後にアニメーションが壊れる

**まれですが、可能性はあります。**
- 一部のアニメーションは再ベイクが必要な場合があります
- アニメーションのコンストレイント調整が必要な場合があります
- 通常はアニメーションが自動的に適応します

**解決策:**
- ルート設定の前にバックアップを保存します
- 変更後にアニメーションをテストします
- 壊れた場合は元に戻して、さらに調査します

### 特定のボーンにルートを設定できない

**考えられる原因:**
- ボーンがロックされています
- ボーンにそれを妨げるコンストレイントがあります
- アーマチュアが編集モードになっています

**解決策:**
- オブジェクトモードまたはポーズモードに切り替えます
- ロックされている場合はボーンのロックを解除します
- 妨げているコンストレイントを削除します

## ボーン階層の理解

### 階層の仕組み

```
Root ("Armature" for VRC models) (top level)
├── Hips
│   ├── Spine
│   │   ├── Chest
│   │   │   ├── Neck
│   │   │   │   └── Head
│   │   │   ├── Shoulder.L
│   │   │   │   └── Arm.L
│   │   │   └── Shoulder.R
│   │   │       └── Arm.R
│   ├── Leg.L
│   └── Leg.R
```

- 各ボーンは 1 つの親を持てます
- 各ボーンは複数の子を持てます
- ルートには親がありません

### 階層が重要な理由

- **アニメーション:** 子は親の回転に追従します
- **IK:** ボーンチェーンには適切な階層が必要です
- **VRChat:** アバターには特定の階層が求められます
- **エクスポート:** Unity には正しいボーン構造が必要です
