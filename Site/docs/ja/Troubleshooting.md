# トラブルシューティング

Cats Blender Plugin のよくある問題と解決策です。

## クイックトラブルシューティング

> 💡 **最初のステップ:** 特定の問題に踏み込む前に:
> 1. **Blender 4.2 LTS 以降**を使用していることを確認してください
> 2. **最新バージョンの Cats**であることを確認してください
> 3. Cats をインストール/更新した後に **Blender を再起動**してください
> 4. Extensions の設定で Cats が**有効**になっていることを確認してください

---

## インストールの問題

### インストール後に拡張機能が表示されない

**症状:**
- Cats をインストールしたが見つからない
- サイドバーに Cats タブがない
- 一覧に拡張機能がない

**解決策:**

1. **有効か確認する:**
   - Edit > Preferences > Extensions
   - "Cats" を検索します
   - チェックボックスがオンになっていることを確認します

2. **Blender を再起動する:**
   - Blender を完全に閉じます
   - Blender を再度開きます
   - もう一度確認します

3. **インストールを確認する:**
   - ZIP ファイルをインストールしたことを確認します（展開しないでください）
   - "Install from Disk" を使用したことを確認します
   - Blender 5.2 / 5.3 用の Cats のバージョンをダウンロードしたことを確認します

4. **Blender のバージョンを確認する:**
   - Help > About Blender
   - 4.2 LTS 以降である必要があります
   - Blender に合った Cats のバージョンをダウンロードします

5: **N を押してサイドバーが開いていることを確認します**

### インストール時にエラーが出る

**考えられる原因:**
- Blender に対して間違った Cats のバージョン
- ダウンロードの破損
- 権限の問題
- 拡張機能の競合

**解決策:**

1. **バージョンの一致を確認する:**
   - Blender 4.2 LTS から 5.4 はすべて現在の Cats リリースを実行できます。Blender 4.1 以前は拡張機能を読み込めません
   - Cats のバージョンを Blender のバージョンに合わせます（[Version Support](Version-Support) を参照）

2. **再ダウンロードする:**
   - 途中までのダウンロードを削除します
   - 新しいコピーをダウンロードします
   - ファイルが破損していないか確認します

3. **権限を確認する:**
   - Blender が extensions フォルダーに書き込めることを確認します
   - Blender を管理者として実行します（Windows）
   - フォルダーの権限を確認します

4. **競合する拡張機能を削除する:**
   - 古い Cats のバージョン
   - 互換性のないアドオン（MMD Tools など。cats には最新の MMD Tools が同梱されており、互いに競合します）
   - 削除後に再起動します

### サイドバーに Cats タブが表示されない

**解決策:**

1. **N を押す:**
   - 3D ビューポートで **N** キーを押します
   - サイドバーの表示/非表示を切り替えます

2. **Cats タブを探す:**
   - サイドバーのすべてのタブを確認します
   - "Cats" タブがあるはずです
   - クリックして開きます

3. **拡張機能が有効か確認する:**
   - Edit > Preferences > Extensions
   - Cats を見つけます
   - 有効のチェックボックスを確認します

## インポート/エクスポートの問題

### モデルがインポートされない

**症状:**
- インポートボタンを押しても何も起きない
- インポート中にエラーメッセージが出る
- Blender がクラッシュする

**解決策:**

1. **ファイル形式を確認する:**
   - サポートされている形式か確認します（.pmx、.pmd、.fbx、.vrm など）
   - ファイルが破損していないこと
   - ファイルサイズが妥当であること

2. **ファイルパスを確認する:**
   - パスに特殊文字がないこと
   - パスが長すぎないこと
   - ファイルが他のプログラムで使用されていないこと

3. **Blender の標準インポーターを試す:**
   - File > Import
   - それでも失敗する場合、ファイルが破損している可能性があります

4. **コンソールでエラーを確認する:**
   - Window > Toggle System Console
   - エラーメッセージを探します
   - 具体的なエラーを報告します

## モデルの表示の問題

### モデルが黒く表示される、またはテクスチャがない

**症状:**
- モデルが全体に黒い
- テクスチャが表示されない
- マテリアルがおかしく見える

**解決策:**

1. **ビューポートのシェーディングを切り替える:**
   - Z キーを押します
   - "Material Preview" または "Rendered" を選択します
   - "Solid" モードではテクスチャが表示されない場合があります

2. **マテリアルのプロパティを確認する:**
   - メッシュを選択します
   - Material Properties パネルを開きます
   - マテリアルが存在することを確認します
   - テクスチャが読み込まれているか確認します

3. **テクスチャのパス:**
   - マテリアルが存在しないテクスチャを参照している可能性があります
   - 必要に応じてテクスチャを再リンクします
   - Blender の "Find Missing Files" を使用します

4. **アトラス作成後:**
   - アトラスのマテリアルは単純な Principled BSDF で、トゥーン/MToon の見た目は保持されません
   - Unity でマテリアルを適切に設定します
   - [Atlas Generator の問題](#atlas-generator-issues)を参照してください

### モデルが反転している/裏返っている

**症状:**
- メッシュが裏返って見える
- 裏面が見える
- シェーディングがおかしく見える

**解決策:**

1. **法線を再計算する:**
   - [Optimization → Mesh Cleanup](Optimization#mesh-cleanup) パネル
   - "Recalculate Normals" をクリックします

2. **編集モードで確認する:**
   - Tab で編集モードに切り替えます
   - Face Orientation（オーバーレイ）を有効にします
   - 青 = 正しい、赤 = 反転

3. **必要に応じて法線を反転する:**
   - すべての面を選択します
   - Mesh Cleanup の "Flip Normals" を使用します
   - メッシュ全体が反転している場合のみ

### VRChat/Unity でスケールが間違っている

**症状:**
- アバターが大きすぎる、または小さすぎる
- 期待した身長になっていない
- プロポーションがおかしい

**解決策:**

1. **Blender でスケールを確認する:**
   - [Scaling](Scaling) パネルを使用します
   - 実際の身長を測定します
   - 正しいサイズにスケーリングします（160-180cm を推奨）

2. **トランスフォームを適用する:**
   - [Optimization → Mesh Cleanup](Optimization#mesh-cleanup)
   - "Apply Transformations"
   - エクスポートの前に

3. **Unity のインポートスケール:**
   - FBX では 1.0 が適切です
   - Unity のインポート設定を確認します
   - Unity ではスケーリングせず、Blender でスケーリングします

## 機能別の問題

### アイトラッキングが動作しない

**症状:**
- 目が動かない
- まばたきが動作しない
- セットアップが壊れているように見える

**解決策:**

1. **ボーンの選択を確認する:**
   - [Eye Tracking](Eye-Tracking) パネル
   - 頭、左目、右目のボーンが選択されているか確認します
   - 正しいボーンを使用します

2. **ウェイトペイントを確認する:**
   - 目は目のボーンにウェイトされている必要があります
   - 100% のウェイトを推奨します
   - ウェイトの漏れがないこと

3. **Blender でテストする:**
   - Eye Tracking パネルのテストコントロールを使用します
   - 目が動くことを確認します
   - まばたきのシェイプキーを確認します

4. **マテリアル / アトラスの順序:**
   - アイトラッキングの**後に**マテリアルを結合したりアトラス化したりしていませんか?
   - マテリアルの結合とアトラス化の**後に**アイトラッキングを設定してください
   - セットアップをやり直す必要がある場合があります

### Visemes が動作しない

**症状:**
- リップシンクで口が動かない
- シェイプキーが割り当てられていない
- プレビューで動きが表示されない

**解決策:**

1. **シェイプキーの割り当てを確認する:**
   - [Visemes](Visemes) パネル
   - Mouth A、O、CH が割り当てられているか確認します
   - 正しいシェイプキーを使用します

2. **シェイプキーが存在するか確認する:**
   - メッシュを選択します
   - Shape Keys パネルを開きます
   - 口のシェイプキーが存在することを確認します

3. **プレビューでテストする:**
   - Visemes パネルのプレビューを使用します
   - 各 viseme を個別に確認します
   - 必要に応じて強度を調整します

4. **翻訳の問題:**
   - viseme の設定前にシェイプキーを翻訳してください
   - 設定後に翻訳しないでください
   - 参照が壊れる可能性があります

### ボーンの結合で問題が発生する

**症状:**
- ボーンの結合後にモデルが壊れる
- ウェイトがおかしく見える
- アニメーションが壊れる

**解決策:**

1. **結合の設定を確認する:**
   - [Optimization](Optimization) パネル
   - 低い結合比率（0.5）から始めます
   - 安全のため "Keep Merged Bones" を有効にします

2. **クリーンアップの前にテストする:**
   - まずボーンを結合します
   - 徹底的にテストします
   - 結合が良好な場合のみクリーンアップします

3. **後でアーマチュアを確認する:**
   - ボーン階層を確認します
   - アニメーションをテストします
   - ウェイトが正しく見えるか確認します

4. **必要に応じて元に戻す:**
   - Ctrl+Z で元に戻します
   - 別の設定を試します
   - またはバックアップから作業します

## Atlas Generator の問題

> 💡 旧 **Atlas Generator (Legacy)** パネル（Material Combiner）は **`5.3.1.0` で削除**され、Pillow と Material Combiner のインストールに関するあらゆる問題も一緒になくなりました。内蔵の [Atlas Generator](Optimization#atlas-generator) は何もインストールする必要がありません。まだアルファ版とされているため、動作がおかしい場合は Blender の Info ログに出力された行とともに報告してください。

### Atlas Generator (Legacy) / Material Combiner が見つからない

レガシーパネルはもう存在しません。代わりに **Optimization > Atlas Generator** を使用してください。Material Combiner がまだインストールされている場合、その **Import Material Combiner Settings** ボタンで古いアトラス設定、マテリアルのチェック、レイヤーを引き継げます。Material Combiner 自体はサードパーティのアドオンであり、Cats はもうサポートしていません。

### アトラスでテクスチャが欠落している、または間違っている

**考えられる原因:**
- Cats がシェーダーを通じてマテリアルのテクスチャを見つけられなかった（行に ⚠ アイコンが表示されます）
- 単一の画像を持たないプロシージャル、ミックス、または頂点カラーのマテリアル
- ディスク上にテクスチャファイルが存在しない

**解決策:**
1. ⚠ の付いたマテリアルで **Bake** をオンにして、代わりに Cycles でレンダリングさせます
2. 欠落したテクスチャを再リンクします（File > External Data > Find Missing Files）
3. ビルド前に **Preview Result** で何がパックされるか確認します

### アトラスの色が暗すぎる

`5.3.1.0` 以前のビルドは、フラットカラーやティントされたマテリアルを暗すぎる状態で書き出していました。Cats を更新してアトラスを再ビルドしてください。色はビューポートと一致するようになりました。

### 2 つ目のアトラスをビルドしたら 1 つ目が変わった

`5.3.1.0` 以前のビルドは `Cats_Atlas_01` / `Cats_Atlas_Mat_01` という名前を再利用していたため、同じファイル内で 2 つ目のアバターをアトラス化すると 1 つ目が上書きされました。各ビルドは独自の名前（`Cats_Atlas_01_2` など）を持つようになりました。更新後に影響を受けたアトラスを再ビルドしてください。

### ファイルを開き直したらアトラスが消えた

**Save to Folder** でフォルダーが空または書き込み不可の場合、`5.3.1.0` 以前のビルドはアトラスを保存もパックもせず、再読み込み時に失われていました。保存に失敗した場合はアトラスが `.blend` にパックされるようになり、ビルド時に警告が表示されます。PNG ファイルを取得するには書き込み可能な **Folder** を設定してください。

### ベイクの問題

- **"cannot be baked" エラー:** オブジェクトが現在のビューレイヤーにありません。たとえば除外されたコレクション内にあります。コレクションを含めるか、そのオブジェクトのマテリアルのチェックを外してください
- **頂点カラーが上書きされた:** `5.3.1.0` 以前のビルドは、Blender のベイク出力が Color Attributes に設定されているとカラー属性にベイクしていました。ベイクは常に画像テクスチャを対象とするようになりました。頂点カラーを元に戻すか、バックアップから復元してください
- **ベイク済みマテリアルが複数のオブジェクトの 1 つでおかしく見えた:** `5.3.1.0` で修正されました。ベイク済みマテリアルを共有するオブジェクトは一緒にベイクされるようになりました

## パフォーマンスの問題

### Cats の操作が非常に遅い

**症状:**
- ツールの完了に数分かかる
- 操作中にハングまたはフリーズする

**考えられる原因:**
- 非常に複雑なモデル
- 多数のオブジェクト/メッシュ
- 遅いコンピューター

**解決策:**

1. **気長に待つ:**
   - 複雑な操作には時間がかかります
   - Cats は動作しています
   - 進行状況はコンソールで確認できます

2. **まず簡略化する:**
   - 不要なオブジェクトを削除します
   - 操作の前にメッシュを結合します
   - まずモデルを整理します

3. **他のプログラムを閉じる:**
   - RAM を解放します
   - ブラウザなどを閉じます
   - Blender にリソースを割り当てます

## エラーメッセージ

### "No Armature Selected"

**解決策:**
- アーマチュアオブジェクトを選択します
- メッシュではなくアーマチュアを選択する必要があります
- オブジェクトモードで行います

### "No Mesh Found"

**解決策:**
- メッシュが存在することを確認します
- メッシュはアーマチュアにペアレントされている必要があります
- オブジェクトの可視性を確認します

### "Shape Keys Not Found"

**解決策:**
- メッシュにシェイプキーがあることを確認します
- 正しいメッシュが選択されているか確認します
- viseme/アイトラッキングにはシェイプキーが存在する必要があります

### "Bone Not Found"

**解決策:**
- ボーン名を確認します
- ボーン一覧を更新します
- ボーンがアーマチュアに存在するか確認します

### ポリシー違反の警告（Blender 5.2 / 5.3）

**症状:**
- 拡張機能のポリシーに関する警告
- レガシーな方法に関する警告

**これは想定どおりです:**
- Cats はサードパーティのアドオンのためにレガシーな方法を使用しています
- 警告は無視しても安全です
- すべて正しく動作します
- 対応は不要です

## 追加のサポートを受ける

### 助けを求める前に

1. **このページを確認する:** 多くの問題はここで扱っています
2. **関連する Wiki ページを読む:** 機能別のガイドです
3. **検索を試す:** リポジトリの既存の issue です
4. **バージョンを確認する:** サポート対象の Blender 5.2 以降を使用しているか

### 助けを求めるとき

次の情報を含めてください。
- Blender のバージョン（正確に）
- Cats のバージョン
- 何をしようとしているか
- 代わりに何が起こるか
- エラーメッセージ（正確な文言）
- 関連する場合はスクリーンショット
- 可能であればコンソール出力

### サポートを受ける場所

- **リポジトリの issue:** バグ報告と質問
- **GitHub Issues:** バグ報告と機能リクエスト
- **この Wiki:** ドキュメントとガイド

### 報告すべきでないもの

- サポートされていない Blender バージョン、または blender.org や Steam 版ではない Blender バージョンでの問題（5.2 より前はサポートされません）
- サードパーティ拡張機能の問題（Material Combiner など。Cats はもう Material Combiner と統合していません）
- 一般的な Blender の質問（Blender のフォーラムを使用してください）
- 事前の議論のない機能リクエスト

## よくあるワークフローの問題

### 操作の順序が間違っている

**多くの問題は順序の誤りに起因します:**

**正しい順序:**
1. モデルをインポート
2. MMD を修正（MMD モデルの場合、新規のみ）
3. 名前を翻訳
4. 必要に応じてトランスフォームを適用
5. **マテリアルを結合/アトラスを作成**
6. **アイトラッキングを設定**
7. **visemes を設定**
8. 最終的な最適化
9. エクスポート

**重要なポイント:** アイトラッキングと visemes の**前に**マテリアルを結合/アトラスを作成してください!

### バックアップの管理

**常にバックアップを保持します:**
- 大きな操作の前
- 各段階の完了後
- 段階的にバージョンを保存
- 可能であればバージョン管理を使用

**良いバックアップの実践:**
```
my_model_01_import.blend
my_model_02_fixed.blend
my_model_03_optimized.blend
my_model_04_rigged.blend
my_model_05_final.blend
```
