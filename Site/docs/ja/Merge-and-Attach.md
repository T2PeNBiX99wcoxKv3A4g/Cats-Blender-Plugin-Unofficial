# マージとアタッチ

**Merge & Attach** パネル（旧 "Custom Model Creation"）は、アーマチュアを結合し、メッシュをアタッチして、結合されたモデルやカスタマイズされたモデルを構築するためのツールを提供します。

## 概要

このパネルには 2 つの主要なモードがあります。
- **Armature Mode** - 2 つの完全なアーマチュアを結合します
- **Mesh Mode** - 個別のメッシュを既存のアーマチュアにアタッチします

上部のチュートリアルボタンが、手順を 1 つずつ案内します。

---

## アーマチュアモード

アーマチュアモードは、2 つのリグ付きモデルを 1 つに統合するために使用します。

### 必要条件
- シーン内に少なくとも 2 つのアーマチュア
- 両方のアーマチュアにメッシュがアタッチされていること

### 主な設定

- **Merge Same Bones** - 名前が一致するボーンを自動的に結合します。両方のモデルが似たスケルトンを共有している場合（例: VRChat 標準のモデル 2 つ）に最適です。
- **Apply Transforms** - 結合前に現在のトランスフォームを適用します。推奨され、スケールや回転の問題を防ぎます。
- **Join Meshes** - 結合後にメッシュを 1 つのオブジェクトに統合します。
- **Remove Zero Weight Bones** - 結合後に未使用のボーンを整理します。
- **Cleanup Shape Keys** - 結合中に重複した/未使用のシェイプキーを削除します。

### 結合対象の選択

- **Merge Into** - 結合された内容を受け取る対象（ベース）のアーマチュア（通常はメインキャラクター）。
- **To Merge** - 結合するアーマチュア（通常は服、アクセサリー、追加パーツ）。
- **Attach to Bone** *（"Merge Same Bones" が無効な場合）* - 結合したアーマチュアをアタッチするボーン（例: 翼を脊椎に）。

**"Attach to Bone" の実際の動作:** 結合したアーマチュアの**ルート**ボーンのみが、選択したボーンに再ペアレントされます。その下のすべては独自の階層を保つため、`Spine` にアタッチされた尻尾のリグは尻尾のままですが、脊椎からぶら下がる形になります。結合したアーマチュアでベースのアーマチュアと名前が衝突するボーンは、同じ名前のベースのボーンに統合され、ウェイトは一致する頂点グループに結合されます。

**物理は自動的に整理されます:** 結合時には**両方**のアーマチュアから剛体とジョイントのオブジェクト（ネストした物理グループを含む）が最初に削除されるため、事前に [Remove Rigid Bodies and Joints](Converters#remove-rigid-bodies-and-joints) を実行する必要はありません。

### 使用方法

1. 両方のモデルをシーンにインポートします。
2. **Merge Into** のアーマチュア（ベースモデル）を選択します。
3. **To Merge** のアーマチュア（追加するモデル）を選択します。
4. 設定を選択します:
   - スケルトンが一致する場合は **Merge Same Bones** を有効にします。
   - **Apply Transforms** を有効にします（推奨）。
   - 単一メッシュの結果にする場合は **Join Meshes** を有効にします。
5. 同じボーンを結合しない場合は **Attach to Bone** を選択します。
6. **Merge** をクリックします。

**一般的な用途:** ベースの体 + リグ付きの服や髪、リグ付きアクセサリー（翼、尻尾、小道具）の追加。

## メッシュモード

メッシュモードは、単体のメッシュを既存のアーマチュアにアタッチするために使用します。

### 必要条件
- シーン内に少なくとも 1 つのアーマチュア
- 少なくとも 1 つのリグなしのメッシュオブジェクト

### 設定と選択

- **Join Meshes** - アタッチしたメッシュを既存のメッシュと結合します。
- **Merge Into** - 対象のアーマチュア。
- **Attach Mesh** - アタッチする（リグなしの）メッシュ。
- **Attach to Bone** - メッシュが追従するボーン（例: 帽子を頭のボーンに）。

### 使用方法

1. アーマチュアとリグなしのメッシュがあることを確認します。
2. **Mesh Mode** に切り替えます。
3. **Merge Into** のアーマチュアを選択します。
4. **Attach Mesh** を選択します。
5. **Attach to Bone** を選択します。
6. 必要に応じて **Join Meshes** を有効にします。
7. **Attach** をクリックします。

**一般的な用途:** 剛体的なアタッチメント（帽子、眼鏡、小道具）や、変形しない簡単な服。

## ヒントとベストプラクティス

**結合前:** モデルを正しく配置し、スケールを合わせ、バックアップを保存し、ボーンにわかりやすい名前を付けてください（"Merge Same Bones" に役立ちます）。

**結合中:** **Apply Transforms** を有効にした状態で始め、可能な場合は **Merge Same Bones** を優先し、問題を修正しやすくするため最初は **Join Meshes** をオフにしておいてください。

**結合後:** ウェイトペイントを確認し、アニメーションをテストし、ボーン階層を見直し、必要に応じて [Optimization](Optimization) で最適化してください。

### トラブルシューティング

- **メッシュが間違った位置にある** → **Apply Transforms** を有効にして再試行してください。
- **ボーンが結合されない** → 名前が完全に一致している（大文字小文字を区別）ことと、位置が似ていることを確認してください。
- **メッシュがアーマチュアに追従しない** → ウェイトが設定されていること、および頂点グループがボーン名と一致していることを確認してください。
- **シェイプキーが消える** → **Cleanup Shape Keys** を有効にしてください。
- **結合したパーツが選択したボーンではなくワールド原点にある** → 結合したアーマチュアのルートが再ペアレントされていません。**Attach to Bone** のドロップダウンを再度開いてボーンを選び直し、もう一度結合してください。**Merge Same Bones** がオフであることを確認してください。これは **Attach to Bone** を完全に無視します。
- **"Please fix your model" / トランスフォームエラー** → 片方または両方のアーマチュアに、デフォルト以外のトランスフォームを持つ親オブジェクト（通常はインポーター由来の Empty）があります。親にトランスフォームを適用する（Ctrl+A → All Transforms）か、**Merge Same Bones** を有効にしてください。これは不要な親を自動的に削除します。

---

## 制限事項

- アーマチュアモードには少なくとも 2 つのアーマチュアが必要です。メッシュモードには少なくとも 1 つのアーマチュアと 1 つのメッシュが必要です。
- 非常に複雑な結合には時間がかかり、一部のカスタムコンストレイントは手動で修正する必要がある場合があります。

> ⚠ **結合の前には必ずモデルをバックアップしてください。** 結果はモデルの複雑さによって異なります。
