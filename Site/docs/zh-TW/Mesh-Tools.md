# 網格工具（已移動） {#mesh-tools-moved}

**網格工具**子面板已不復存在。它的內容被拆分到[最佳化](./Optimization.md)的兩個子面板中，這樣網格相關的工作就不再分散於兩處：

| 舊位置 | 新位置 |
| --- | --- |
| Mesh Tools → Separate By | [最佳化 → 網格清理](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Normals | [最佳化 → 網格清理](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Apply Transformations | [最佳化 → 網格清理](./Optimization.md#mesh-cleanup) |
| Mesh Tools → 形態鍵工具 | [最佳化 → 形態鍵](./Optimization.md#shape-keys) |

Join Meshes 與 Remove Doubles 也移到了**網格清理**中，它們先前位於*材質操作*底下（現在的[材質](./Optimization.md#materials)）。

趾行腿與扭轉骨骼的*產生*工具則有自己的[骨骼工具](./Bone-Tools.md)面板。
