# 骨骼父子關係 {#bone-parenting}

骨骼父子關係（Bone Parenting）面板可協助你管理並設定骨架的根骨骼，這對於正確的模型綁定與動畫來說是不可或缺的。

## 什麼是根骨骼？ {#what-is-a-root-bone}

根骨骼是骨架階層中最上層的父骨骼：
- 所有其他骨骼都是根的子骨骼（直接或間接）
- 控制模型的整體位置與旋轉
- 對於正確的動畫至關重要
- VRChat 虛擬角色必需具備

## 為什麼根骨骼很重要 {#why-root-bones-matter}

設定正確的根骨骼可確保：
- 模型在遊戲中的行為正確
- 動畫正常播放
- IK（反向運動學）行為正確
- VRChat 相容性

## 根骨骼選擇 {#root-bone-selection}

面板會列出可作為根骨骼的可用骨骼。

### 選擇根骨骼 {#choosing-a-root-bone}

**根骨骼通常會是：**
- 位於模型中心
- 命名為「Root」、「Hips」、「Armature」或類似名稱
- 相對於世界空間永不應該移動的骨骼
- 脊椎／髖部骨骼的父骨骼

**常見的根骨骼名稱：**
- Root
- Hips
- Armature
- Hip
- pelvis
- root_bone

## 主要動作 {#main-actions}

### 重新整理根骨骼 {#refresh-root}

更新根骨骼清單與階層資訊。

**使用時機：**
- 匯入模型之後
- 對骨架做出變更之後
- 合併骨架之後
- 骨骼清單看起來已過期時

**使用方式：**
1. 點擊 **Refresh Root**
2. 等待清單更新
3. 檢視可用的根骨骼

### 設定根骨骼 {#set-root}

將選取的骨骼設為骨架的根。

**它會做什麼：**
- 重新組織骨骼階層
- 設定正確的父子關係
- 確保選取的骨骼位於最上層
- 更新骨架結構

**使用方式：**
1. 從清單中選取想要的骨骼
2. 點擊 **Set Root**
3. 在 Blender 的骨骼檢視中確認階層

## 工作流程 {#workflow}

### 設定根骨骼（新模型） {#setting-up-root-bone-new-model}

1. **匯入你的模型**
2. **開啟骨骼父子關係面板**
3. **點擊 Refresh Root**
4. **檢視可用骨骼**
5. **選擇適當的根骨骼**
6. **點擊 Set Root**
7. **確認階層**

### 修正根骨骼問題 {#fixing-root-bone-issues}

若你的模型根骨骼不正確：

1. **找出正確的骨骼**（通常是 Hips 或 Root）
2. **點擊 Refresh Root**
3. **選取正確的骨骼**
4. **點擊 Set Root**
5. **測試動畫**
6. **儲存變更**

### 骨架合併之後 {#after-armature-merging}

使用 [合併與附加](./Merge-and-Attach.md) 之後：

1. **重新整理根骨骼** 以更新階層
2. **檢查根骨骼是否正確**
3. **視需要設定根骨骼**
4. **確認合併後的骨骼父子關係正確**

## 使用案例 {#use-cases}

### 為 VRChat 準備模型 {#preparing-model-for-vrchat}

1. 匯入模型
2. 修復 MMD 模型（如僅需用於 MMD 與 VRM 模型）
3. **設定正確的根骨骼**
4. 設定眼動追蹤與視素
5. 匯出

### 修正匯入的模型 {#fixing-imported-models}

有些匯入器不會正確設定根骨骼：

1. 模型出現在錯誤的位置
2. 動畫無法正確運作
3. **解決方式：** 設定正確的根骨骼

### 合併模型之後 {#after-merging-models}

合併骨架時：

1. 合併後的骨架階層可能混亂
2. **重新整理並設定根骨骼** 來修正
3. 確保骨骼結構乾淨

### 建立自訂骨架 {#creating-custom-rigs}

建立自訂骨架時：

1. 建立骨骼
2. 一開始就 **設定根骨骼**
3. 從根開始建立階層
4. 讓結構保持井然有序

## 最佳實務 {#best-practices}

### 選擇根骨骼 {#choosing-root-bone}

**應該：**
- ✅ 選擇中央的主要骨骼
- ✅ 挑選位於角色中心的骨骼
- ✅ 人形骨架使用 Hips
- ✅ 確認它在邏輯上合理

**不應該：**
- ❌ 選擇末端骨骼（手指、腳趾）
- ❌ 選擇輔助骨骼
- ❌ 挑選應該獨立移動的骨骼
- ❌ 使用任意的骨骼

### 何時要重新整理 {#when-to-refresh}

**在下列情況之後重新整理根骨骼：**
- 匯入模型
- 合併骨架
- 新增或刪除骨骼
- 複製骨架
- 大幅變更階層

### 設定根骨骼之後 {#after-setting-root}

**永遠要確認：**
1. 在編輯模式中開啟骨架
2. 檢查骨骼階層（按住 shift 點擊骨骼以查看父系）
3. 確認根骨骼沒有父系
4. 確認其他骨骼都能追溯回根
5. 測試姿態模式以確保所有東西都能正確移動

## 常見問題 {#common-issues}

### 根骨骼清單是空的 {#root-bone-list-is-empty}

**可能原因：**
- 未選取骨架
- 骨架沒有骨骼
- 面板需要重新整理

**解決方式：**
- 選取你的骨架物件
- 點擊 Refresh Root
- 確認骨架有骨骼

### 錯誤的骨骼顯示為根 {#wrong-bone-appears-as-root}

**可能原因：**
- 階層沒有被更新
- 匯入問題
- 先前的設定不正確

**解決方式：**
- 點擊 Refresh Root
- 選取正確的骨骼
- 點擊 Set Root
- 確認變更已生效

### 設定根骨骼之後動畫壞掉 {#animations-break-after-setting-root}

**這很罕見，但有可能：**
- 部分動畫可能需要重新烘焙
- 動畫約束可能需要調整
- 通常動畫會自動適應

**解決方式：**
- 設定根骨骼前先儲存備份
- 變更後測試動畫
- 若壞掉，先復原並進一步調查

### 無法將特定骨骼設為根 {#cant-set-root-on-specific-bone}

**可能原因：**
- 骨骼被鎖定
- 骨骼上有約束阻擋
- 骨架處於編輯模式

**解決方式：**
- 切換到物件模式或姿態模式
- 若骨骼被鎖定則解除鎖定
- 移除阻擋的約束

## 理解骨骼階層 {#understanding-bone-hierarchy}

### 階層如何運作 {#how-hierarchies-work}

```
Root ("Armature" for VRC models) (top level)
├── Hips
│   ├── Spine
│   │   ├── Chest
│   │   │   ├── Neck
│   │   │   │   └── Head
│   │   │   ├── Shoulder.L
│   │   │   │   └── Arm.L
│   │   │   └── Shoulder.R
│   │   │       └── Arm.R
│   ├── Leg.L
│   └── Leg.R
```

- 每根骨骼只能有一個父系
- 每根骨骼可以有多個子系
- 根沒有父系

### 為什麼階層很重要 {#why-hierarchy-matters}

- **動畫：** 子骨骼會跟隨父骨骼的旋轉
- **IK：** 骨骼鏈需要正確的階層
- **VRChat：** 虛擬角色需要特定的階層
- **匯出：** Unity 需要正確的骨骼結構
