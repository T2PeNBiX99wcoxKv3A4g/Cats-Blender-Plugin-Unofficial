# 設定

設定與更新面板提供 Cats Blender Plugin 的組態選項與更新管理。

## 一般設定

### 匯出選項

#### 內嵌貼圖
- 將貼圖直接包含在匯出的檔案中
- 增加檔案大小
- 自包含的匯出檔
- 適合分享模型

**何時啟用：**
- 分享含貼圖的 FBX 檔案
- 單一檔案散佈
- 不需要另外管理貼圖

> **如果你是要為 UNITY／VRCHAT 製作東西，請不要內嵌貼圖，材質應該在 UNITY 中設定**

**何時停用：**
- 保持檔案大小精簡
- 在 Unity 中分開管理貼圖
- 更好的資源組織

#### 移除剛體／關節
- 在匯出期間清理物理
- 移除 MMD 物理資料
- 降低檔案複雜度
- 建議用於 VRChat 匯出

**何時啟用：**
- 匯出 MMD 模型
- 不需要物理資料
- 更乾淨的匯出檔

**何時停用：**
- 需要保留物理
- 在目標應用程式中使用物理

#### 匯出翻譯 CSV
- 在匯出期間產生翻譯檔
- 建立含名稱對應的 CSV
- 自 `5.2.4.0` 起包含 **source** 欄位：字典、MMD 作者名稱或線上服務
- 適合做為文件紀錄
- 翻譯的參考

**何時啟用：**
- 需要翻譯文件紀錄
- 想要檢視翻譯
- 建立模型文件

**何時停用：**
- 不需要翻譯紀錄
- 縮短匯出時間

#### 自訂匯出目錄
- 設定偏好的匯出儲存位置
- 記住你的選擇
- 更快的工作流程
- 井然有序的檔案管理

**設定方式：**
1. 點擊資料夾圖示
2. 瀏覽到想要的位置
3. 選擇資料夾
4. 之後的匯出都會預設儲存到這裡

## 語言設定

### 介面語言

Cats 的介面支援多種語言。

#### 可用語言

- **英文（en_US）** - 預設
- **日文（ja_JP）**
- **韓文（ko_KR）**
- 其他社群提供翻譯的語言

#### 變更語言

1. 從下拉選單選擇語言
2. 約兩秒後 Cats 會重新載入自己（僅 Cats，不會影響你的其他外掛）
3. UI 元素會更新為所選語言

不需要重新啟動 Blender。若標籤沒有改變，請重新啟動 Blender。

#### 自訂語言檔

Cats 支援自訂翻譯檔：
- 內附的檔案位於擴充功能內的 `resources/translations/`；**Download Latest Translations** 會將較新的副本存到 Cats [使用者資料資料夾](#settings-file-location)中的 `translations` 資料夾，且會優先使用這些檔案
- 損壞或下載一半的語言檔會被略過：Cats 會退回使用內附的副本，再退回英文，而不是載入失敗
- JSON 格式
- 社群可以貢獻翻譯
- 輕鬆加入新語言

### 翻譯管理

**翻譯檔結構：**
- 每種語言有一個 JSON 檔
- 包含 UI 字串的對應
- 易於編輯與擴充
- 為新語言提供範本

## 除錯選項

### 維護工具

#### 重設 Google 字典
- 清除快取的 Google 翻譯資料
- 若翻譯不正確時很有用
- 強制重新翻譯
- 可安全使用

**使用時機：**
- 翻譯看起來有問題
- 想要全新的翻譯資料
- 重大更新之後
- 疑難排解翻譯問題

**使用方式：**
1. 點擊 **Reset Google Dictionary**
2. 確認動作
3. 字典快取已清除

#### 翻譯除錯（開發分支）
- 在開發分支中提供
- 顯示翻譯過程的細節
- 有助於找出翻譯問題
- 供進階使用者／開發者使用

#### 系統快取清理
- 清除各種快取資料
- 重設暫存檔案
- 可協助解決奇怪的狀況
- 定期使用是安全的

**使用時機：**
- 外掛行為異常
- 更新之後
- 疑難排解無法解釋的問題

#### 組態重設選項
- 還原預設設定
- 清除自訂組態
- 回到全新安裝的狀態
- 設定損壞時使用

> ⚠ **警告：** 組態重設無法復原。你的自訂設定將會遺失。

## 更新管理

### 版本控制

#### 更新通知
- 自動檢查新版本
- 有更新可用時顯示
- 顯示於外掛介面中
- 不干擾的通知

**組態：**
- 啟用／停用更新檢查
- 設定檢查頻率
- 選擇通知樣式

#### 自動更新檢查
- Cats 載入時在背景執行一次
- 檢查 [GitHub](https://github.com/T2PeNBiX99wcoxKv3A4g/Cats-Blender-Plugin-Unofficial/releases) 上的發行版
- 與已安裝的版本進行比對
- 有更新可用時顯示更新按鈕

自 `5.3.1.0` 起，更新器會列出每個 Cats 發行版，而不只是針對你的 Blender 版本製作的版本，因為一個發行版可以支援一個以上的 Blender 版本。Blender 本身會檢查每個發行版支援的 Blender 範圍，並拒絕安裝你的 Blender 無法執行的版本。

**運作方式：**
1. Cats 檢查 GitHub 上的發行版清單
2. 比對版本號
3. 若有較新版本則通知
4. 提供下載連結

> **需要 Blender 的線上存取。** Cats 只在 **Edit > Preferences > System > Network > Allow Online Access** 開啟時才會檢查更新。關閉時，自動檢查會被無聲略過，而 **Check for Updates** 會顯示訊息告知你線上存取已停用。

#### 版本相容性資訊
- 顯示 Blender 版本是否受支援
- 對不相容的版本提出警告
- 建議正確的版本
- 避免安裝問題

#### 發行說明存取
- 檢視更新的變更紀錄
- 查看新功能
- 了解錯誤修正
- 從更新通知中存取

### 管理更新

#### 手動檢查更新

1. 開啟設定面板
2. 點擊 **Check for Updates**
3. 等待檢查完成
4. 若有更新可用，依照提示操作

#### 安裝更新

1. 從提供的連結下載新版本
2. 關閉 Blender
3. 移除舊版本：
   - 前往 Edit > Preferences > Extensions
   - 找到 Cats
   - 移除擴充功能
4. 重新啟動 Blender
5. 安裝新版本
6. 啟用擴充功能

> 📝 **注意：** 在移除舊版本與安裝新版本之間，務必重新啟動 Blender，以獲得最乾淨的安裝。

#### 瞭解版本號

Cats 使用三部分的語意化版本編號：

- **Major.Minor.Patch**（例如 `5.5.0`）
- **Major.Minor** 標示本延續版本所起始的 Blender 系列；同一個建置仍可安裝在所有受支援的 Blender 版本上
- **Patch** 合計發行次數、功能與修正

範例：

- `5.3.9` - 一個修補版發行
- `5.4.0` - 加入文件網站的發行版
- `5.5.0` - 在網站上加入所有 UI 語言的發行版

各發行版支援哪些 Blender 版本，請見[版本支援](Version-Support)。

## 設定最佳實務

### 匯出設定

**建議用於 VRChat：**
- ❌ 內嵌貼圖：關閉（在 Unity 中處理）
- ✅ 移除剛體／關節：開啟
- ❌ 匯出翻譯 CSV：關閉（除非有需要）
- ✅ 自訂匯出目錄：設為你的專案資料夾

**建議用於分享模型：**
- ✅ 內嵌貼圖：開啟（對收件者更方便）
- ✅ 移除剛體／關節：開啟
- ✅ 匯出翻譯 CSV：開啟（文件紀錄）
- ✅ 自訂匯出目錄：設為匯出資料夾

### 更新設定

**建議：**
- ✅ 啟用自動更新檢查
- ✅ 每天或每週檢查
- ✅ 更新前閱讀發行說明
- ✅ 重大更新前保留備份

### 語言設定

**獲得最佳體驗：**
- 若你覺得自在就使用英文（大多數文件為英文）
- 使用母語以更容易理解
- 回報缺少的翻譯以協助社群
- 檢查你的語言是否可用

## 設定疑難排解

### 設定沒有儲存

**可能原因：**
- 權限問題
- 偏好設定損壞
- Blender 未正確關閉

**解決方式：**
- 檢查資料夾權限
- 重設組態
- 手動儲存 Blender 偏好設定
- 必要時重新安裝

### 更新沒有顯示

**可能原因：**
- Blender 的 **Allow Online Access** 已關閉
- 更新檢查已停用
- 沒有網際網路連線
- 防火牆阻擋 github.com
- VPN 干擾
- 代理伺服器或安全軟體替換了 HTTPS 憑證（Cats 會驗證更新伺服器的憑證）

**解決方式：**
- 開啟 **Edit > Preferences > System > Network > Allow Online Access**
- 啟用更新檢查
- 檢查網際網路連線
- 在防火牆中允許 github.com
- 暫時停用 VPN
- 檢查系統主控台：`URL ERROR` 表示 Cats 無法連上更新伺服器，或其憑證不受信任

### 語言沒有改變

**可能原因：**
- Cats 的自動重新載入失敗（請在系統主控台檢查 `Cats reload failed`）
- 翻譯檔遺失
- 語言檔損壞（Cats 會退回使用內附檔案或英文）

**解決方式：**
- 完全重新啟動 Blender
- 確認翻譯檔存在
- 再次點擊 **Download Latest Translations**，或視需要重新安裝

## 設定檔位置

Cats 會將設定保存在自己的使用者資料資料夾中，在 Cats 更新後仍會保留。它是 Blender `extensions/.user` 目錄下的擴充功能資料夾（從磁碟安裝時，儲存庫部分通常是 `user_default`）：
- Windows：`%APPDATA%\Blender Foundation\Blender\5.x\extensions\.user\user_default\cats_blender_plugin\`
- macOS：`~/Library/Application Support/Blender/5.x/extensions/.user/user_default/cats_blender_plugin/`
- Linux：`~/.config/blender/5.x/extensions/.user/user_default/cats_blender_plugin/`

它包含：
- `settings.json` - 你的 Cats 設定，包括翻譯服務 API 金鑰
- `dictionary_google.json` - 線上翻譯的快取
- `dictionary.json` 與 `translations/` - 下載的字典與語言檔

你的設定是全域的：每次你開啟 `.blend` 時都會重新套用，因此以其他數值儲存的檔案不會覆寫它們。自 `5.3.1.0` 起，翻譯 API 金鑰、LibreTranslate URL 與 MyMemory 電子郵件**永遠不會寫入 `.blend` 檔案**，而舊版本存進檔案中的任何此類資料都會在檔案開啟時被移除。

> ⚠ **警告：** 手動編輯這些檔案可能會造成問題。請盡可能使用設定面板。

## 與 Blender 偏好設定的整合

Cats 會遵循 Blender 的偏好設定：
- 檔案路徑
- 語言設定（盡可能）
- 介面縮放
- 主題設定

Cats 載入時**不會**變更你的 Blender 偏好設定。較舊的版本會開啟檔案壓縮並變更外掛支援篩選器；自 `5.3.1.0` 起，你的偏好設定會完全保持你設定的樣子。

- ✅ 重大組態重設
- ❌ 匯出選項（立即生效）
- ❌ 更新檢查（立即生效）
