# UV 工具

**UV 工具**（UV Tools）是 `5.2.3.0` 中新增的面板，內含 UV 編輯的輔助工具。它包含兩個工具：**Align UV Edges to Target** 與 **Find Shortest Seam Path**。

## 在哪裡找到它

- 完整面板位於 **UV／影像編輯器**的側邊面板（N 面板）中，在 **CATS** 分頁底下。請開啟 UV 編輯器才能看到它。
- **Find Shortest Seam Path** 也同步出現在 **3D 視圖** 的 CATS 分頁中（位於「UV Tools」底下），因為那才是你實際選取頂點的地方。

*Align UV Edges* 僅限於 UV 編輯器，它需要 UV 編輯器的 2D 游標與選取範圍。

---

## 對齊 UV 邊至目標

重塑每個所選網格上一條選取的 UV 點連線，使其跟隨**作用中**網格上選取的 UV 點連線。這對於**拼裝（kitbashing）**非常有用，可讓一個模型的 UV 版面與另一個相符，使它們的貼圖對齊。

**2D 游標**標示每條連線的「起點」是哪一端，因此所有連線都會以相同方向行進，之後才沿著目標插值這些點。

### 使用方式

1. 在 UV 編輯器中，將 **UV Sync Selection 關閉**。
2. 選取所有相關的網格，**作用中**的那個就是*目標*。
3. 進入**編輯模式**，並在每個網格上選取一條相符的 **UV 邊線**。
4. 將 **2D 游標**放在這些連線的起點端附近。
5. 按下 **Align UV Edges to Target**。

> 每個所選網格都需要恰好一條乾淨的已選取 UV 點連線。若選取範圍有分支或不是單一連線，Cats 會提出警告。

---

## 尋找最短路徑接縫

選取連接兩個所選頂點的最短**接縫**邊路段。方便快速選取一圈接縫來處理。

它只沿著標記為接縫的邊行走（廣度優先搜尋），因此結果永遠是你的兩個點之間邊數最少的路徑。

### 使用方式

1. 在你的網格上進入**編輯模式**。
2. 選取**恰好兩個頂點**，各自位於接縫上。
3. 按下 **Find Shortest Seam Path**（UV 編輯器與 3D 視圖的 CATS 分頁都提供）。

路徑上的邊會被選取，模式也會切換為邊選取。若這兩個頂點沒有透過接縫相連，Cats 會告知找不到路徑。
