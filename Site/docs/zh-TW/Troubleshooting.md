# 疑難排解

Cats Blender Plugin 的常見問題與解決方式。

## 快速疑難排解

> 💡 **第一步：** 在深入特定問題之前：
> 1. 確認你使用的是 **Blender 4.2 LTS 或更新版本**
> 2. 確認你有**最新版本的 Cats**
> 3. 在安裝／更新 Cats 之後**重新啟動 Blender**
> 4. 檢查 Cats 在擴充功能偏好設定中是**啟用**的

---

## 安裝問題

### 安裝後擴充功能沒有出現

**症狀：**
- 已安裝 Cats 但找不到它
- 側邊欄沒有 Cats 分頁
- 擴充功能不在清單中

**解決方式：**

1. **檢查是否已啟用：**
   - Edit > Preferences > Extensions
   - 搜尋「Cats」
   - 確認勾選框已勾選

2. **重新啟動 Blender：**
   - 完全關閉 Blender
   - 重新開啟 Blender
   - 再次檢查

3. **確認安裝：**
   - 確認你安裝的是 ZIP 檔案（不要解壓縮）
   - 確認你使用了「Install from Disk」
   - 檢查你下載的是適用於 Blender 5.2 / 5.3 的 Cats 版本

4. **檢查 Blender 版本：**
   - Help > About Blender
   - 必須是 4.2 LTS 或更新版本
   - 為你的 Blender 下載正確的 Cats 版本

5: **按 N 確認側邊欄已開啟**

### 安裝時出現錯誤

**可能原因：**
- Cats 版本與你的 Blender 不相符
- 下載檔案損毀
- 權限問題
- 擴充功能衝突

**解決方式：**

1. **確認版本相符：**
   - Blender 4.2 LTS 到 5.4 都可執行目前的 Cats 發行版；Blender 4.1 及更舊版本無法載入此擴充功能
   - 讓你的 Cats 版本與 Blender 版本相符（請見[版本支援](Version-Support)）

2. **重新下載：**
   - 刪除未完成的下載
   - 下載全新的副本
   - 確認檔案沒有損毀

3. **檢查權限：**
   - 確認 Blender 可寫入擴充功能資料夾
   - 以系統管理員身分執行 Blender（Windows）
   - 檢查資料夾權限

4. **移除衝突的擴充功能：**
   - 舊的 Cats 版本
   - 不相容的外掛（例如 MMD Tools，Cats 內附最新的 MMD Tools，兩者會互相衝突）
   - 移除後重新啟動

### 側邊欄中看不到 Cats 分頁

**解決方式：**

1. **按 N：**
   - 在 3D 視埠中按 **N** 鍵
   - 切換側邊欄的可見性

2. **尋找 Cats 分頁：**
   - 檢查側邊欄中的所有分頁
   - 應該會看到「Cats」分頁
   - 點擊以開啟

3. **確認擴充功能已啟用：**
   - Edit > Preferences > Extensions
   - 找到 Cats
   - 檢查啟用勾選框

## 匯入／匯出問題

### 模型無法匯入

**症狀：**
- 匯入按鈕沒有反應
- 匯入期間出現錯誤訊息
- Blender 當機

**解決方式：**

1. **檢查檔案格式：**
   - 確認是支援的格式（.pmx、.pmd、.fbx、.vrm 等）
   - 檔案沒有損毀
   - 檔案大小合理

2. **檢查檔案路徑：**
   - 路徑中沒有特殊字元
   - 路徑不要太長
   - 檔案沒有被其他程式占用

3. **試試 Blender 原生的匯入器：**
   - File > Import
   - 若該方式也失敗，檔案可能已損毀

4. **檢查主控台是否有錯誤：**
   - Window > Toggle System Console
   - 尋找錯誤訊息
   - 回報具體的錯誤

## 模型顯示問題

### 模型顯示為黑色或沒有貼圖

**症狀：**
- 模型全黑
- 貼圖沒有顯示
- 材質看起來不對

**解決方式：**

1. **切換視埠著色：**
   - 按 Z 鍵
   - 選擇「Material Preview」或「Rendered」
   - 「Solid」模式可能不會顯示貼圖

2. **檢查材質屬性：**
   - 選取網格
   - 開啟材質屬性面板
   - 確認材質存在
   - 檢查貼圖是否已載入

3. **貼圖路徑：**
   - 材質可能參照到遺失的貼圖
   - 視需要重新連結貼圖
   - 使用 Blender 中的「Find Missing Files」

4. **建立圖集之後：**
   - 圖集材質是單純的 Principled BSDF，toon／MToon 的外觀不會被保留
   - 請在 Unity 中正確設定材質
   - 請見[圖集產生器問題](#atlas-generator-issues)

### 模型內翻／裡外顛倒

**症狀：**
- 網格看起來裡外顛倒
- 顯示背面
- 著色看起來不對

**解決方式：**

1. **重新計算法線：**
   - [最佳化 → 網格清理](Optimization#mesh-cleanup)面板
   - 點擊「Recalculate Normals」

2. **在編輯模式中檢查：**
   - 按 Tab 進入編輯模式
   - 啟用面朝向（覆疊）
   - 藍色 = 正確，紅色 = 內翻

3. **必要時翻轉法線：**
   - 選取所有面
   - 使用網格清理中的「Flip Normals」
   - 僅在整個網格都內翻時使用

### 在 VRChat／Unity 中比例錯誤

**症狀：**
- 虛擬角色太大或太小
- 不在預期的身高
- 比例錯誤

**解決方式：**

1. **在 Blender 中檢查比例：**
   - 使用[縮放](Scaling)面板
   - 測量實際身高
   - 縮放到正確的大小（建議 160-180cm）

2. **套用變換：**
   - [最佳化 → 網格清理](Optimization#mesh-cleanup)
   - 「Apply Transformations」
   - 在匯出前執行

3. **Unity 匯入縮放：**
   - FBX 應為 1.0
   - 檢查 Unity 中的匯入設定
   - 不要在 Unity 中縮放，請在 Blender 中縮放

## 功能特定問題

### 眼動追蹤沒有作用

**症狀：**
- 眼睛不會移動
- 眨眼沒有作用
- 設定似乎壞掉了

**解決方式：**

1. **確認骨骼選擇：**
   - [眼動追蹤](Eye-Tracking)面板
   - 檢查是否已選取頭部、左眼、右眼骨骼
   - 使用正確的骨骼

2. **檢查權重繪製：**
   - 眼睛必須權重給眼球骨骼
   - 建議 100% 權重
   - 不要有權重滲漏

3. **在 Blender 中測試：**
   - 使用眼動追蹤面板中的測試控制項
   - 確認眼睛會移動
   - 檢查眨眼形態鍵

4. **材質／圖集順序：**
   - 你是否在眼動追蹤**之後**才合併材質或做圖集？
   - 請在材質合併與圖集製作**之後**再設定眼動追蹤
   - 可能需要重做設定

### 視素沒有作用

**症狀：**
- 嘴型對嘴時嘴巴不會動
- 形態鍵未指定
- 預覽沒有顯示動作

**解決方式：**

1. **檢查形態鍵指派：**
   - [視素](Visemes)面板
   - 確認已指派 Mouth A、O、CH
   - 使用正確的形態鍵

2. **確認形態鍵存在：**
   - 選取網格
   - 開啟形態鍵面板
   - 確認嘴部形態鍵存在

3. **用預覽測試：**
   - 使用視素面板中的預覽
   - 逐一檢查每個視素
   - 視需要調整強度

4. **翻譯問題：**
   - 在設定視素之前翻譯形態鍵
   - 不要在設定之後翻譯
   - 可能會破壞參照

### 骨骼合併造成問題

**症狀：**
- 骨骼合併後模型壞掉
- 權重看起來不對
- 動畫損壞

**解決方式：**

1. **檢查合併設定：**
   - [最佳化](Optimization)面板
   - 從較低的合併比例（0.5）開始
   - 為安全起見啟用「Keep Merged Bones」

2. **在清理前先測試：**
   - 先合併骨骼
   - 徹底測試
   - 只有在合併結果良好時才進行清理

3. **之後確認骨架：**
   - 檢查骨骼階層
   - 測試動畫
   - 確認權重看起來正確

4. **必要時復原：**
   - 用 Ctrl+Z 復原
   - 嘗試不同的設定
   - 或從備份繼續

## 圖集產生器問題

> 💡 舊的 **Atlas Generator (Legacy)** 面板（Material Combiner）已於 **`5.3.1.0` 中移除**，隨之而去的還有所有 Pillow 與 Material Combiner 的安裝問題。內建的[圖集產生器](Optimization#atlas-generator)不需要安裝任何東西。它仍標示為 alpha，因此若它行為異常，請附上它在 Blender 資訊日誌中印出的那一行來回報。

### 我找不到 Atlas Generator (Legacy)／Material Combiner

舊面板已不存在。請改用 **Optimization > Atlas Generator**。若仍安裝 Material Combiner，它的 **Import Material Combiner Settings** 按鈕會把你舊的圖集設定、材質勾選與圖層複製過來。Material Combiner 本身是第三方外掛，Cats 已不再支援它。

### 圖集中的貼圖遺失或錯誤

**可能原因：**
- Cats 無法透過著色器找到材質的貼圖（該列會顯示 ⚠ 圖示）
- 程序化、混合或頂點著色的材質沒有單一影像
- 磁碟上的貼圖檔案遺失

**解決方式：**
1. 為標示 ⚠ 的材質開啟 **Bake**，讓 Cycles 改為算繪它們
2. 重新連結遺失的貼圖（File > External Data > Find Missing Files）
3. 使用 **Preview Result** 在實際建置前檢查將會封裝什麼

### 圖集顏色看起來太暗

`5.3.1.0` 之前的建置會把純色與著色材質寫得太暗。請更新 Cats 並重新建置圖集；顏色現在會與視埠一致。

### 建立第二個圖集更動了我的第一個圖集

`5.3.1.0` 之前的建置會重複使用 `Cats_Atlas_01`／`Cats_Atlas_Mat_01` 這些名稱，因此在同一檔案中為第二個虛擬角色做圖集會覆蓋第一個。現在每次建置都有自己的名稱（`Cats_Atlas_01_2` 等）。更新後請重新建置受影響的圖集。

### 重新開啟檔案後圖集消失了

使用 **Save to Folder** 且資料夾為空或不可寫入時，`5.3.1.0` 之前的建置既沒有儲存也沒有封裝圖集，因此重新載入後它就不見了。現在儲存失敗時圖集會封裝進 `.blend`，而且建置會警告你。請設定可寫入的**資料夾**以取得 PNG 檔案。

### 烘焙問題

- **「cannot be baked」錯誤：** 該物件不在目前的視圖層中，例如它位於被排除的集合裡。請納入該集合，或取消勾選該物件的材質
- **頂點色被覆蓋：** 當 Blender 的烘焙輸出設為 Color Attributes 時，`5.3.1.0` 之前的建置會烘焙到色彩屬性中。烘焙現在一律以影像貼圖為目標；請復原或從備份還原頂點色
- **某個烘焙材質在數個物件中的其中一個上顯示錯誤：** 已在 `5.3.1.0` 修正，共用烘焙材質的物件現在會一起烘焙

## 效能問題

### Cats 操作非常慢

**症狀：**
- 工具需要數分鐘才能完成
- 操作期間停滯或凍結

**可能原因：**
- 模型非常複雜
- 物件／網格很多
- 電腦較慢

**解決方式：**

1. **耐心等待：**
   - 複雜的操作需要時間
   - Cats 正在運作
   - 檢查主控台以了解進度

2. **先簡化：**
   - 移除不必要的物件
   - 在操作前合併網格
   - 先清理模型

3. **關閉其他程式：**
   - 釋放記憶體
   - 關閉瀏覽器等
   - 把資源留給 Blender

## 錯誤訊息

### 「No Armature Selected」

**解決方式：**
- 選取你的骨架物件
- 必須選取骨架，而不是網格
- 在物件模式中

### 「No Mesh Found」

**解決方式：**
- 確保網格存在
- 網格必須以骨架為父系
- 檢查物件可見性

### 「Shape Keys Not Found」

**解決方式：**
- 確認網格有形態鍵
- 檢查是否選取了正確的網格
- 視素／眼動追蹤必須有形態鍵存在

### 「Bone Not Found」

**解決方式：**
- 確認骨骼名稱
- 重新整理骨骼清單
- 檢查骨架中是否存在該骨骼

### 政策違規警告（Blender 5.2 / 5.3）

**症狀：**
- 關於擴充功能政策的警告
- 關於舊式方法的警示

**這是預期中的行為：**
- Cats 使用舊式方法載入第三方外掛
- 警告可以安全忽略
- 一切仍會正常運作
- 不需要採取任何行動

## 取得更多協助

### 發問之前

1. **查看本頁：** 許多問題都涵蓋在這裡
2. **閱讀相關的 Wiki 頁面：** 各功能的專屬指南
3. **嘗試搜尋：** 儲存庫中既有的 issue
4. **確認版本：** 使用受支援的 Blender 5.2+

### 發問時

請包含：
- Blender 版本（確切版本）
- Cats 版本
- 你試著要做什麼
- 實際上發生了什麼
- 錯誤訊息（確切文字）
- 相關的截圖
- 若有的話，主控台輸出

### 在哪裡取得協助

- **儲存庫 issues：** 錯誤回報與問題
- **GitHub Issues：** 錯誤回報與功能請求
- **本 Wiki：** 文件與指南

### 什麼不要回報

- 不受支援的 Blender 版本，或非 blender.org／Steam 版本的 Blender 所產生的問題（5.2 之前的版本都不受支援）
- 第三方擴充功能問題（Material Combiner 等；Cats 已不再與 Material Combiner 整合）
- 一般 Blender 問題（請使用 Blender 論壇）
- 未先討論的功能請求

## 常見工作流程問題

### 操作順序錯誤

**許多問題都源自錯誤的順序：**

**正確順序：**
1. 匯入模型
2. 修復 MMD（若為 MMD 模型，僅限全新匯入）
3. 翻譯名稱
4. 視需要套用變換
5. **合併材質／建立圖集**
6. **設定眼動追蹤**
7. **設定視素**
8. 最終最佳化
9. 匯出

**重點：** 合併材質／建立圖集必須在眼動追蹤與視素**之前**完成！

### 備份管理

**永遠保留備份：**
- 重大操作之前
- 完成各階段之後
- 儲存增量版本
- 若可能，使用版本控制

**良好的備份習慣：**
```
my_model_01_import.blend
my_model_02_fixed.blend
my_model_03_optimized.blend
my_model_04_rigged.blend
my_model_05_final.blend
```
