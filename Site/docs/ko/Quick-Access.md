# 빠른 액세스

**빠른 액세스** 패널은 최상단 패널이며 시작점입니다. 가장 일반적인 작업을 모아 둡니다: 빠른 메시 작업, 가져오기/내보내기, **MMD 모델 수정**, 포즈 모드.

## 패널 구성 (위에서 아래로)

1. **업데이트 / 버전 알림** (해당될 때만 표시됨)
2. **빠른 작업**  머티리얼 결합, 모든 메시 결합
3. **가져오기 / 내보내기**
4. **아마추어 선택기** (아마추어가 두 개 이상일 때 표시됨)
5. **MMD 모델 수정** (+ 설정 기어)
6. **포즈 모드**

---

## 빠른 작업

빠른 원클릭 작업으로, 상단에 유지됩니다:

- **머티리얼 결합** - 속성이 일치하는 머티리얼을 병합하여 드로우 콜을 줄입니다.
- **모든 메시 결합** - 모든 메시를 하나의 오브젝트로 결합합니다 (머티리얼, 버텍스 그룹, 웨이트 유지).

> ⚠ 모든 메시 결합은 영구적이므로 먼저 저장하세요.

---

## 모델 가져오기

VRChat 워크플로에 적합한 설정으로 모델을 가져옵니다.

### 지원 형식

- **MMD:** `.pmx`, `.pmd`
- **XNALara:** `.xps`, `.mesh`, `.ascii`
- **Source Engine:** `.smd`, `.qc`, `.vta`, `.dmx`
- **VRM:** `.vrm`
- **glTF / GLB:** `.gltf`, `.glb`
- **FBX:** `.fbx`
- **DAE:** `.dae` (Collada)
- **ZIP:** `.zip` (압축된 모델 패키지)

> 다른 형식도 작동할 수 있지만, 위의 형식이 완전히 지원되는 형식입니다.

**가져오는 방법:** **모델 가져오기**를 클릭하고 파일을 선택한 후 가져옵니다. Cats가 최적 설정을 자동으로 적용합니다.

---

## 모델 내보내기

- **Unity용 FBX** - Unity/VRChat에 적합한 스케일, 회전, 아마추어 설정으로 내보냅니다.
- **Resonite (glTF)** - Resonite용 glTF 2.0으로 내보냅니다.

**내보내는 방법:** 해당 내보내기 버튼을 클릭하고 위치를 선택한 후 저장합니다.

## MMD 모델 수정

**MMD 모델 수정** 버튼(옆에 **⚙ 설정 기어**가 있음)은 쉽게 찾을 수 있도록 여기 상단에 있습니다. 새로 가져온 MMD/VRM을 Unity/VRChat에서 사용할 수 있는 리그로 변환합니다.

> ⚠ **새로 가져온 MMD / VRM 모델 전용입니다.** 이미 Unity/VRChat용으로 설정된 모델, 스토어에서 구매한 모델 또는 직접 만든 사용자 지정 빌드에는 실행하지 **마세요**. 동일한 경고가 패널의 버튼 바로 위에도 표시됩니다.

> 🚫 **이 경고를 무시하는 것은 본인의 책임입니다.** Cats와 이 위키가 제공한 모든 경고를 무시하고 새로 가져온 MMD/VRM이 아닌 대상에 MMD 모델 수정을 실행한다면, 그 결과는 전적으로 본인 책임입니다. **이에 대한 이슈를 열지 마세요.** 즉시 이 경고들을 다시 안내받고 이슈는 바로 닫힙니다.

버튼이 수행하는 모든 작업과 기어 뒤의 설정을 포함한 전체 세부 내용은 [변환기](Converters) 페이지에 있습니다 (MMD 모델 수정은 MMD 정리 섹션에도 나타납니다).

## 포즈 모드

포즈 모드에 들어가 아마추어를 조작합니다.

- **포즈 모드 시작** - 포즈 모드에 들어갑니다 (작은 버튼은 현재 포즈를 *초기화하지 않고* 시작합니다).
- 포즈 모드에 있는 동안:
  - **포즈 모드 중지** - (작은 버튼은 초기화하지 않고 중지합니다)
  - **포즈를 셰이프 키로** - 현재 포즈를 새로운 셰이프 키로 베이크합니다 (사용자 지정 표정에 유용)
  - **레스트 포즈로 적용** - 현재 포즈를 아마추어의 레스트 포즈로 설정합니다

> ⚠ 레스트 포즈로 적용은 레스트 포즈를 영구적으로 변경하므로 먼저 저장하세요.

## 일반적인 워크플로

1. 모델을 **가져옵니다**.
2. 새로 가져온 MMD/VRM이라면 **MMD 모델 수정**을 실행합니다.
3. 이름을 **번역**합니다 ([번역](Translation)).
4. 최적화하고([최적화](Optimization)), [눈 추적](Eye-Tracking)과 [입 모양](Visemes)을 설정합니다.
5. 대상 플랫폼용으로 **내보냅니다**.
