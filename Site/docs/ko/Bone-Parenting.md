# 본 페어런팅 {#bone-parenting}

본 페어런팅 패널은 아마추어의 루트 본을 관리하고 설정하는 데 도움을 주며, 이는 올바른 모델 리깅과 애니메이션에 필수적입니다.

## 루트 본이란? {#what-is-a-root-bone}

루트 본은 아마추어 계층 구조의 최상위 부모 본입니다.
- 다른 모든 본은 (직접 또는 간접적으로) 루트의 자식입니다
- 모델의 전체 위치와 회전을 제어합니다
- 올바른 애니메이션에 필수적입니다
- VRChat 아바타에 필요합니다

## 루트 본이 중요한 이유 {#why-root-bones-matter}

올바르게 설정된 루트 본은 다음을 보장합니다.
- 게임 내에서의 올바른 모델 동작
- 올바른 애니메이션 재생
- 올바른 IK(Inverse Kinematics) 동작
- VRChat 호환성

## 루트 본 선택 {#root-bone-selection}

패널에는 루트 본으로 사용할 수 있는 본들이 표시됩니다.

### 루트 본 선택하기 {#choosing-a-root-bone}

**일반적으로 루트 본은 다음과 같습니다.**
- 모델의 중심에 위치합니다
- "Root", "Hips", "Armature" 등으로 명명됩니다
- 월드 공간 기준으로 절대 움직이지 않아야 하는 본입니다
- 척추/엉덩이 본의 부모입니다

**일반적인 루트 본 이름:**
- Root
- Hips
- Armature
- Hip
- pelvis
- root_bone

---

## 주요 기능 {#main-actions}

### 루트 새로 고침 {#refresh-root}

루트 본 목록과 계층 구조 정보를 업데이트합니다.

**사용 시점:**
- 모델을 가져온 후
- 아마추어를 수정한 후
- 아마추어를 병합한 후
- 본 목록이 오래된 것처럼 보일 때

**사용 방법:**
1. **루트 새로 고침**을 클릭합니다
2. 목록이 업데이트될 때까지 기다립니다
3. 사용 가능한 루트 본을 확인합니다

### 루트 설정 {#set-root}

선택한 본을 아마추어의 루트로 설정합니다.

**수행하는 작업:**
- 본 계층 구조를 재구성합니다
- 올바른 페어런팅을 설정합니다
- 선택한 본이 최상위에 오도록 합니다
- 아마추어 구조를 업데이트합니다

**사용 방법:**
1. 목록에서 원하는 본을 선택합니다
2. **루트 설정**을 클릭합니다
3. Blender의 본 뷰에서 계층 구조를 확인합니다

---

## 워크플로 {#workflow}

### 루트 본 설정하기 (새 모델) {#setting-up-root-bone-new-model}

1. **모델을 가져옵니다**
2. **본 페어런팅 패널을 엽니다**
3. **루트 새로 고침을 클릭합니다**
4. **사용 가능한 본을 확인합니다**
5. **적절한 루트 본을 선택합니다**
6. **루트 설정을 클릭합니다**
7. **계층 구조를 확인합니다**

### 루트 본 문제 해결하기 {#fixing-root-bone-issues}

모델의 루트가 잘못된 경우:

1. **올바른 본을 확인합니다** (보통 Hips 또는 Root)
2. **루트 새로 고침을 클릭합니다**
3. **올바른 본을 선택합니다**
4. **루트 설정을 클릭합니다**
5. **애니메이션을 테스트합니다**
6. **변경 사항을 저장합니다**

### 아마추어 병합 후 {#after-armature-merging}

[병합 및 부착](./Merge-and-Attach.md)를 사용한 후:

1. **루트 새로 고침**으로 계층 구조를 업데이트합니다
2. **루트가 올바른지 확인합니다**
3. 필요하면 **루트 설정**을 합니다
4. **병합된 본의 페어런팅이 올바른지 확인합니다**

## 사용 사례 {#use-cases}

### VRChat용 모델 준비 {#preparing-model-for-vrchat}

1. 모델 가져오기
2. MMD 모델 수정 (필요한 경우 MMD 및 VRM 모델에만 사용)
3. **올바른 루트 본 설정**
4. 눈 추적 및 입 모양(Viseme) 구성
5. 내보내기

### 가져온 모델 수정 {#fixing-imported-models}

일부 가져오기 도구는 루트를 올바르게 설정하지 않습니다.

1. 모델이 잘못된 위치에 나타납니다
2. 애니메이션이 제대로 작동하지 않습니다
3. **해결책:** 올바른 루트 본을 설정합니다

### 모델 병합 후 {#after-merging-models}

아마추어를 결합할 때:

1. 병합된 아마추어의 계층 구조가 꼬일 수 있습니다
2. **루트 새로 고침 및 루트 설정**으로 해결합니다
3. 깔끔한 본 구조를 보장합니다

### 사용자 지정 리그 만들기 {#creating-custom-rigs}

사용자 지정 리그를 만들 때:

1. 본을 생성합니다
2. 시작할 때 **루트 설정**을 합니다
3. 루트에서부터 계층 구조를 구축합니다
4. 구조가 정리된 상태로 유지됩니다

## 모범 사례 {#best-practices}

### 루트 본 선택 {#choosing-root-bone}

**해야 할 것:**
- ✅ 중심이 되는 주요 본을 선택합니다
- ✅ 캐릭터 중심의 본을 고릅니다
- ✅ 휴머노이드 리그에는 Hips를 사용합니다
- ✅ 논리적으로 타당한지 확인합니다

**하지 말아야 할 것:**
- ❌ 끝단 본(손가락, 발가락)을 선택하지 마세요
- ❌ 헬퍼 본을 선택하지 마세요
- ❌ 독립적으로 움직여야 하는 본을 고르지 마세요
- ❌ 임의의 본을 사용하지 마세요

### 새로 고침 시점 {#when-to-refresh}

**다음 후에 루트 새로 고침을 수행하세요:**
- 모델 가져오기
- 아마추어 병합
- 본 추가 또는 삭제
- 아마추어 복제
- 주요 계층 구조 변경

### 루트 설정 후 {#after-setting-root}

**항상 확인하세요:**
1. 편집 모드에서 아마추어를 엽니다
2. 본 계층 구조를 확인합니다 (Shift-클릭으로 부모를 확인)
3. 루트 본에 부모가 없는지 확인합니다
4. 다른 본이 루트로 이어지는지 확인합니다
5. 포즈 모드에서 모든 것이 올바르게 움직이는지 테스트합니다

## 일반적인 문제 {#common-issues}

### 루트 본 목록이 비어 있음 {#root-bone-list-is-empty}

**가능한 원인:**
- 선택된 아마추어가 없음
- 아마추어에 본이 없음
- 패널 새로 고침 필요

**해결 방법:**
- 아마추어 오브젝트를 선택합니다
- 루트 새로 고침을 클릭합니다
- 아마추어에 본이 있는지 확인합니다

### 잘못된 본이 루트로 표시됨 {#wrong-bone-appears-as-root}

**가능한 원인:**
- 계층 구조가 업데이트되지 않음
- 가져오기 문제
- 이전 설정이 잘못됨

**해결 방법:**
- 루트 새로 고침을 클릭합니다
- 올바른 본을 선택합니다
- 루트 설정을 클릭합니다
- 변경 사항이 적용되었는지 확인합니다

### 루트 설정 후 애니메이션이 깨짐 {#animations-break-after-setting-root}

**드문 경우이지만 가능합니다:**
- 일부 애니메이션은 다시 베이킹해야 할 수 있습니다
- 애니메이션 제약 조건을 조정해야 할 수 있습니다
- 보통 애니메이션은 자동으로 적응합니다

**해결 방법:**
- 루트를 설정하기 전에 백업을 저장합니다
- 변경 후 애니메이션을 테스트합니다
- 깨진 경우 실행 취소하고 추가로 조사합니다

### 특정 본에 루트를 설정할 수 없음 {#cant-set-root-on-specific-bone}

**가능한 원인:**
- 본이 잠겨 있음
- 본에 이를 방해하는 제약 조건이 있음
- 아마추어가 편집 모드에 있음

**해결 방법:**
- 오브젝트 모드 또는 포즈 모드로 전환합니다
- 본이 잠겨 있으면 잠금을 해제합니다
- 방해하는 제약 조건을 제거합니다

## 본 계층 구조 이해하기 {#understanding-bone-hierarchy}

### 계층 구조의 동작 방식 {#how-hierarchies-work}

```
Root ("Armature" for VRC models) (top level)
├── Hips
│   ├── Spine
│   │   ├── Chest
│   │   │   ├── Neck
│   │   │   │   └── Head
│   │   │   ├── Shoulder.L
│   │   │   │   └── Arm.L
│   │   │   └── Shoulder.R
│   │   │       └── Arm.R
│   ├── Leg.L
│   └── Leg.R
```

- 각 본은 하나의 부모를 가질 수 있습니다
- 각 본은 여러 개의 자식을 가질 수 있습니다
- 루트에는 부모가 없습니다

### 계층 구조가 중요한 이유 {#why-hierarchy-matters}

- **애니메이션:** 자식은 부모의 회전을 따라갑니다
- **IK:** 본 체인에는 올바른 계층 구조가 필요합니다
- **VRChat:** 아바타에 대해 특정 계층 구조를 기대합니다
- **내보내기:** Unity에는 올바른 본 구조가 필요합니다
