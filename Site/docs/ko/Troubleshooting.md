# 문제 해결

Cats Blender Plugin의 일반적인 문제와 해결 방법입니다.

## 빠른 문제 해결

> 💡 **첫 단계:** 특정 문제를 파고들기 전에:
> 1. **Blender 4.2 LTS 이상**을 사용하고 있는지 확인하세요
> 2. **최신 버전의 Cats**가 설치되어 있는지 확인하세요
> 3. Cats를 설치/업데이트한 후 **Blender를 재시작**하세요
> 4. Extensions 환경 설정에서 Cats가 **활성화**되어 있는지 확인하세요

---

## 설치 문제

### 설치 후 확장 기능이 나타나지 않음

**증상:**
- Cats를 설치했지만 찾을 수 없음
- 사이드바에 Cats 탭이 없음
- 목록에 확장 기능이 없음

**해결 방법:**

1. **활성화 여부 확인:**
   - Edit > Preferences > Extensions
   - "Cats" 검색
   - 체크박스가 선택되어 있는지 확인

2. **Blender 재시작:**
   - Blender를 완전히 종료
   - Blender 다시 열기
   - 다시 확인

3. **설치 확인:**
   - ZIP 파일을 설치했는지 확인 (압축을 풀지 마세요)
   - "Install from Disk"를 사용했는지 확인
   - Blender 5.2 / 5.3용 Cats 버전을 다운로드했는지 확인

4. **Blender 버전 확인:**
   - Help > About Blender
   - 4.2 LTS 이상이어야 함
   - Blender에 맞는 올바른 Cats 버전 다운로드

5: **N을 눌러 사이드바가 열려 있는지 확인하세요**

### 설치 중 오류 발생

**가능한 원인:**
- Blender 버전에 맞지 않는 Cats 버전
- 손상된 다운로드
- 권한 문제
- 충돌하는 확장 기능

**해결 방법:**

1. **버전 일치 확인:**
   - Blender 4.2 LTS부터 5.4까지 모두 현재 Cats 릴리스를 실행할 수 있으며, Blender 4.1 이하는 확장 기능을 로드할 수 없음
   - Cats 버전을 Blender 버전에 맞추세요 ([버전 지원](Version-Support) 참조)

2. **다시 다운로드:**
   - 부분 다운로드 삭제
   - 새 사본 다운로드
   - 파일이 손상되지 않았는지 확인

3. **권한 확인:**
   - Blender가 확장 기능 폴더에 쓸 수 있는지 확인
   - Blender를 관리자로 실행 (Windows)
   - 폴더 권한 확인

4. **충돌하는 확장 기능 제거:**
   - 구 Cats 버전
   - 호환되지 않는 애드온 (MMD Tools 같은 것. Cats에는 최신 MMD Tools가 포함되어 있어 서로 충돌합니다)
   - 제거 후 재시작

### 사이드바에 Cats 탭이 보이지 않음

**해결 방법:**

1. **N 누르기:**
   - 3D 뷰포트에서 **N** 키를 누릅니다
   - 사이드바 표시를 전환합니다

2. **Cats 탭 찾기:**
   - 사이드바의 모든 탭 확인
   - "Cats" 탭이 보여야 함
   - 클릭하여 엽니다

3. **확장 기능 활성화 확인:**
   - Edit > Preferences > Extensions
   - Cats 찾기
   - 활성화 체크박스 확인

## 가져오기/내보내기 문제

### 모델을 가져올 수 없음

**증상:**
- 가져오기 버튼이 아무 동작도 하지 않음
- 가져오기 중 오류 메시지
- Blender 충돌

**해결 방법:**

1. **파일 형식 확인:**
   - 지원되는 형식인지 확인 (.pmx, .pmd, .fbx, .vrm 등)
   - 파일이 손상되지 않았는지
   - 파일 크기가 적절한지

2. **파일 경로 확인:**
   - 경로에 특수 문자 없음
   - 경로가 너무 길지 않음
   - 파일이 다른 프로그램에서 사용 중이 아님

3. **Blender 기본 가져오기 도구 시도:**
   - File > Import
   - 이것도 실패하면 파일이 손상되었을 수 있음

4. **콘솔에서 오류 확인:**
   - Window > Toggle System Console
   - 오류 메시지 확인
   - 구체적인 오류 보고

## 모델 표시 문제

### 모델이 검게 보이거나 텍스처가 없음

**증상:**
- 모델이 전부 검은색
- 텍스처가 표시되지 않음
- 머티리얼이 잘못되어 보임

**해결 방법:**

1. **뷰포트 셰이딩 전환:**
   - Z 키를 누릅니다
   - "Material Preview" 또는 "Rendered" 선택
   - "Solid" 모드는 텍스처를 표시하지 않을 수 있음

2. **머티리얼 속성 확인:**
   - 메시 선택
   - 머티리얼 속성 패널 열기
   - 머티리얼이 있는지 확인
   - 텍스처가 로드되었는지 확인

3. **텍스처 경로:**
   - 머티리얼이 누락된 텍스처를 참조할 수 있음
   - 필요하면 텍스처를 다시 연결
   - Blender의 "Find Missing Files" 사용

4. **아틀라스 생성 후:**
   - 아틀라스 머티리얼은 단순한 Principled BSDF이며 툰/MToon 모양은 유지되지 않음
   - Unity에서 머티리얼을 올바르게 설정
   - [아틀라스 생성기 문제](#atlas-generator-issues) 참조

### 모델이 뒤집혀 있음/안쪽이 바깥으로

**증상:**
- 메시가 뒤집혀 보임
- 뒷면이 보임
- 셰이딩이 잘못되어 보임

**해결 방법:**

1. **노멀 재계산:**
   - [최적화 → 메시 정리](Optimization#mesh-cleanup) 패널
   - "Recalculate Normals" 클릭

2. **편집 모드에서 확인:**
   - Tab으로 편집 모드
   - Face Orientation 활성화 (오버레이)
   - 파란색 = 정상, 빨간색 = 뒤집힘

3. **필요하면 노멀 뒤집기:**
   - 모든 면 선택
   - 메시 정리의 "Flip Normals" 사용
   - 메시 전체가 뒤집힌 경우에만

### VRChat/Unity에서 잘못된 스케일

**증상:**
- 아바타가 너무 크거나 작음
- 예상 키가 아님
- 비율이 잘못됨

**해결 방법:**

1. **Blender에서 스케일 확인:**
   - [스케일링](Scaling) 패널 사용
   - 실제 키 측정
   - 올바른 크기로 스케일링 (160-180cm 권장)

2. **변형 적용:**
   - [최적화 → 메시 정리](Optimization#mesh-cleanup)
   - "Apply Transformations"
   - 내보내기 전에

3. **Unity 가져오기 스케일:**
   - FBX는 1.0이어야 함
   - Unity에서 가져오기 설정 확인
   - Unity에서 스케일링하지 말고 Blender에서 스케일링

## 기능별 문제

### 눈 추적이 작동하지 않음

**증상:**
- 눈이 움직이지 않음
- 깜빡임이 작동하지 않음
- 설정이 깨진 것 같음

**해결 방법:**

1. **본 선택 확인:**
   - [눈 추적](Eye-Tracking) 패널
   - 머리, 왼쪽 눈, 오른쪽 눈 본이 선택되었는지 확인
   - 올바른 본 사용

2. **웨이트 페인팅 확인:**
   - 눈은 눈 본에 웨이트되어야 함
   - 100% 웨이트 권장
   - 웨이트 번짐 없음

3. **Blender에서 테스트:**
   - 눈 추적 패널의 테스트 제어 사용
   - 눈이 움직이는지 확인
   - 깜빡임 셰이프 키 확인

4. **머티리얼 / 아틀라스 순서:**
   - 눈 추적 **후에** 머티리얼을 결합하거나 아틀라스를 생성했나요?
   - 머티리얼 결합과 아틀라스 작업 **후에** 눈 추적을 설정하세요
   - 설정을 다시 해야 할 수 있음

### 입 모양이 작동하지 않음

**증상:**
- 립싱크에서 입이 움직이지 않음
- 셰이프 키가 할당되지 않음
- 미리 보기에 움직임이 나타나지 않음

**해결 방법:**

1. **셰이프 키 할당 확인:**
   - [입 모양](Visemes) 패널
   - Mouth A, O, CH가 할당되었는지 확인
   - 올바른 셰이프 키 사용

2. **셰이프 키 존재 확인:**
   - 메시 선택
   - 셰이프 키 패널 열기
   - 입 셰이프 키가 있는지 확인

3. **미리 보기로 테스트:**
   - 입 모양 패널의 미리 보기 사용
   - 각 입 모양을 개별적으로 확인
   - 필요하면 강도 조정

4. **번역 문제:**
   - 입 모양 설정 전에 셰이프 키 번역
   - 설정 후에는 번역하지 마세요
   - 참조가 깨질 수 있음

### 본 병합이 문제를 일으킴

**증상:**
- 본 병합 후 모델이 깨짐
- 웨이트가 잘못되어 보임
- 애니메이션이 깨짐

**해결 방법:**

1. **병합 설정 확인:**
   - [최적화](Optimization) 패널
   - 낮은 병합 비율로 시작 (0.5)
   - 안전을 위해 "병합된 본 유지" 활성화

2. **정리 전에 테스트:**
   - 먼저 본 병합
   - 철저히 테스트
   - 병합이 양호할 때만 정리

3. **이후 아마추어 확인:**
   - 본 계층 구조 확인
   - 애니메이션 테스트
   - 웨이트가 올바른지 확인

4. **필요하면 실행 취소:**
   - Ctrl+Z로 실행 취소
   - 다른 설정 시도
   - 또는 백업에서 작업

## 아틀라스 생성기 문제

> 💡 이전 **아틀라스 생성기 (레거시)** 패널(Material Combiner)은 **`5.3.1.0`에서 제거**되었으며, 그에 따른 모든 Pillow 및 Material Combiner 설치 문제도 사라졌습니다. 내장 [아틀라스 생성기](Optimization#atlas-generator)는 아무것도 설치할 필요가 없습니다. 여전히 알파로 표시되어 있으므로 문제가 발생하면 Blender Info 로그에 출력된 줄과 함께 알려 주세요.

### 아틀라스 생성기 (레거시) / Material Combiner를 찾을 수 없음

레거시 패널은 더 이상 존재하지 않습니다. 대신 **최적화 > 아틀라스 생성기**를 사용하세요. Material Combiner가 여전히 설치되어 있다면 **Import Material Combiner Settings** 버튼이 이전 아틀라스 설정, 머티리얼 체크, 레이어를 복사합니다. Material Combiner 자체는 타사 애드온이며 Cats는 더 이상 이를 지원하지 않습니다.

### 아틀라스에서 텍스처가 누락되거나 잘못됨

**가능한 원인:**
- Cats가 셰이더를 통해 머티리얼의 텍스처를 찾지 못함 (행에 ⚠ 아이콘 표시)
- 단일 이미지가 없는 절차적, 혼합 또는 버텍스 컬러 머티리얼
- 디스크에서 텍스처 파일 누락

**해결 방법:**
1. ⚠로 표시된 머티리얼에 **Bake**를 켜서 대신 Cycles가 렌더링하게 합니다
2. 누락된 텍스처 다시 연결 (File > External Data > Find Missing Files)
3. **Preview Result**로 빌드 전에 무엇이 패킹될지 확인

### 아틀라스 색상이 너무 어둡게 보임

`5.3.1.0` 이전 빌드는 단색 및 색조가 적용된 머티리얼을 너무 어둡게 기록했습니다. Cats를 업데이트하고 아틀라스를 다시 빌드하세요. 이제 색상이 뷰포트와 일치합니다.

### 두 번째 아틀라스를 빌드하니 첫 번째가 변경됨

`5.3.1.0` 이전 빌드는 `Cats_Atlas_01` / `Cats_Atlas_Mat_01` 이름을 재사용했으므로 같은 파일에서 두 번째 아바타를 아틀라스 처리하면 첫 번째가 덮어쓰였습니다. 이제 각 빌드는 고유한 이름(`Cats_Atlas_01_2` 등)을 받습니다. 업데이트 후 영향을 받은 아틀라스를 다시 빌드하세요.

### 파일을 다시 열자 아틀라스가 사라짐

**Save to Folder**와 비어 있거나 쓸 수 없는 폴더를 사용하면 `5.3.1.0` 이전 빌드는 아틀라스를 저장하지도 패킹하지도 않아 다시 로드할 때 사라졌습니다. 이제 저장에 실패하면 아틀라스가 `.blend`에 패킹되고 빌드가 경고합니다. PNG 파일을 얻으려면 쓸 수 있는 **Folder**를 설정하세요.

### 베이킹 문제

- **"cannot be baked" 오류:** 오브젝트가 현재 뷰 레이어에 없습니다. 예를 들어 제외된 컬렉션에 있습니다. 컬렉션을 포함하거나 해당 오브젝트의 머티리얼 체크를 해제하세요
- **버텍스 컬러가 덮어써짐:** Blender의 베이크 출력이 Color Attributes로 설정되어 있을 때 `5.3.1.0` 이전 빌드는 컬러 속성으로 베이크했습니다. 이제 베이킹은 항상 이미지 텍스처를 대상으로 합니다. 버텍스 컬러를 실행 취소하거나 백업에서 복원하세요
- **베이크 머티리얼이 여러 오브젝트 중 하나에서 잘못 보임:** `5.3.1.0`에서 수정되었으며, 베이크 머티리얼을 공유하는 오브젝트는 이제 함께 베이크됩니다

## 성능 문제

### Cats 작업이 매우 느림

**증상:**
- 도구 완료에 몇 분이 걸림
- 작업 중 멈추거나 정지

**가능한 원인:**
- 매우 복잡한 모델
- 많은 오브젝트/메시
- 느린 컴퓨터

**해결 방법:**

1. **인내심을 가지세요:**
   - 복잡한 작업은 시간이 걸림
   - Cats가 작업 중임
   - 콘솔에서 진행 상황 확인

2. **먼저 단순화:**
   - 불필요한 오브젝트 제거
   - 작업 전에 메시 결합
   - 먼저 모델 정리

3. **다른 프로그램 종료:**
   - RAM 확보
   - 브라우저 등 종료
   - Blender에 리소스 제공

## 오류 메시지

### "No Armature Selected"

**해결 방법:**
- 아마추어 오브젝트를 선택하세요
- 메시가 아닌 아마추어를 선택해야 함
- 오브젝트 모드에서

### "No Mesh Found"

**해결 방법:**
- 메시가 있는지 확인
- 메시가 아마추어에 페어런팅되어 있어야 함
- 오브젝트 가시성 확인

### "Shape Keys Not Found"

**해결 방법:**
- 메시에 셰이프 키가 있는지 확인
- 올바른 메시가 선택되었는지 확인
- 입 모양/눈 추적에는 셰이프 키가 있어야 함

### "Bone Not Found"

**해결 방법:**
- 본 이름 확인
- 본 목록 새로 고침
- 아마추어에 본이 있는지 확인

### 정책 위반 경고 (Blender 5.2 / 5.3)

**증상:**
- 확장 기능 정책에 대한 경고
- 레거시 방식에 대한 알림

**정상적인 현상입니다:**
- Cats는 타사 애드온에 레거시 방식을 사용함
- 경고는 무시해도 안전함
- 모든 것이 정상적으로 작동함
- 조치가 필요하지 않음

## 추가 도움 받기

### 도움을 요청하기 전에

1. **이 페이지 확인:** 많은 문제가 여기에 다루어져 있음
2. **관련 위키 페이지 읽기:** 기능별 가이드
3. **검색 시도:** 저장소의 기존 이슈
4. **버전 확인:** 지원되는 Blender 5.2+ 사용 중인지

### 도움을 요청할 때

다음을 포함하세요:
- Blender 버전 (정확히)
- Cats 버전
- 하려는 작업
- 대신 발생하는 상황
- 오류 메시지 (정확한 텍스트)
- 관련된 경우 스크린샷
- 가능하면 콘솔 출력

### 도움을 받을 수 있는 곳

- **저장소 이슈:** 버그 보고 및 질문
- **GitHub Issues:** 버그 보고 및 기능 요청
- **이 위키:** 문서 및 가이드

### 보고하지 말아야 할 것

- 지원되지 않는 Blender 버전 또는 blender.org나 Steam 버전이 아닌 Blender 버전 관련 문제 (5.2 이전은 지원되지 않음)
- 타사 확장 기능 문제 (Material Combiner 등. Cats는 더 이상 Material Combiner와 통합되지 않음)
- 일반적인 Blender 질문 (Blender 포럼 사용)
- 먼저 논의하지 않은 기능 요청

## 일반적인 워크플로 문제

### 작업 순서가 잘못됨

**많은 문제가 잘못된 순서에서 비롯됩니다:**

**올바른 순서:**
1. 모델 가져오기
2. MMD 수정 (MMD 모델인 경우, 새 파일만)
3. 이름 번역
4. 필요하면 변형 적용
5. **머티리얼 결합/아틀라스 생성**
6. **눈 추적 설정**
7. **입 모양 설정**
8. 최종 최적화
9. 내보내기

**핵심:** 눈 추적과 입 모양 **전에** 머티리얼을 결합하고 아틀라스를 생성하세요!

### 백업 관리

**항상 백업 보관:**
- 주요 작업 전
- 단계를 완료한 후
- 증분 버전 저장
- 가능하면 버전 관리 사용

**좋은 백업 관행:**
```
my_model_01_import.blend
my_model_02_fixed.blend
my_model_03_optimized.blend
my_model_04_rigged.blend
my_model_05_final.blend
```
