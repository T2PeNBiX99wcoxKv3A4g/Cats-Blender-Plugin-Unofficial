# UV 도구 {#uv-tools}

**UV 도구**는 UV 편집을 위한 도우미가 담긴 `5.2.3.0`의 새로운 패널입니다. **Align UV Edges to Target**과 **Find Shortest Seam Path** 두 가지 도구가 있습니다.

## 찾는 위치 {#where-to-find-it}

- 전체 패널은 **UV / 이미지 에디터** 사이드 패널(N 패널)의 **CATS** 탭 아래에 있습니다. 보려면 UV 에디터를 여세요.
- **Find Shortest Seam Path**는 실제로 버텍스를 선택하는 곳이기 때문에 **3D 뷰** CATS 탭("UV 도구" 아래)에도 반영되어 있습니다.

*Align UV Edges*는 UV 에디터 전용이며, UV 에디터의 2D 커서와 선택이 필요합니다.

---

## UV 가장자리를 대상에 정렬 {#align-uv-edges-to-target}

선택한 각 메시의 UV 포인트 라인을 **활성** 메시의 선택된 UV 포인트 라인을 따라가도록 재구성합니다. **키트배싱**에 매우 유용하며, 한 모델의 UV 레이아웃을 다른 모델에 맞춰 텍스처가 정렬되게 합니다.

**2D 커서**는 각 라인의 어느 쪽 끝이 "시작"인지 표시하므로, 포인트가 대상을 따라 보간되기 전에 모든 라인이 동일한 방향으로 진행됩니다.

### 사용 방법 {#how-to-use}

1. UV 에디터에서 **UV Sync Selection을 끕니다**.
2. 관련된 모든 메시를 선택합니다. **활성** 메시가 *대상*입니다.
3. **편집 모드**로 들어가 각 메시에서 일치하는 **UV 가장자리 라인**을 선택합니다.
4. 라인의 시작 끝 근처에 **2D 커서**를 배치합니다.
5. **Align UV Edges to Target**을 누릅니다.

> 선택한 각 메시에는 선택된 UV 포인트의 깔끔한 라인이 정확히 하나 있어야 합니다. 선택이 분기되거나 단일 라인이 아니면 Cats가 경고합니다.

---

## 최단 심 경로 찾기 {#find-shortest-seam-path}

선택한 두 버텍스를 연결하는 **심** 가장자리의 최단 경로를 선택합니다. 작업할 심 루프를 빠르게 선택할 때 유용합니다.

심으로 표시된 가장자리만 따라 탐색하므로(너비 우선 탐색), 결과는 항상 두 지점 사이의 가장 적은 가장자리 경로입니다.

### 사용 방법 {#how-to-use-1}

1. 메시에서 **편집 모드**로 들어갑니다.
2. 각각 심 위에 있는 **정확히 두 개의 버텍스**를 선택합니다.
3. **Find Shortest Seam Path**를 누릅니다 (UV 에디터와 3D 뷰 CATS 탭 모두에서 사용 가능).

경로 가장자리가 선택되고 모드가 가장자리 선택으로 전환됩니다. 두 버텍스가 심을 통해 연결되어 있지 않으면 Cats는 경로를 찾지 못했다고 알려 줍니다.
