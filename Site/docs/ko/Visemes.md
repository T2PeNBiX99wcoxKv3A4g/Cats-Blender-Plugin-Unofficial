# 입 모양

입 모양 패널은 VRChat에서 립싱크와 얼굴 애니메이션을 위한 입 모양(viseme) 셰이프 키를 설정하는 데 도움을 줍니다.

## 입 모양이란?

입 모양은 서로 다른 발음에 대응하는 입 모양입니다. 이를 통해 VRChat에서 말할 때 아바타가 자동으로 립싱크할 수 있습니다.

VRChat은 세 가지 주요 입 모양을 사용합니다:
- **Mouth A ('ah'):** 모음 소리를 위한 벌린 입
- **Mouth O ('oh'):** 'o'와 'u' 소리를 위한 둥근 입술
- **Mouth CH:** 'ch'와 'sh' 소리를 위한 닫히고 앞으로 나온 입술

## 요구 사항

- 입 움직임을 위한 셰이프 키가 있는 메시
- 적절히 명명된 셰이프 키 (또는 이를 할당할 수 있는 능력)

## 메시 선택

장면에 메시가 여러 개 있을 때:
- 얼굴/입이 포함된 **대상 메시를 선택**합니다
- 보통 몸 또는 머리 메시입니다
- 메시에 셰이프 키가 있어야 합니다

## 입 모양 설정

### 미리 보기 제어

**미리 보기 입 모양:**
- 실시간으로 입 모양을 테스트합니다
- 각 모양이 어떻게 보이는지 확인합니다
- 미리 보기 중에 값을 조정합니다

**미리 보기 중지:**
- 기본 상태로 돌아갑니다
- 모든 셰이프 키를 0으로 초기화합니다
- 미리 보기 모드를 종료합니다

**미리 보기 선택:**
- 테스트할 특정 입 모양을 선택하는 드롭다운
- Mouth A, Mouth O, Mouth CH를 개별적으로 테스트합니다
- 각 모양을 미세 조정할 때 유용합니다

### 셰이프 키 할당

Cats는 각 입 모양에 어떤 셰이프 키가 대응하는지 알아야 합니다.

#### Mouth A ('ah' 소리)
- 벌린 입을 위한 셰이프 키를 선택합니다
- 'a', 'e' 같은 모음 소리에 사용됩니다
- 보통 가장 크게 벌어진 입 모양입니다
- 예시 이름: "a", "ah", "mouth_open"

**할당 방법:**
1. Mouth A의 드롭다운을 클릭합니다
2. 메시에서 적절한 셰이프 키를 선택합니다
3. 미리 보기로 테스트합니다

#### Mouth O ('oh' 소리)
- 둥근 입술을 위한 셰이프 키를 선택합니다
- 'o'와 'u' 소리에 사용됩니다
- 입술이 O자 모양을 이룹니다
- 예시 이름: "o", "oh", "mouth_o"

**할당 방법:**
1. Mouth O의 드롭다운을 클릭합니다
2. 적절한 셰이프 키를 선택합니다
3. 미리 보기로 테스트합니다

#### Mouth CH
- 닫히고 앞으로 나온 입술을 위한 셰이프 키를 선택합니다
- 'ch', 'sh' 소리에 사용됩니다
- 입술이 앞으로 나오지만 대부분 닫혀 있습니다
- 예시 이름: "ch", "mouth_ch", "sil"

**할당 방법:**
1. Mouth CH의 드롭다운을 클릭합니다
2. 적절한 셰이프 키를 선택합니다
3. 미리 보기로 테스트합니다

### 셰이프 강도

- 입 모양의 강도/배수를 조정합니다
- 범위: 보통 0.0 ~ 2.0
- 기본값: 1.0 (대부분의 경우 기본값이면 충분합니다)
- **낮은 값:** 더 미묘한 립싱크
- **높은 값:** 더 과장된 립싱크

**조정 방법:**
1. 슬라이더를 움직이거나 값을 입력합니다
2. 미리 보기로 효과를 확인합니다
3. 자연스러운 강도를 찾습니다
4. 권장 범위: 0.8 ~ 1.2

## 자동 입 모양 설정

**자동 입 모양 설정** 기능은 입 모양을 자동으로 구성하려고 시도합니다:

**수행하는 작업:**
- 일반적인 셰이프 키 이름을 검색합니다
- 자동으로 입 모양 슬롯에 할당합니다
- 기본 립싱크 구성을 만듭니다
- 기본 강도 값을 설정합니다

**사용 방법:**
1. **자동 입 모양 설정**을 클릭합니다
2. 할당을 검토합니다
3. 필요하면 조정합니다
4. 미리 보기로 테스트합니다

**가장 잘 작동할 때:**
- 표준 셰이프 키 이름을 가진 모델
- MMD 모델 (수정 후)
- 일반적인 출처의 모델

> 💡 **팁:** 자동 설정이 모든 것을 완벽하게 처리하지 못하더라도 좋은 시작점입니다. 이후에 할당을 수동으로 조정할 수 있습니다.

## 워크플로

### 기본 입 모양 설정

1. [빠른 액세스](Quick-Access)로 **모델을 가져옵니다**
2. **입 모양 패널을 엽니다**
3. **메시를 선택합니다** (여러 개인 경우)
4. 먼저 **자동 입 모양 설정을 시도합니다**
5. **할당을 검토합니다:**
   - 각 입 모양 셰이프 키를 확인합니다
   - 필요하면 조정합니다
6. **미리 보기로 테스트합니다:**
   - 각 입 모양을 미리 봅니다
   - 강도를 조정합니다
7. **모델을 내보냅니다**

### 수동 입 모양 설정

자동 설정이 작동하지 않거나 더 많은 제어가 필요한 경우:

1. **셰이프 키를 파악합니다:**
   - Blender의 셰이프 키 패널로 이동합니다
   - 어떤 셰이프가 입 움직임용인지 확인합니다
2. **각 입 모양을 수동으로 할당합니다:**
   - Mouth A: 벌린 입 모양
   - Mouth O: 둥근 입 모양
   - Mouth CH: 닫히거나 앞으로 나온 입 모양
3. **각각 테스트합니다:**
   - 미리 보기로 확인합니다
   - 필요하면 강도를 조정합니다

## 팁 및 모범 사례

### 좋은 입 모양 만들기

처음부터 셰이프 키를 만드는 경우:

**Mouth A:**
- 턱이 벌어져야 합니다
- 이가 보여야 합니다
- 혀가 약간 보여야 합니다
- 자연스러운 'ah' 표정

**Mouth O:**
- 입술이 O자 모양을 이룹니다
- 턱이 약간 벌어집니다
- 입술이 약간 앞으로 나옵니다
- 'oh' 또는 'oo'를 말하는 것처럼

**Mouth CH:**
- 입술이 닫히거나 거의 닫힙니다
- 입술이 앞으로 나옵니다
- 'much'나 'ssh'의 끝소리처럼
- 약간 오므린 모양

### 입 모양 테스트

1. **먼저 Blender에서 테스트:**
   - 미리 보기 기능을 사용합니다
   - 여러 각도에서 확인합니다
   - 모양이 자연스러운지 확인합니다
2. **VRChat에서 테스트:**
   - 업로드하고 게임 내에서 테스트합니다
   - 다른 사람에게 어떻게 보이는지 물어봅니다
   - 필요하면 조정합니다

### 일반적인 문제

**입 모양이 너무 미묘함:**
- 셰이프 강도를 높입니다
- 셰이프 키에 충분한 움직임이 있는지 확인합니다
- 올바른 셰이프 키가 할당되었는지 확인합니다

**입 모양이 너무 과장됨:**
- 셰이프 강도를 낮춥니다
- 셰이프 키 값이 너무 과하지 않은지 확인합니다
- VRChat에서 테스트합니다 (Blender와 다르게 보일 수 있음)

**입이 움직이지 않음:**
- 입 모양이 할당되었는지 확인합니다
- 올바른 메시에 셰이프 키가 있는지 확인합니다
- 입 모양 패널에서 메시가 선택되었는지 확인합니다

**잘못된 모양이 나타남:**
- 입 모양 할당을 확인합니다
- 셰이프 키 이름을 확인합니다
- 필요하면 수동으로 다시 할당합니다

## 고급 옵션

### 여러 메시

아바타에 별도의 메시가 있는 경우:
- 입 모양이 있는 몸 메시
- 입 모양이 있는 머리 메시
- 활성 입 모양은 하나의 메시에만 있을 수 있습니다
- 애니메이션할 메시를 선택합니다

### 사용자 지정 입 모양 시스템

일부 모델은 다른 입 모양 시스템을 사용합니다:
- 표준 3-입 모양 (VRChat 기본값)
- 15-입 모양 (고급, 여기서는 다루지 않음)
- 사용자 지정 블렌드 셰이프

Cats는 표준 3-입 모양 시스템을 지원합니다.

## 입 모양 시스템 설명

### 왜 3개의 입 모양인가?

VRChat의 단순화된 시스템은 다음과 같은 이유로 3개의 입 모양을 사용합니다:
- 실시간 립싱크에 효율적
- 정확도와 성능의 좋은 균형
- 전체 음소 시스템보다 설정이 쉬움
- 음성 인식과 잘 작동함

### VRChat에서의 작동 방식

1. VRChat이 음성 입력을 분석합니다
2. 어떤 소리를 내고 있는지 판단합니다
3. 적절한 입 모양 셰이프 키를 활성화합니다
4. 부드러운 애니메이션을 위해 모양 사이를 블렌딩합니다

## 다른 도구와의 통합

### 머티리얼 결합 후

> ⚠ **중요:** 머티리얼을 결합하고 아틀라스를 생성한 **후에** 입 모양을 설정하세요. 구형 Material Combiner 애드온은 입 모양 설정 후에 실행하면 셰이프 키가 어긋날 수 있었습니다. 내장 [아틀라스 생성기](Optimization#atlas-generator)는 머티리얼과 UV만 변경하지만, 동일한 순서를 유지하세요.

**권장 순서:**
1. 모델 가져오기
2. MMD 모델 수정 (필요하고 vrm/mmd 모델인 경우에만)
3. 머티리얼 결합 / 아틀라스 생성
4. 입 모양 설정
5. 눈 추적 설정
6. 내보내기

### 눈 추적과 함께

입 모양과 [눈 추적](Eye-Tracking)은 함께 작동합니다:
- 둘 다 셰이프 키를 사용합니다
- 독립적으로 설정할 수 있습니다
- 설정 후 둘 다 테스트합니다
- 서로 충돌하지 않습니다
