# 변환기

**변환기** 패널(이전 이름 "MMD 옵션")은 모델을 한 리그/포맷에서 다른 리그/포맷으로 변환하는 도구와 MMD 전용 정리 기능을 모아 둔 곳입니다. 새로 가져온 모델을 Unity/VRChat용으로 준비하는 곳이기도 합니다.

이 패널은 세 영역으로 구성됩니다.

1. **Rigify 변환** - Rigify/Metarig 아마추어를 Cats 호환 아마추어로 변환합니다
2. **플랫폼 변환** - Source/Valve 본 이름과 Koikatsu 셰이프 키 수정
3. **MMD 정리** - MMD 모델 수정 및 리지드 바디/조인트 제거

---

## Rigify → Cats

**Convert Rigify to Cats** 버튼은 항상 표시되지만, **Rigify 또는 Metarig 아마추어가 활성화되기 전까지는 회색으로 비활성화**됩니다. Cats가 이를 감지하면 정보 상자가 나타나고 버튼을 사용할 수 있게 됩니다.

MMD 모델 수정은 Rigify 리그를 직접 처리할 수 없으므로, 먼저 변환한 후 일반 워크플로를 계속 진행하세요.

**옵션:**
- **트위스트 본 병합** - 변환하는 동안 Rigify의 트위스트 본을 부모 본에 합칩니다.

**사용 방법:**
1. Rigify/Metarig 아마추어를 선택합니다.
2. 버튼이 활성화되면 **Convert Rigify to Cats**를 클릭합니다.
3. 나머지 워크플로를 계속 진행합니다.

## 플랫폼 변환

### 본을 Valve 형식으로 변환

아마추어의 주요 본 이름을 Source 엔진(Source Filmmaker, GMod 등)에서 사용하는 **ValveBiped** 규칙으로 변경합니다. 예를 들어 `hips`는 `ValveBiped.Bip01_Pelvis`가 됩니다. GMod 변환 스크립트가 손가락 본을 필요로 하므로 손가락 본도 함께 이름이 변경됩니다.

이 기능은 본 이름만 변경하며, 계층 구조나 레스트 포즈는 변경하지 않습니다.

**요구 사항:** 모델에 먼저 CATS 표준 본 이름이 있어야 하므로, 이 작업 전에 **MMD 모델 수정**을 실행하세요.

**사용 시점:** Source Engine / Valve 게임으로 내보낼 때.

> ⚠ **구 버전 Cats로 변환한 경우 오른쪽 본을 확인하세요.**
>
> 구 버전은 짧은 형식의 오른쪽 이름 일곱 개를 **왼쪽**에 매핑했기 때문에, `R_Shoulder`, `R_Arm`, `R_Elbow`, `R_Wrist`, `R_Leg`, `R_Knee`, `R_Ankle` 같은 본들이 `ValveBiped.Bip01_L_*`로 나왔습니다. CATS의 풀네임(`Right shoulder`, `Right arm`, …)을 사용하는 모델은 영향을 받지 않았습니다.
>
> 모델의 **새 복사본**에 변환기를 다시 실행하여 수정하세요. 이미 내보낸 FBX는 복구할 수 없으며, 이미 이름이 잘못된 아마추어에 다시 실행해도 도움이 되지 않습니다. ValveBiped 이름이 더 이상 찾는 대상과 일치하지 않기 때문입니다.

### Koikatsu 셰이프 키 수정

**Koikatsu / Illusion** 내보내기에서 생성되는 분할된 셰이프 키를 정리합니다. Koikatsu는 하나의 표정을 여러 키에 분산시키므로(`eye_face.fXX`에 `eye_siroL`/`eye_line_u`, `kuti_face.fXX`에 `kuti_ha`/`kuti_sita`), 그대로는 사용할 수 없습니다.

이 도구는 일치하는 각 그룹을 하나의 `eyes_XX` 또는 `mouth_XX` 셰이프 키로 병합하고, 슬라이더를 적절한 최댓값으로 제한하며, 사용된 원본 키를 제거합니다.

**사용 시점:** 새로 가져온 Koikatsu 모델에서 [입 모양](Visemes)을 설정하기 전에.

## MMD 정리

### MMD 모델 수정

새로 가져온 MMD/VRM 모델을 Unity/VRChat에서 사용할 수 있는 리그로 변환하는 주요 도구입니다.

> ⚠ **경고: MMD 모델 수정은 Unity용으로 설정되지 않은, 새로 가져온 MMD / VRM 전용입니다.**
>
> **다음의 경우 사용하지 마세요:**
> - Booth, Gumroad 또는 유사한 스토어에서 모델을 구매한 경우
> - 모델이 이미 Unity/VRChat용으로 설정된 경우
> - 처음부터 사용자 지정 모델을 직접 만드는 경우
>
> Fix Model은 "무엇이든 고치는" 버튼이 아닙니다. 특정 가져오기 포맷을 위한 변환기입니다. 동일한 경고가 버튼이 있는 [빠른 액세스](Quick-Access)에도 표시됩니다.

> 🚫 **이 경고를 무시하는 것은 본인의 책임입니다.** Cats와 이 위키가 제공한 모든 경고를 무시하고 새로 가져온 MMD/VRM이 아닌 대상에 MMD 모델 수정을 실행한다면, 그 결과는 전적으로 본인 책임입니다. **이에 대한 이슈를 열지 마세요.** 즉시 이 경고들을 다시 안내받고 이슈는 바로 닫힙니다.

> 💡 버튼 옆의 **⚙ 설정 기어**는 **모델 설정**(끝 본 유지, 트위스트 본 유지, 메시 결합, 본 연결, 제로 웨이트 제거, 보호된 본 등)을 엽니다. 자세한 내용은 [설정](Settings)을 참조하세요.

#### 수행하는 작업

1. **본 페어런팅 변경** - Unity에 맞게 계층 구조를 재구성합니다
2. **불필요한 본 제거** - MMD 전용/미사용 본을 제거합니다
3. **이름 변경 및 번역** - 일본어 → 영어, 표준화된 이름 ([번역](Translation)). `5.2.4.0` 이후로 셰이프 키와 머티리얼은 PMX 파일의 **작성자 영어 이름**을 사용할 수 있으며, 셰이프 키 설정은 ⚙ 모델 설정에 있습니다
4. **웨이트 페인트 병합** - 버텍스 웨이트를 재분배합니다
5. **엉덩이 회전** - Unity에 맞게 엉덩이 회전을 보정합니다
6. **제약 조건 제거** - MMD 전용 제약 조건/IK를 제거합니다
7. **미사용 버텍스 그룹 삭제** - 비어 있는 웨이트 그룹을 정리합니다
8. **모프를 셰이프 키로 변환**

#### 사용 방법

1. [빠른 액세스](Quick-Access)를 통해 새로 가져온 MMD 또는 VRM 모델을 가져옵니다.
2. 아마추어를 선택합니다.
3. **MMD 모델 수정**을 클릭합니다 (변환기 또는 빠른 액세스에서).
4. 완료될 때까지 기다립니다 (복잡한 모델은 1분 정도 걸릴 수 있습니다).
5. 결과를 확인합니다.

### 리지드 바디 및 조인트 제거

MMD 물리 컴포넌트(리지드 바디 + 조인트 제약 조건)를 제거합니다. VRChat은 Unity의 물리 시스템을 사용하므로 MMD 물리는 호환되지 않으며 제거해야 합니다.

**사용 방법:** 모델을 선택하고 **리지드 바디 및 조인트 제거**를 클릭합니다.

**일치 대상:** 모델 하위에 있는 오브젝트 중 이름에 `rigidbodies` 또는 `joints`가 포함된 모든 것(대소문자 구분 없음)입니다. `Rigidbodies`, `RIGIDBODIES`, `rigidbodies` 모두 잡힙니다. 일치는 모델의 최상위 부모 아래 한 단계와 두 단계까지 실행되며, 일치 항목을 삭제하면 그 하위 트리 전체가 함께 삭제되므로 중첩된 물리 그룹도 한 번에 처리됩니다.

> 💡 **이 기능은 전역 설정과 다르며, 여전히 필요합니다.** [설정](Settings)의 **리지드 바디 + 조인트 제거**는 기본적으로 켜져 있고 Cats 버튼을 누를 때마다 실행되지만, `rigidbody`라는 이름의 *컬렉션* 전체를 삭제할 뿐입니다. 조인트는 확인하지 않고, 떠 있는 오브젝트도 확인하지 않습니다. 이 버튼은 모델 아래 부모로 연결된 *오브젝트*에서 동작하며 조인트도 잡습니다. MMD 가져오기에서는 계속 이 버튼을 사용하세요.

## 일반적인 MMD → VRChat 워크플로

1. [빠른 액세스](Quick-Access)를 통해 `.pmx`/`.pmd`/`.vrm`을 **가져옵니다**.
2. **MMD 모델 수정** (변환기 또는 빠른 액세스).
3. **리지드 바디 및 조인트 제거**.
4. **머티리얼 결합** 및 기타 정리 ([최적화](Optimization)).
5. **최적화** - 아틀라스, 본 병합, 중복 버텍스 제거.
6. [눈 추적](Eye-Tracking)과 [입 모양](Visemes)을 설정합니다.
7. [빠른 액세스](Quick-Access)를 통해 Unity용 FBX로 **내보내고**, Unity에서 머티리얼을 설정합니다.

## 일반적인 문제

**MMD 모델 수정 후 모델이 깨져 보임** 아마도 이미 Unity용으로 준비된 모델이었을 것입니다. 실행 취소(Ctrl+Z)하고 원본을 다시 가져온 후, 해당 모델에 MMD 모델 수정을 실행하지 마세요.

**본 이름이 이상하거나 영어임** 정상입니다. 이름은 VRChat에 맞게 번역되고 표준화됩니다.

**일부 머티리얼이 검게 보임** 대개 문제없습니다. Unity에서 머티리얼을 설정하세요. [최적화](Optimization)의 **모두 PNG로 변환**을 시도해 볼 수도 있습니다.

**Blender에서 모델이 회전되어 보임** Blender와 Unity는 서로 다른 좌표계를 사용합니다. 내보내기에서 이를 처리하며 Unity에서는 올바르게 표시됩니다.

## VRM 참고 사항

VRM 모델은 일반적으로 MMD 모델과 동일한 처리가 필요합니다.
- 새 VRM 파일(VRoid 내보내기 등)에는 **MMD 모델 수정**을 실행합니다
- 이미 처리된 VRM 모델에는 MMD 모델 수정을 실행하지 마세요

VRM 전용 셰이프 키 도구는 없습니다. **Koikatsu 셰이프 키 수정**은 Koikatsu 내보내기 전용이며, 위의 설명을 참조하세요.

Cats는 **VRM Add-on for Blender**와 함께 사용할 수 있습니다. 이 애드온으로 `.vrm`을 가져온 다음 Cats로 처리하고 최적화하세요.
