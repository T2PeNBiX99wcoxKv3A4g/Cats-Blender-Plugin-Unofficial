# 병합 및 부착

**병합 및 부착** 패널(이전 이름 "사용자 지정 모델 생성")은 아마추어를 병합하고 메시를 부착하여 결합되거나 사용자 지정된 모델을 만드는 도구를 제공합니다.

## 개요

이 패널에는 두 가지 주요 모드가 있습니다.
- **아마추어 모드** - 두 개의 완전한 아마추어를 서로 병합합니다
- **메시 모드** - 개별 메시를 기존 아마추어에 부착합니다

상단의 튜토리얼 버튼은 과정을 단계별로 안내합니다.

---

## 아마추어 모드

아마추어 모드는 리깅된 두 모델을 하나로 결합할 때 사용합니다.

### 요구 사항
- 장면에 최소 두 개의 아마추어
- 두 아마추어 모두 메시가 연결되어 있어야 함

### 주요 설정

- **동일 본 병합** - 이름이 일치하는 본을 자동으로 결합합니다. 두 모델이 비슷한 골격을 공유할 때(예: VRChat 표준 모델 두 개) 이상적입니다.
- **변형 적용** - 병합 전에 현재 변형을 적용합니다. 권장되며 스케일/회전 문제를 방지합니다.
- **메시 결합** - 병합 후 메시를 하나의 오브젝트로 결합합니다.
- **제로 웨이트 본 제거** - 병합 후 사용하지 않는 본을 정리합니다.
- **셰이프 키 정리** - 병합 중 중복/미사용 셰이프 키를 제거합니다.

### 병합 선택

- **병합 대상** - 병합된 내용을 받는 대상(기본) 아마추어입니다 (보통 주 캐릭터).
- **병합할 대상** - 결합할 아마추어입니다 (보통 의상, 액세서리 또는 추가 파츠).
- **본에 부착** *("동일 본 병합"이 비활성화된 경우)* - 병합된 아마추어를 부착할 본입니다 (예: 척추에 날개).

**"본에 부착"이 실제로 하는 일:** 병합된 아마추어의 **루트** 본만 선택한 본에 다시 페어런팅됩니다. 그 아래의 모든 것은 자체 계층 구조를 유지하므로, `Spine`에 부착된 꼬리 리그는 여전히 꼬리이며 단지 이제 척추에 매달릴 뿐입니다. 병합된 아마추어에서 기본 아마추어와 이름이 충돌하는 본은 같은 이름의 기본 본에 합쳐지고, 해당 웨이트는 일치하는 버텍스 그룹에 병합됩니다.

**물리는 자동으로 정리됩니다:** 병합은 먼저 **두** 아마추어 모두에서 리지드 바디와 조인트 오브젝트를 제거하며 중첩된 물리 그룹도 포함합니다. 따라서 미리 [리지드 바디 및 조인트 제거](Converters#remove-rigid-bodies-and-joints)를 실행할 필요가 없습니다.

### 사용 방법

1. 두 모델을 장면으로 가져옵니다.
2. **병합 대상** 아마추어(기본 모델)를 선택합니다.
3. **병합할 대상** 아마추어(추가할 모델)를 선택합니다.
4. 설정을 선택합니다:
   - 골격이 일치하면 **동일 본 병합**을 활성화합니다.
   - **변형 적용**을 활성화합니다 (권장).
   - 단일 메시 결과를 원하면 **메시 결합**을 활성화합니다.
5. 동일 본을 병합하지 않는 경우 **본에 부착**을 선택합니다.
6. **병합**을 클릭합니다.

**일반적인 용도:** 기본 몸체 + 리깅된 의상/머리카락, 리깅된 액세서리(날개, 꼬리, 소품) 추가.

## 메시 모드

메시 모드는 독립된 메시를 기존 아마추어에 부착할 때 사용합니다.

### 요구 사항
- 장면에 최소 하나의 아마추어
- 최소 하나의 리깅되지 않은 메시 오브젝트

### 설정 및 선택

- **메시 결합** - 부착된 메시를 기존 메시와 결합합니다.
- **병합 대상** - 대상 아마추어입니다.
- **메시 부착** - 부착할 (리깅되지 않은) 메시입니다.
- **본에 부착** - 메시가 따라갈 본입니다 (예: 머리 본에 모자).

### 사용 방법

1. 아마추어와 리깅되지 않은 메시가 있는지 확인합니다.
2. **메시 모드**로 전환합니다.
3. **병합 대상** 아마추어를 선택합니다.
4. **메시 부착**을 선택합니다.
5. **본에 부착**을 선택합니다.
6. 원하면 **메시 결합**을 활성화합니다.
7. **부착**을 클릭합니다.

**일반적인 용도:** 고정된 부착물(모자, 안경, 소품)과 간단한 비변형 의상.

## 팁 및 모범 사례

**병합 전:** 모델을 올바르게 배치하고, 스케일을 맞추고, 백업을 저장하고, 본 이름을 명확히 지정하세요 ("동일 본 병합"에 도움이 됩니다).

**병합 중:** **변형 적용**을 켜고 시작하고, 가능하면 **동일 본 병합**을 선호하며, 처음에는 **메시 결합**을 꺼 두어 문제를 더 쉽게 수정할 수 있게 하세요.

**병합 후:** 웨이트 페인팅을 확인하고, 애니메이션을 테스트하고, 본 계층 구조를 검토하며, 필요하면 [최적화](Optimization)를 통해 최적화하세요.

### 문제 해결

- **메시가 잘못된 위치에 있음** → **변형 적용**을 활성화하고 다시 시도하세요.
- **본이 병합되지 않음** → 이름이 정확히 일치하는지(대소문자 구분)와 위치가 비슷한지 확인하세요.
- **메시가 아마추어를 따라가지 않음** → 웨이트가 적용되어 있고 버텍스 그룹이 본 이름과 일치하는지 확인하세요.
- **셰이프 키가 사라짐** → **셰이프 키 정리**를 활성화하세요.
- **병합된 파츠가 선택한 본이 아닌 월드 원점에 있음** → 병합된 아마추어의 루트가 다시 페어런팅되지 않았습니다. **본에 부착** 드롭다운을 다시 열어 본을 다시 선택한 후 다시 병합하세요. **동일 본 병합**이 꺼져 있는지 확인하세요. 이 옵션은 **본에 부착**을 완전히 무시합니다.
- **"모델을 수정해 주세요" / 변형 오류** → 아마추어 중 하나 또는 둘 모두에 기본값이 아닌 변형을 가진 부모 오브젝트(보통 가져오기 도구의 Empty)가 있습니다. 부모에 변형을 적용하거나(Ctrl+A → All Transforms), **동일 본 병합**을 활성화하세요. 그러면 불필요한 부모가 자동으로 삭제됩니다.

---

## 제한 사항

- 아마추어 모드는 최소 2개의 아마추어가 필요하고, 메시 모드는 최소 1개의 아마추어와 1개의 메시가 필요합니다.
- 매우 복잡한 병합은 시간이 걸리며, 일부 사용자 지정 제약 조건은 수동으로 수정해야 할 수 있습니다.

> ⚠ **병합하기 전에 항상 모델을 백업하세요.** 결과는 모델 복잡도에 따라 달라집니다.
