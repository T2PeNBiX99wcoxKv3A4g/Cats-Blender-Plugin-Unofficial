# 스케일링 {#scaling}

스케일링 패널은 VRChat 같은 VR 플랫폼에 맞게 아바타의 비율과 키를 재조정합니다. Cats에 내장되어 있으므로 추가로 설치할 것이 없습니다.

> 📝 **Immersive Scaler를 대체합니다.** 이전 버전의 Cats는 별도의 Immersive Scaler 애드온이 필요했습니다. 외부 Immersive Scaler는 더 이상 유지 관리되지 않으므로 Cats는 이제 이를 기반으로 한 자체 스케일러를 제공합니다. 도구, 설정 및 결과는 Immersive Scaler와 동일합니다. Immersive Scaler가 여전히 설치되어 있다면 제거해도 됩니다. Cats는 더 이상 이를 사용하지 않습니다.

## 개요 {#overview}

적절한 아바타 스케일링은 VR 경험에 매우 중요합니다:
- VR에서 편안한 시야를 보장합니다
- 월드 대비 올바른 비율을 유지합니다
- 플랫폼의 키 권장 사항을 충족합니다
- VR에서 더 나은 사회적 상호작용을 제공합니다

단순히 모델 크기를 조정하는 것과 달리, 스케일러는 **비율**을 조정합니다. 필요한 변화량을 팔과 다리에 나누어 배분하고, 팔다리 두께를 적절히 유지하며, 아바타를 바닥에 배치한 다음 목표 키로 스케일링합니다. 아마추어와 메시는 셰이프 키를 포함하여 함께 변경됩니다.

## 요구 사항 {#requirements}

- Cats의 아마추어 드롭다운에서 선택한 휴머노이드 아마추어 (또는 활성 오브젝트로 지정)
- 어깨, 팔, 팔꿈치, 손목, 다리, 무릎, 발목, 눈에 해당하는 인식 가능한 본. 일반적인 명명 규칙(VRChat/Unity, **Fix Model** 이후의 MMD, `Left arm`, `UpperArm.L`, `Thigh_R` 등)은 자동으로 감지됩니다. 본을 찾지 못하면 [본 재정의](#bone-overrides)로 직접 설정하세요.

아마추어를 찾지 못하면 버튼이 회색으로 비활성화되며, 마우스를 올리면 그 이유를 설명합니다.

## 아바타 크기 재조정 {#avatar-rescale}

주요 섹션입니다. 값을 설정한 후 **아마추어 크기 재조정**을 클릭합니다.

| 설정 | 기본값 | 수행하는 작업 |
|---|---|---|
| **목표 키** | 1.61 m | 스케일링 후 가장 높은 버텍스의 높이. **눈 기준 스케일**이 켜져 있으면 대신 눈의 높이가 됩니다. |
| **다리/팔 스케일링** | 55% | 비율 변화 중 다리가 담당하는 비율. 나머지는 팔이 담당합니다. |
| **사용자 지정 팔 비율** | 0.4537 | 스케일링할 팔 대 키 비율로, VRChat의 `--custom-arm-ratio` 실행 옵션과 같습니다. 값이 높을수록 팔이 길어집니다. 0.4537은 VRChat의 기본값입니다. |
| **모델 중앙 정렬** | 끔 | 모델을 X/Y = 0으로 이동합니다. |

값 옆의 작은 화살표 버튼은 **현재 아바타에서 값을 읽어옵니다**:
- **목표 키** 옆: 목표를 아바타의 현재 키로 설정합니다
- **사용자 지정 팔 비율** 옆: 아바타의 현재 비율에서 비율을 설정합니다
- **상체 비율** / **상단 다리 비율** 옆: 현재 비율을 읽어옵니다

다른 값을 변경하면서 하나의 값을 그대로 유지할 때 유용합니다.

### 사용자 지정 {#customization}

더 세밀한 제어를 위해 **사용자 지정**을 펼치세요:

| 설정 | 기본값 | 수행하는 작업 |
|---|---|---|
| **팔 두께** | 50% | 팔을 늘리거나 줄일 때 유지 또는 추가되는 팔 두께의 정도. |
| **다리 두께** | 50% | 다리에 대해서도 동일합니다. |
| **상단 다리 비율** | 53% | 엉덩이에서 발뒤꿈치까지 거리 중 상단 다리의 비율. |
| **추가 다리 길이** | 0 m | 다리가 실제 바닥 아래로 얼마나 더 뻗어야 하는지, 즉 VRChat 바닥이 실제 바닥보다 얼마나 아래에 있어야 하는지. |
| **눈 기준 스케일** | 끔 | **목표 키**를 머리 꼭대기가 아닌 눈의 높이로 설정합니다. |
| **본 매핑 표시** | 끔 | [본 재정의](#bone-overrides) 섹션을 표시합니다. |

### 핵심 기능 토글 {#core-functionality-toggle}

**핵심 기능 토글**을 펼치면 개별 단계를 끌 수 있습니다. 주로 문제 해결에 유용합니다:

- **주 크기 재조정 건너뛰기**: 비율 조정을 건너뜁니다
- **바닥으로 이동 건너뛰기**: 아바타를 바닥으로 이동하지 않습니다
- **키 스케일링 건너뛰기**: 목표 키로의 최종 스케일링을 하지 않습니다
- **상대 비율로 스케일링**: **다리/팔 스케일링** 대신 **상체 비율**로 몸통을 스케일링합니다. VRChat의 상체 고정 모드에 더 잘 맞습니다.
- **머리 크기 유지**: 대신 몸통을 스케일링하여 머리 크기를 동일하게 유지하려고 시도합니다

## 손가락 벌리기 {#finger-spreading}

손가락 본을 회전시켜 손목에서 바깥으로 벌어지게 하여, VRChat의 손가락 추적과 제스처에서 더 보기 좋은 손 모양을 만듭니다.

**사용자 지정**을 펼치면:
- **엄지 무시** *(기본적으로 켜짐)*: 엄지를 그대로 둡니다
- **벌림 계수** *(기본값 1)*: 얼마나 회전할지. 1은 각 손가락이 손목에서 정확히 반대 방향을 향하게 합니다.

**손가락 벌리기**를 클릭하여 적용합니다.

---

## 엉덩이 수정 (베타) {#hip-fix-beta}

**엉덩이 본 축소**는 엉덩이 본을 척추에 훨씬 가깝게 이동합니다. 일부 모델은 엉덩이 본이 매우 길어 전신 추적에서 나쁘게 휘어집니다. 베타 기능이므로 내보내기 전에 결과를 확인하세요.

---

## 본 재정의 {#bone-overrides}

사용자 지정 아래에서 **본 매핑 표시**가 선택되면 표시됩니다. 각 행은 스케일러가 사용하는 본 하나입니다: 양쪽의 어깨, 팔, 팔꿈치, 손목, 다리, 무릎, 발목, 발가락, 눈, 그리고 목, 머리, 엉덩이, 척추, 가슴, 상단 가슴, 그리고 모든 손가락 본([손가락 벌리기](#finger-spreading)에서 사용됨). 행의 버튼을 클릭하면 검색 가능한 목록에서 일치하는 본을 선택할 수 있습니다.

본이 자동으로 감지되지 않았거나 잘못된 본이 선택된 경우에만 재정의를 사용하세요. 나머지는 기본값으로 두세요.

## 스케일 맞추기 {#scale-matching}

장면에 **아마추어가 두 개 이상** 있을 때만 표시됩니다. 한 아마추어의 비율을 다른 아마추어에 맞게 스케일링합니다. 예를 들어 의상 아마추어를 몸에 맞출 때 사용합니다:

1. **참조 아마추어**를 선택합니다 (맞출 대상)
2. **스케일링 아마추어**를 선택합니다 (변경할 대상)
3. **스케일 맞추기**를 클릭합니다

---

## 기본 워크플로 {#basic-workflow}

1. [빠른 액세스](./Quick-Access.md)로 **모델을 가져옵니다**
2. MMD/VRM 모델이라면 **Fix Model**을 실행합니다
3. **스케일링** 패널을 엽니다
4. **목표 키**를 설정합니다 (또는 화살표를 클릭하여 현재 키 유지)
5. **아마추어 크기 재조정**을 클릭합니다
6. 선택적으로 **손가락 벌리기**를 실행합니다
7. 결과를 확인한 후 내보냅니다

모든 스케일러 버튼은 **Ctrl+Z**로 실행 취소할 수 있습니다.

## 모범 사례 {#best-practices}

### 권장 아바타 키 {#recommended-avatar-heights}

**VRChat의 경우:**

| 키 범위 | 설명 | 사용 사례 |
|-------------|-------------|----------|
| 165cm (5'5") | 이상적인 평균 | 가장 다재다능하고 모두에게 편안함 |
| 160-170cm | 편안한 범위 | 대부분의 아바타에 적합 |
| 150-160cm | 작은 아바타 | 귀여운 캐릭터, 어린이 |
| 170-180cm | 큰 아바타 | 키 큰 캐릭터, 전사 |
| 140-150cm | 매우 작음 | 치비, 작은 생물 |
| 180-200cm | 매우 큼 | 거인, 몬스터 (드물게 사용) |

**일반 지침:**
- 너무 작음: 월드 오브젝트와 상호작용하기 어려움
- 너무 큼: 천장을 뚫을 수 있고 위압적으로 보임
- 평균: 사회적 상호작용에 가장 편안함
- 아바타 유형과 사용 사례를 고려하세요

### 스케일링 시점 {#when-to-scale}

**다음 전에 스케일링하세요:**
- 눈 추적 설정
- 입 모양 설정
- 셰이프 키 생성
- 최종 최적화
- 내보내기

**다음 후에 스케일링하세요:**
- 모델 가져오기
- MMD 모델 수정
- 기본 메시 정리

### 스케일 테스트 {#testing-scale}

**VRChat에서:**
- 최종 확정 전에 게임 내에서 테스트하세요
- 다른 사람에게 어떻게 보이는지 물어보세요
- 거울 모습을 확인하세요
- 월드 오브젝트와의 상호작용을 테스트하세요

## 일반적인 스케일 문제 {#common-scale-issues}

### 버튼이 회색으로 비활성화됨 {#buttons-are-greyed-out}

아마추어를 찾지 못했습니다. Cats의 아마추어 드롭다운에서 아바타의 아마추어를 선택하거나 뷰포트에서 클릭하여 활성 오브젝트로 만드세요.

### 본이 누락되었다고 보고되거나 결과가 뒤틀려 보임 {#a-bone-is-reported-missing-or-the-result-looks-twisted}

스케일러가 본을 찾지 못했거나 잘못된 본을 선택했습니다. 사용자 지정 아래의 **본 매핑 표시**를 선택하고 [본 재정의](#bone-overrides)에서 해당 본을 설정하세요.

### VRChat에서 아바타가 잘못된 크기로 보임 {#avatar-appears-wrong-size-in-vrchat}

**가능한 원인:**
- Blender에서 잘못 스케일링됨
- 내보내기 설정이 잘못됨
- Unity 가져오기 스케일 문제

**해결 방법:**
- **목표 키** 옆의 화살표를 클릭하여 아바타의 현재 키를 읽고 확인합니다
- Cats에서 올바른 내보내기 설정을 사용합니다
- Unity 가져오기 스케일을 확인합니다 (FBX는 1.0이어야 함)

### 스케일링 후 비율이 잘못되어 보임 {#proportions-look-wrong-after-scaling}

**가능한 원인:**
- 스케일러를 사용하기 전에 모델 크기를 수동으로 조정함
- 잘못된 본이 감지됨
- 설정이 너무 과함

**해결 방법:**
- 실행 취소한 후 **다리/팔 스케일링**과 두께 값을 기본값에 가깝게 하여 다시 시도합니다
- [본 재정의](#bone-overrides)를 확인합니다
- **핵심 기능 토글**을 사용하여 한 번에 한 단계씩 실행하고 어느 단계가 문제를 일으키는지 확인합니다

## 통합 참고 사항 {#integration-notes}

### 최적화와 함께 {#with-optimization}

최적화 전후 어느 쪽이든 스케일링할 수 있습니다:
- [최적화](./Optimization.md) 도구에 큰 영향을 주지 않습니다
- 본 병합은 어떤 스케일에서도 작동합니다
- 아틀라스 생성은 어떤 스케일에서도 작동합니다

### 내보내기와 함께 {#with-export}

[빠른 액세스](./Quick-Access.md) 내보내기를 사용하면:
- Cats가 스케일을 올바르게 처리합니다
- FBX 내보내기는 스케일을 유지합니다
- 추가 설정이 필요하지 않습니다
