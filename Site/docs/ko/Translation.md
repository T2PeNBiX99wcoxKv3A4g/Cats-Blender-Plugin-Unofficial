# 번역

**번역** 패널은 일본어(및 기타) 이름을 영어로 번역하여 모델이 영어 도구, Unity, VRChat에서 깔끔하게 작동하도록 합니다. `5.2.3.0`에서 자체 전용 패널과 **플러그 가능한 다중 서비스 백엔드**를 갖게 되었습니다.

## 작동 방식

번역은 항상 두 단계로 이루어집니다:

1. **내부 사전 우선.** Cats의 번들 사전이 모든 이름에 적용됩니다. 오프라인이며 즉각적이고 속도 제한이 없습니다.
2. **온라인 서비스가 빈 부분을 채웁니다.** 사전이 해결하지 못한 것은 선택한 온라인 서비스로 전송됩니다. 결과는 캐시되므로 반복되는 이름은 다시 네트워크에 접속하지 않습니다.

즉, 내부 사전은 *항상* 사용되며, 서비스 드롭다운은 **남은 부분을 어떤 온라인 서비스가 처리할지**만 결정합니다.

`5.2.4.0` 이후로 MMD 모델에는 중간 단계가 있습니다: **모델 작성자가 PMX 파일에 저장한 영어 이름**(MMD Tools는 *Name(Eng)*로 표시)입니다. 아래의 [작성자 이름](#author-names-mmd)을 참조하세요.

## 서비스 선택

**Translation Service** 드롭다운에서 제공하는 옵션:

| 서비스 | 필요 사항 | 참고 |
|---|---|---|
| **Internal Dictionary Only** | 없음 | 오프라인. 네트워크 호출이 전혀 없으며 번역되지 않은 텍스트는 그대로 둡니다. |
| **Google Translate** *(기본값)* | 없음 | 무료 엔드포인트, 키 불필요. 속도 제한이나 일시적 차단이 있을 수 있습니다. 이전 기본 동작과 일치합니다. |
| **DeepL** | API 키 | 무료 또는 Pro DeepL 키. 높은 품질, 네이티브 배치 번역. |
| **LibreTranslate** | URL (+ 선택적 키) | 공개 서버 또는 직접 호스팅하는 인스턴스. |
| **MyMemory** | 없음 (이메일 선택 사항) | 무료이며, 이메일을 추가하면 일일 할당량이 늘어납니다. |

자격 증명이 필요한 서비스를 선택하면 패널에 해당 필드가 나타납니다:
- **DeepL** → DeepL API Key
- **LibreTranslate** → LibreTranslate URL 및 선택적 API Key
- **MyMemory** → 선택적 이메일

> 🔒 서비스 선택과 자격 증명은 `.blend` 파일 내부가 아닌 Cats의 **전역 설정**([설정](Settings#settings-file-location) 참조)에 저장되므로 API 키가 모델과 함께 이동하지 않습니다. `5.3.1.0` 이전에는 API 키, LibreTranslate URL, MyMemory 이메일이 각 `.blend`에도 저장되었습니다. `5.3.1.0` 이상으로 이러한 파일을 열면 제거됩니다(유지하려면 파일을 저장하세요). 이전 버전으로 만든 파일을 공유했다면 API 키를 교체하는 것을 고려하세요.

> 💡 온라인 서비스를 사용할 수 없는 경우(키 없음, 오프라인 또는 속도 제한) 번역은 실패하는 대신 내부 사전이 할 수 있는 만큼으로 **우아하게 저하**됩니다.

> 온라인 서비스는 Blender의 **Edit > Preferences > System > Network > Allow Online Access**가 켜져 있을 때만 실행됩니다. 꺼져 있으면 Cats는 내부 사전만 사용하고 온라인 액세스가 비활성화되었다는 경고를 표시합니다. **Internal Dictionary Only**는 어느 경우든 작동합니다.

## 번역 버튼

- **Translate All**은 아래의 모든 항목을 한 번에 번역합니다
- **셰이프 키**
- **오브젝트**
- **본**
- **머티리얼**

## 작성자 이름 (MMD)

PMX 파일에는 모델 작성자가 작성한 모든 본, 셰이프 키, 머티리얼의 선택적 영어 이름이 포함됩니다. `5.2.4.0`부터 Cats는 이를 사용할 수 있는데, 작성자가 해당 키의 *역할*을 알고 있었기 때문에 어떤 사전이나 온라인 서비스보다 나은 경우가 많습니다.

- **Author Names (Shape Keys)**는 셰이프 키에 이를 어떻게 사용할지 결정합니다:
  - **Fill Gaps** *(기본값)* 사전 우선, 작성자의 영어 이름은 사전이 완전히 번역하지 못한 키에 한해 온라인 서비스를 호출하기 전에 사용됩니다.
  - **Prefer Author Names** 작성자 이름이 있으면 항상 우선합니다. 나머지는 평소처럼 사전과 온라인 서비스를 통해 처리됩니다.
  - **Off** 이를 무시하고 `5.2.4.0` 이전처럼 사전과 온라인 서비스로만 번역합니다.
- **Author Names (Materials)** *(기본적으로 켜짐)* 일본어 이름을 번역하는 대신 작성자의 영어 머티리얼 이름을 사용합니다. 비어 있거나, 순수 영어가 아니거나, 여러 머티리얼이 공유하는 이름은 건너뛰고 평소처럼 번역합니다.

**본과 오브젝트는 작성자 이름을 절대 사용하지 않습니다.** MMD 모델 수정은 리그를 인식하기 위해 사전의 본 이름에 의존하므로 본 번역은 변경되지 않습니다.

셰이프 키 설정은 **MMD 모델 수정**의 ⚙ 모델 설정에도 반영되며, MMD 모델 수정은 MMD 루트를 삭제하기 전에 이름을 기록하므로 이후에도 사용할 수 있습니다. 번역 보고서는 작성자로부터 온 이름이 몇 개인지 알려 주며, [번역 CSV 내보내기](Settings#export-translation-csv)에는 각 이름의 출처를 나타내는 *source* 열이 추가됩니다.

> 🧪 **새 기능이며 가볍게 테스트되었습니다.** 이 기능이 개발된 모델에서는 작동하지만, 영어 이름이 있는 더 많은 MMD 모델로 검증할 필요가 있습니다. 셰이프 키나 머티리얼이 예상하지 못한 이름으로 나오면 설정을 **Off**로 전환하고 해당 모델을 알려 주세요.

## 옵션

- **Skip Dictionary for Shape Keys** *(온라인 전용)* 레거시 동작: 셰이프 키에 대해 내부 사전을 무시하고 선택한 온라인 서비스로만 번역합니다. Cats 0.9.0 이하의 정확한 셰이프 키 이름에 의존하는 경우에만 필요합니다.
- **Skip Locked Shape Keys** 잠긴 셰이프 키는 번역되지 않고 그대로 둡니다 (의도적으로 이름을 지정한 키를 보호할 때 유용).

## 모범 사례

**해야 할 것:**
- ✅ 가져오기 / MMD 모델 수정 직후 일찍 번역하세요
- ✅ 입 모양이나 눈 추적을 설정하기 **전에** 번역하세요
- ✅ 반복 실행 시 캐시가 제 역할을 하도록 두세요

**하지 말아야 할 것:**
- ❌ 입 모양/눈 추적을 설정한 *후에* 다시 번역하지 마세요 (참조가 깨질 수 있습니다)
- ❌ 같은 모델을 반복해서 번역하지 마세요 (단어가 중복될 수 있습니다)

### 번역 시점

**다음 전:** 입 모양, 눈 추적, 사용자 지정 셰이프 키, 다른 모델과의 병합.
**다음 후:** 모델 가져오기, MMD 모델 수정 실행.

## 캐시 초기화

온라인 번역 캐시는 [설정](Settings) 패널(**Reset Google Dictionary**)에서 지울 수 있습니다. 잘못된 번역이 캐시되었거나 서비스를 전환하여 새 결과를 원할 때 유용합니다.
