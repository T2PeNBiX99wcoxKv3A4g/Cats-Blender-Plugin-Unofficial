# 메시 도구 (이동됨)

**메시 도구** 하위 패널은 더 이상 존재하지 않습니다. 그 내용은 [최적화](Optimization)의 두 하위 패널로 분리되어, 메시 작업이 더 이상 두 곳에 흩어져 있지 않습니다:

| 이전 위치 | 새 위치 |
| --- | --- |
| 메시 도구 → Separate By | [최적화 → 메시 정리](Optimization#mesh-cleanup) |
| 메시 도구 → 노멀 | [최적화 → 메시 정리](Optimization#mesh-cleanup) |
| 메시 도구 → 변형 적용 | [최적화 → 메시 정리](Optimization#mesh-cleanup) |
| 메시 도구 → 셰이프 키 도구 | [최적화 → 셰이프 키](Optimization#shape-keys) |

메시 결합과 중복 버텍스 제거도 **메시 정리**로 이동했습니다. 이전에는 *머티리얼 작업*(현재는 [머티리얼](Optimization#materials)) 아래에 있었습니다.

발가락 보행 다리와 트위스트 본 *생성* 도구는 자체 [본 도구](Bone-Tools) 패널을 갖습니다.
