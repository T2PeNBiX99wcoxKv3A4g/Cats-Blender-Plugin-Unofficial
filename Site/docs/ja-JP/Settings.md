# 設定 {#settings}

設定とアップデートのパネルは、Cats Blender Plugin の構成オプションとアップデート管理を提供します。

## 一般設定 {#general-settings}

### エクスポートオプション {#export-options}

#### テクスチャを埋め込む {#embed-textures}
- テクスチャをエクスポートしたファイルに直接含めます
- ファイルサイズが増加します
- 自己完結したエクスポートになります
- モデルの共有に便利です

**有効にするタイミング:**
- テクスチャ付きの FBX ファイルを共有する場合
- 単一ファイルで配布する場合
- 別途テクスチャを管理する必要がない場合

> **UNITY / VRCHAT 向けに何かを作成している場合はテクスチャを埋め込まないでください。マテリアルは UNITY で設定する必要があります**

**無効にするタイミング:**
- ファイルサイズを小さく保つ場合
- Unity でテクスチャを別途管理する場合
- アセットをより良く整理する場合

#### 剛体/ジョイントを削除 {#remove-rigidbodiesjoints}
- エクスポート時に物理を整理します
- MMD の物理データを削除します
- ファイルの複雑さを軽減します
- VRChat へのエクスポートに推奨されます

**有効にするタイミング:**
- MMD モデルをエクスポートする場合
- 物理データが不要な場合
- よりクリーンなエクスポートを望む場合

**無効にするタイミング:**
- 物理を保持する必要がある場合
- 対象アプリケーションで物理を使用する場合

#### 翻訳 CSV をエクスポート {#export-translation-csv}
- エクスポート時に翻訳ファイルを生成します
- 名前のマッピングを含む CSV を作成します
- `5.2.4.0` 以降は **source** 列が含まれます。辞書、MMD の作者名、またはオンラインサービスです
- ドキュメント作成に便利です
- 翻訳の参照用になります

**有効にするタイミング:**
- 翻訳のドキュメントが必要な場合
- 翻訳を確認したい場合
- モデルのドキュメントを作成する場合

**無効にするタイミング:**
- 翻訳の記録が不要な場合
- エクスポート時間を短縮する場合

#### カスタムエクスポートディレクトリ {#custom-export-directory}
- エクスポートの保存先を設定します
- 選択内容を記憶します
- ワークフローが速くなります
- 整理されたファイル管理ができます

**設定方法:**
1. フォルダーアイコンをクリックします
2. 目的の場所に移動します
3. フォルダーを選択します
4. 以降のエクスポートはここがデフォルトになります

## 言語設定 {#language-settings}

### インターフェースの言語 {#interface-language}

Cats はユーザーインターフェースで複数の言語をサポートします。

#### 利用可能な言語 {#available-languages}

- **English (en_US)** - デフォルト
- **Japanese (ja_JP)**
- **Korean (ko_KR)**
- コミュニティが翻訳を提供した追加の言語

#### 言語の変更 {#changing-language}

1. ドロップダウンから言語を選択します
2. 約 2 秒後に Cats が自身を再読み込みします（Cats のみで、他のアドオンは影響を受けません）
3. UI 要素が選択した言語に更新されます

Blender の再起動は不要です。ラベルが変わらない場合は Blender を再起動してください。

#### カスタム言語ファイル {#custom-language-files}

Cats はカスタムの翻訳ファイルをサポートします。
- 同梱ファイルは拡張機能内の `resources/translations/` にあります。**Download Latest Translations** は新しいコピーを Cats の[ユーザーデータフォルダー](#settings-file-location)内の `translations` フォルダーに保存し、それらが優先して使用されます
- 破損した、またはダウンロードが途中の言語ファイルはスキップされます。Cats は読み込みに失敗するのではなく、同梱のコピー、次に英語へフォールバックします
- JSON 形式です
- コミュニティが翻訳を提供できます
- 新しい言語を簡単に追加できます

### 翻訳の管理 {#translation-management}

**翻訳ファイルの構造:**
- 各言語に JSON ファイルがあります
- UI 文字列のマッピングを含みます
- 簡単に編集・拡張できます
- 新しい言語用のテンプレートが利用できます

## デバッグオプション {#debug-options}

### メンテナンスツール {#maintenance-tools}

#### Reset Google Dictionary {#reset-google-dictionary}
- キャッシュされた Google Translate のデータをクリアします
- 翻訳が正しくない場合に便利です
- 新しい翻訳を強制します
- 安全に使用できます

**使用するタイミング:**
- 翻訳が間違っているように見える場合
- 新しい翻訳データが必要な場合
- 大きな更新の後
- 翻訳の問題をトラブルシューティングする場合

**使用方法:**
1. **Reset Google Dictionary** をクリックします
2. 操作を確認します
3. 辞書のキャッシュがクリアされます

#### 翻訳のデバッグ（開発ブランチ） {#translation-debugging-dev-branch}
- 開発ブランチで利用できます
- 翻訳プロセスの詳細を表示します
- 翻訳の問題の特定に役立ちます
- 上級ユーザー/開発者向けです

#### システムキャッシュのクリーンアップ {#system-cache-cleanup}
- さまざまなキャッシュデータをクリアします
- 一時ファイルをリセットします
- 奇妙な問題の解決に役立つことがあります
- 定期的に使用しても安全です

**使用するタイミング:**
- プラグインの動作がおかしい場合
- 更新の後
- 原因不明の問題をトラブルシューティングする場合

#### 構成のリセットオプション {#configuration-reset-options}
- デフォルト設定に戻します
- カスタム構成をクリアします
- インストール直後の状態に戻します
- 設定が破損している場合に使用します

> ⚠ **警告:** 構成のリセットは元に戻せません。カスタム設定は失われます。

## アップデート管理 {#update-management}

### バージョン管理 {#version-control}

#### アップデート通知 {#update-notifications}
- 新しいバージョンを自動的に確認します
- アップデートが利用可能な場合に表示します
- プラグインのインターフェースに表示されます
- 邪魔にならない通知です

**構成:**
- アップデート確認の有効/無効
- 確認の頻度の設定
- 通知スタイルの選択

#### 自動アップデート確認 {#automatic-update-checks}
- Cats の読み込み時にバックグラウンドで 1 回実行されます
- [GitHub](https://github.com/T2PeNBiX99wcoxKv3A4g/Cats-Blender-Plugin-Unofficial/releases) のリリースを確認します
- インストール済みのバージョンと比較します
- 利用可能な場合はアップデートボタンを表示します

`5.3.1.0` 以降、アップデーターはお使いの Blender バージョン向けのものだけでなく、すべての Cats リリースを一覧表示します。1 つのリリースが複数の Blender バージョンをサポートできるためです。Blender 自体が各リリースのサポート対象 Blender 範囲を確認し、お使いの Blender で実行できないものはインストールを拒否します。

**仕組み:**
1. Cats が GitHub のリリース一覧を確認します
2. バージョン番号を比較します
3. 新しいバージョンが存在する場合に通知します
4. ダウンロードリンクを提供します

> **Blender のオンラインアクセスが必要です。** Cats は **Edit > Preferences > System > Network > Allow Online Access** がオンの場合にのみアップデートを確認します。オフの場合、自動確認は通知なくスキップされ、**Check for Updates** はオンラインアクセスが無効であることを伝えるメッセージを表示します。

#### バージョン互換性の情報 {#version-compatibility-info}
- Blender のバージョンがサポート対象か表示します
- 互換性のないバージョンについて警告します
- 正しいバージョンを推奨します
- インストールの問題を防ぎます

#### リリースノートへのアクセス {#release-notes-access}
- アップデートの変更履歴を表示します
- 新機能を確認できます
- バグ修正を把握できます
- アップデート通知からアクセスできます

### アップデートの管理 {#managing-updates}

#### 手動でのアップデート確認 {#checking-for-updates-manually}

1. 設定パネルを開きます
2. **Check for Updates** をクリックします
3. 確認が完了するまで待ちます
4. アップデートが利用可能な場合は案内に従います

#### アップデートのインストール {#installing-updates}

1. 提供されたリンクから新しいバージョンをダウンロードします
2. Blender を閉じます
3. 古いバージョンを削除します:
   - Edit > Preferences > Extensions に移動します
   - Cats を見つけます
   - 拡張機能を削除します
4. Blender を再起動します
5. 新しいバージョンをインストールします
6. 拡張機能を有効にします

> 📝 **注意:** 最もクリーンにインストールするため、古いバージョンの削除と新しいバージョンのインストールの間には必ず Blender を再起動してください。

#### バージョン番号の理解 {#understanding-version-numbers}

Cats は 3 つの部分からなるセマンティックバージョニングを使用します。

- **Major.Minor.Patch**（例: `5.5.0`）
- **Major.Minor** はこの継続プロジェクトが開始された Blender シリーズを表します。同じビルドがサポートされるすべての Blender バージョンにインストールできます
- **Patch** はリリース、機能、修正をまとめて数えます

例:

- `5.3.9` - パッチリリース
- `5.4.0` - ドキュメントサイトを追加したリリース
- `5.5.0` - サイトにすべての UI 言語を追加したリリース

各リリースがサポートする Blender バージョンについては [Version Support](./Version-Support.md) を参照してください。

## 設定のベストプラクティス {#settings-best-practices}

### エクスポート設定 {#export-settings}

**VRChat に推奨:**
- ❌ テクスチャを埋め込む: オフ（Unity で処理します）
- ✅ 剛体/ジョイントを削除: オン
- ❌ 翻訳 CSV をエクスポート: オフ（必要な場合を除く）
- ✅ カスタムエクスポートディレクトリ: プロジェクトフォルダーに設定

**モデルの共有に推奨:**
- ✅ テクスチャを埋め込む: オン（受け取る側にとって簡単です）
- ✅ 剛体/ジョイントを削除: オン
- ✅ 翻訳 CSV をエクスポート: オン（ドキュメント用）
- ✅ カスタムエクスポートディレクトリ: エクスポート用フォルダーに設定

### アップデート設定 {#update-settings}

**推奨:**
- ✅ 自動アップデート確認を有効にする
- ✅ 毎日または毎週確認する
- ✅ アップデート前にリリースノートを読む
- ✅ 大きなアップデートの前にバックアップを取る

### 言語設定 {#language-settings-1}

**最良の体験のために:**
- 問題なければ英語を使用する（ドキュメントの多くは英語です）
- より良く理解するために母国語を使用する
- 不足している翻訳を報告してコミュニティに貢献する
- 自分の言語が利用可能か確認する

## 設定のトラブルシューティング {#troubleshooting-settings}

### 設定が保存されない {#settings-not-saving}

**考えられる原因:**
- 権限の問題
- 設定の破損
- Blender が正しく終了していない

**解決策:**
- フォルダーの権限を確認します
- 構成をリセットします
- Blender の設定を手動で保存します
- 必要に応じて再インストールします

### アップデートが表示されない {#updates-not-showing}

**考えられる原因:**
- Blender の **Allow Online Access** がオフになっています
- アップデート確認が無効になっています
- インターネット接続がありません
- ファイアウォールが github.com をブロックしています
- VPN が干渉しています
- プロキシやセキュリティソフトが HTTPS 証明書を置き換えています（Cats はアップデートサーバーの証明書を検証します）

**解決策:**
- **Edit > Preferences > System > Network > Allow Online Access** をオンにします
- アップデート確認を有効にします
- インターネット接続を確認します
- ファイアウォールで github.com を許可します
- 一時的に VPN を無効にします
- システムコンソールを確認します。`URL ERROR` は、Cats がアップデートサーバーに到達できなかった、またはその証明書が信頼されなかったことを意味します

### 言語が変わらない {#language-not-changing}

**考えられる原因:**
- Cats の自動再読み込みが失敗しました（システムコンソールで `Cats reload failed` を確認してください）
- 翻訳ファイルがありません
- 言語ファイルが破損しています（その場合 Cats は同梱ファイルまたは英語にフォールバックします）

**解決策:**
- Blender を完全に再起動します
- 翻訳ファイルが存在することを確認します
- **Download Latest Translations** をもう一度クリックするか、必要に応じて再インストールします

## 設定ファイルの場所 {#settings-file-location}

Cats は設定を独自のユーザーデータフォルダーに保持し、Cats のアップデート後も存続します。これは Blender の `extensions/.user` ディレクトリ内の拡張機能のフォルダーです（ディスクからインストールした場合、リポジトリ部分は通常 `user_default` です）。
- Windows: `%APPDATA%\Blender Foundation\Blender\5.x\extensions\.user\user_default\cats_blender_plugin\`
- macOS: `~/Library/Application Support/Blender/5.x/extensions/.user/user_default/cats_blender_plugin/`
- Linux: `~/.config/blender/5.x/extensions/.user/user_default/cats_blender_plugin/`

含まれるもの:
- `settings.json` - 翻訳サービスの API キーを含む Cats の設定
- `dictionary_google.json` - オンライン翻訳のキャッシュ
- `dictionary.json` と `translations/` - ダウンロードした辞書と言語ファイル

設定はグローバルです。`.blend` を開くたびに再適用されるため、別の値で保存されたファイルが設定を上書きすることはありません。`5.3.1.0` 以降、翻訳の API キー、LibreTranslate URL、MyMemory のメールは **`.blend` ファイルに書き込まれることはなく**、古いバージョンがファイルに保存したものはファイルを開いたときに削除されます。

> ⚠ **警告:** これらのファイルを手動で編集すると問題が発生する可能性があります。可能な場合は設定パネルを使用してください。

## Blender の設定との統合 {#integration-with-blender-preferences}

Cats は Blender の設定を尊重します。
- ファイルパス
- 言語設定（可能な場合）
- インターフェースのスケール
- テーマ設定

Cats は読み込み時に Blender の設定を**変更しません**。古いバージョンはファイル圧縮を有効にし、アドオンのサポートフィルターを変更していましたが、`5.3.1.0` 以降、設定はあなたが設定したとおりに保たれます。

---

## 再起動が必要な変更 {#changes-requiring-restart}

一部の設定は Blender の再起動が必要です。
- ❌ 言語の変更（Cats が自身を再読み込みします）
- ✅ 主要な構成のリセット
- ❌ エクスポートオプション（即座に反映されます）
- ❌ アップデート確認（即座に反映されます）
