# Visemes {#visemes}

Visemes パネルは、VRChat でのリップシンクと表情アニメーションのための viseme シェイプキーを設定するのに役立ちます。

## Viseme とは {#what-are-visemes}

Viseme は、さまざまな発話音に対応する口の形です。これにより、VRChat で話したときにアバターが自動的にリップシンクできるようになります。

VRChat は 3 つの主要な viseme 形状を使用します。
- **Mouth A（'ah'）:** 母音のための開いた口
- **Mouth O（'oh'）:** 'o' と 'u' の音のための丸めた唇
- **Mouth CH:** 'ch' と 'sh' の音のための、閉じて前に突き出した唇

## 必要条件 {#requirements}

- 口の動き用のシェイプキーを持つメッシュ
- 適切に名前が付けられたシェイプキー（または割り当てられること）

## メッシュの選択 {#mesh-selection}

シーンに複数のメッシュがある場合:
- 顔/口を含む**対象のメッシュを選択**します
- 通常は体または頭のメッシュです
- メッシュにシェイプキーがある必要があります

## Viseme の設定 {#viseme-settings}

### プレビューコントロール {#preview-controls}

**Preview Visemes:**
- viseme の形状をリアルタイムでテストします
- 各形状の見え方を確認します
- プレビューしながら値を調整します

**Stop Preview:**
- デフォルトの状態に戻します
- すべてのシェイプキーを 0 にリセットします
- プレビューモードを終了します

**Preview Selection:**
- テストする特定の viseme を選ぶドロップダウン
- Mouth A、Mouth O、Mouth CH を個別にテストします
- 各形状の微調整に便利です

### シェイプキーの割り当て {#shape-key-assignment}

Cats は、どのシェイプキーが各 viseme に対応するかを知る必要があります。

#### Mouth A（'ah' の音） {#mouth-a-ah-sound}
- 開いた口のシェイプキーを選択します
- 'a'、'e' などの母音に使用されます
- 通常は最も大きく開いた口です
- 名前の例: "a"、"ah"、"mouth_open"

**割り当て方法:**
1. Mouth A のドロップダウンをクリックします
2. メッシュから適切なシェイプキーを選択します
3. プレビューでテストします

#### Mouth O（'oh' の音） {#mouth-o-oh-sound}
- 丸めた唇のシェイプキーを選択します
- 'o' と 'u' の音に使用されます
- 唇が O の形を作ります
- 名前の例: "o"、"oh"、"mouth_o"

**割り当て方法:**
1. Mouth O のドロップダウンをクリックします
2. 適切なシェイプキーを選択します
3. プレビューでテストします

#### Mouth CH {#mouth-ch}
- 閉じて前に突き出した唇のシェイプキーを選択します
- 'ch'、'sh' の音に使用されます
- 唇は前に押し出されますが、ほぼ閉じています
- 名前の例: "ch"、"mouth_ch"、"sil"

**割り当て方法:**
1. Mouth CH のドロップダウンをクリックします
2. 適切なシェイプキーを選択します
3. プレビューでテストします

### シェイプの強度 {#shape-intensity}

- viseme 形状の強さ/倍率を調整します
- 範囲: 通常 0.0 から 2.0
- デフォルト: 1.0（ほとんどの場合デフォルトで問題ありません）
- **小さい値:** より控えめなリップシンク
- **大きい値:** より誇張されたリップシンク

**調整方法:**
1. スライダーを動かすか値を入力します
2. プレビューで効果を確認します
3. 自然に見える強度を見つけます
4. 推奨範囲: 0.8 から 1.2

## 自動 Viseme セットアップ {#auto-viseme-setup}

**Auto Viseme Setup** 機能は、viseme の自動構成を試みます。

**動作内容:**
- 一般的なシェイプキー名を検索します
- 自動的に viseme スロットに割り当てます
- 基本的なリップシンク構成を作成します
- デフォルトの強度値を設定します

**使用方法:**
1. **Auto Viseme Setup** をクリックします
2. 割り当てを確認します
3. 必要に応じて調整します
4. プレビューでテストします

**最も効果的な場合:**
- 標準的なシェイプキー名を持つモデル
- MMD モデル（修正後）
- 一般的なソースのモデル

> 💡 **ヒント:** 自動セットアップがすべてを正しく行わなくても、良い出発点になります。後から割り当てを手動で調整できます。

## ワークフロー {#workflow}

### 基本的な Viseme のセットアップ {#basic-viseme-setup}

1. [Quick Access](./Quick-Access.md) を使用して**モデルをインポート**します
2. **Visemes パネルを開きます**
3. **メッシュを選択します**（複数ある場合）
4. まず **Auto Viseme Setup** を試します
5. **割り当てを確認します:**
   - 各 viseme のシェイプキーを確認します
   - 必要に応じて調整します
6. **プレビューでテストします:**
   - 各 viseme をプレビューします
   - 強度を調整します
7. **モデルをエクスポートします**

### 手動での Viseme セットアップ {#manual-viseme-setup}

自動セットアップが動作しない場合、またはより細かく制御したい場合:

1. **シェイプキーを特定します:**
   - Blender の Shape Keys パネルに移動します
   - どのシェイプが口の動き用か確認します
2. **各 viseme を手動で割り当てます:**
   - Mouth A: 開いた口の形状
   - Mouth O: 丸めた口の形状
   - Mouth CH: 閉じた/前に突き出した口の形状
3. **それぞれをテストします:**
   - プレビューで確認します
   - 必要に応じて強度を調整します

## ヒントとベストプラクティス {#tips-and-best-practices}

### 良い Viseme の作成 {#creating-good-visemes}

シェイプキーをゼロから作成する場合:

**Mouth A:**
- 顎が開いている
- 歯が見える
- 舌がわずかに見える
- 自然な 'ah' の表情

**Mouth O:**
- 唇が O の形を作る
- 顎がわずかに開いている
- 唇がわずかに前に押し出されている
- 'oh' や 'oo' と言うときのような形

**Mouth CH:**
- 唇が閉じている、またはほぼ閉じている
- 唇が前に押し出されている
- 'much' や 'ssh' の語尾のような形
- わずかにすぼめた形

### Viseme のテスト {#testing-visemes}

1. **まず Blender でテストします:**
   - プレビュー機能を使用します
   - 複数の角度から確認します
   - 形状が自然に見えるか確認します
2. **VRChat でテストします:**
   - アップロードしてゲーム内でテストします
   - 他の人に見え方を聞きます
   - 必要に応じて調整します

### よくある問題 {#common-issues}

**Viseme が控えめすぎる:**
- Shape Intensity を上げます
- シェイプキーに十分な動きがあるか確認します
- 正しいシェイプキーが割り当てられているか確認します

**Viseme が誇張されすぎる:**
- Shape Intensity を下げます
- シェイプキーの値が極端すぎないか確認します
- VRChat でテストします（Blender とは見え方が異なる場合があります）

**口が動かない:**
- viseme が割り当てられているか確認します
- 正しいメッシュにシェイプキーが存在するか確認します
- Visemes パネルでメッシュが選択されていることを確認します

**間違った形状が表示される:**
- viseme の割り当てを確認します
- シェイプキーの名前を確認します
- 必要に応じて手動で再割り当てします

## 詳細オプション {#advanced-options}

### 複数のメッシュ {#multiple-meshes}

アバターに個別のメッシュがある場合:
- viseme を持つ体のメッシュ
- viseme を持つ頭のメッシュ
- アクティブな viseme を持てるメッシュは 1 つだけです
- アニメーションさせるメッシュを選択します

### カスタム Viseme システム {#custom-viseme-systems}

一部のモデルは異なる viseme システムを使用します。
- 標準の 3 viseme（VRChat のデフォルト）
- 15 viseme（高度、ここでは扱いません）
- カスタムのブレンドシェイプ

Cats は標準の 3 viseme システムをサポートします。

## Viseme システムの説明 {#viseme-systems-explained}

### なぜ 3 つの Viseme なのか {#why-3-visemes}

VRChat の簡略化されたシステムが 3 つの viseme を使用する理由:
- リアルタイムのリップシンクに効率的です
- 精度とパフォーマンスのバランスが良いです
- 完全な音素システムよりも設定が簡単です
- 音声認識と相性が良いです

### VRChat での動作 {#how-it-works-in-vrchat}

1. VRChat が音声入力を分析します
2. どの音を発しているかを判断します
3. 適切な viseme シェイプキーを有効にします
4. 滑らかなアニメーションのために形状間をブレンドします

## 他のツールとの統合 {#integration-with-other-tools}

### マテリアルの結合後 {#after-material-combining}

> ⚠ **重要:** マテリアルを結合してアトラスを作成した**後**に visemes を設定してください。旧 Material Combiner アドオンは、viseme 設定後に実行するとシェイプキーがずれる可能性がありました。内蔵の [Atlas Generator](./Optimization.md#atlas-generator) はマテリアルと UV のみを変更しますが、同じ順序を守ってください。

**推奨する順序:**
1. モデルをインポートします
2. MMD モデルを修正します（必要な場合で、vrm/mmd モデルのみ）
3. マテリアルを結合 / アトラスを作成します
4. visemes を設定します
5. アイトラッキングを設定します
6. エクスポートします

### アイトラッキングとの関係 {#with-eye-tracking}

visemes と [Eye Tracking](./Eye-Tracking.md) は連携して動作します。
- どちらもシェイプキーを使用します
- 独立して設定できます
- 設定後に両方をテストします
- 両者の間に競合はありません
