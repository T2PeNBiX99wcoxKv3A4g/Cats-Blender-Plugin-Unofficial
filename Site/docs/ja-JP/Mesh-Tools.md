# メッシュツール（移動済み） {#mesh-tools-moved}

**Mesh Tools** サブパネルは存在しなくなりました。その内容は [Optimization](./Optimization.md) の 2 つのサブパネルに分割され、メッシュ作業が 2 か所に分散しないようになりました。

| 旧位置 | 新位置 |
| --- | --- |
| Mesh Tools → Separate By | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Normals | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → Apply Transformations | [Optimization → Mesh Cleanup](./Optimization.md#mesh-cleanup) |
| Mesh Tools → シェイプキーツール | [Optimization → Shape Keys](./Optimization.md#shape-keys) |

Join Meshes と Remove Doubles も **Mesh Cleanup** に移動しました。以前は *Material Operations*（現在は [Materials](./Optimization.md#materials)）の下にありました。

デジティグレード脚とツイストボーンの*生成*ツールには、専用の [Bone Tools](./Bone-Tools.md) パネルがあります。
