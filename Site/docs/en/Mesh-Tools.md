# Mesh Tools (moved)

The **Mesh Tools** sub-panel no longer exists. Its contents were split into two sub-panels of [Optimization](Optimization), so that mesh work is no longer spread across two places:

| Old location | New location |
| --- | --- |
| Mesh Tools → Separate By | [Optimization → Mesh Cleanup](Optimization#mesh-cleanup) |
| Mesh Tools → Normals | [Optimization → Mesh Cleanup](Optimization#mesh-cleanup) |
| Mesh Tools → Apply Transformations | [Optimization → Mesh Cleanup](Optimization#mesh-cleanup) |
| Mesh Tools → shape key tools | [Optimization → Shape Keys](Optimization#shape-keys) |

Join Meshes and Remove Doubles also moved into **Mesh Cleanup**, they were previously under *Material Operations* (now [Materials](Optimization#materials)).

The digitigrade-leg and twist-bone *generation* tools have their own [Bone Tools](Bone-Tools) panel.
