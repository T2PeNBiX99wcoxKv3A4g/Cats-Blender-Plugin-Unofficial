# 눈 추적 {#eye-tracking}

눈 추적 패널은 VRChat용 아바타에 눈 움직임과 깜빡임 애니메이션을 설정하는 도구를 제공합니다.

## 개요 {#overview}

눈 추적을 사용하면 VR에서 아바타의 눈이 실제 눈의 움직임을 따라가게 하고, 깜빡임 애니메이션을 설정할 수 있습니다. 이 기능은 VRChat에서 자연스러운 아바타를 만드는 데 필수적입니다.

## 모드 선택 {#mode-selection}

눈 추적 패널은 두 가지 모드를 제공합니다.

### SDK3 모드 {#sdk3-mode}
- VRChat SDK3를 위한 간단한 설정
- 자동 본 회전 구성
- 눈 본을 직접 할당
- **대부분의 사용자에게 권장됨**
- 더 빠른 설정 과정

### 레거시 모드 {#legacy-mode}
- 완전한 눈 추적 설정
- 사용자 지정 가능한 눈 움직임
- 고급 깜빡임 제어
- 셰이프 키 통합
- 매개변수에 대한 더 많은 제어

> 💡 **팁:** VRChat에는 레거시 모드를 사용하지 마세요. 레거시 모드는 ChilloutVR 같은 다른 게임 전용이며, VRChat 눈 추적은 이제 Unity에서 설정합니다.

---

## SDK3 모드 설정 {#sdk3-mode-setup}

SDK3 모드는 간소화된 설정 과정을 제공합니다.

### 요구 사항 {#requirements}
- 아마추어에 눈 본이 있어야 함
- 아마추어에 머리 본이 있어야 함
- 눈에 올바른 웨이트가 적용되어 있어야 함

### 단계별 설정 {#step-by-step-setup}

1. **모드 선택:**
   - 패널에서 **SDK3 모드**를 선택합니다

2. **본 선택:**
   - **머리 본:** 머리 본을 선택합니다
   - **왼쪽 눈 본:** 왼쪽 눈 본을 선택합니다
   - **오른쪽 눈 본:** 오른쪽 눈 본을 선택합니다

3. **움직임 구성:**
   - Cats가 회전 한계를 자동으로 설정합니다
   - 눈 본이 추적용으로 구성됩니다

4. **테스트:**
   - 테스트 제어 기능을 사용합니다
   - 눈 움직임이 자연스러운지 확인합니다

이것으로 끝입니다, 나머지는 Unity에서 설정해야 합니다.

---

## 레거시 모드 설정 {#legacy-mode-setup}

레거시 모드는 ChilloutVR 같은 다른 게임이나 소프트웨어를 위한 더 많은 제어와 옵션을 제공합니다.

### 본 선택 {#bone-selection}

#### 머리 본 {#head-bone}
- 주 머리 본을 선택합니다
- 눈 회전의 기준으로 사용됩니다
- 보통 "Head" 또는 "head"로 명명됩니다

#### 눈 본 {#eye-bones}
- **왼쪽 눈 본:** 왼쪽 눈 제어 본
- **오른쪽 눈 본:** 오른쪽 눈 제어 본
- 이 본들은 머리에 페어런팅되어야 합니다
- 일반적으로 "Eye_L" / "Eye_R" 등으로 명명됩니다

> 📝 **참고:** Cats는 일반적인 이름의 본을 자동으로 감지할 수 있습니다.

### 셰이프 키 구성 {#shape-key-configuration}

깜빡임과 눈 애니메이션용:

#### 윙크 셰이프 키 {#wink-shape-keys}
- **왼쪽 윙크:** 왼쪽 눈 감김용 셰이프 키
- **오른쪽 윙크:** 오른쪽 눈 감김용 셰이프 키
- 깜빡임과 윙크 표정에 사용됩니다

#### 아래 눈꺼풀 제어 {#lower-lid-controls}
- **왼쪽 아래 눈꺼풀:** 왼쪽 아래 눈꺼풀용 셰이프 키
- **오른쪽 아래 눈꺼풀:** 오른쪽 아래 눈꺼풀용 셰이프 키
- 더 자연스러운 깜빡임 애니메이션을 만듭니다
- 선택 사항이지만 권장됩니다

### 눈 움직임 설정 {#eye-movement-settings}

**거리 조정:**
- 눈이 움직일 수 있는 거리를 제어합니다
- 값이 높을수록 더 많이 움직입니다
- 값이 낮을수록 더 미묘합니다
- 기본값이 보통 적절합니다

**회전 제어:**
- X축: 수평 움직임 (왼쪽/오른쪽)
- Y축: 수직 움직임 (위/아래)
- 테스트하는 동안 이 값을 조정하세요

### 추가 옵션 {#additional-options}

**눈 깜빡임 비활성화:**
- 자동 깜빡임을 방지합니다
- 수동으로 제어하려는 경우 사용하세요
- 또는 모델이 깜빡임을 지원하지 않는 경우

**눈 움직임 비활성화:**
- 눈 회전을 고정합니다
- 눈이 시선을 따라가지 않습니다
- 스타일화된 눈이나 정적인 눈에 사용하세요

**눈 간격:**
- 눈 타깃 사이의 간격을 조정합니다
- 모델에 맞게 미세 조정하세요
- 눈이 모이는 방식에 영향을 줍니다

**메시 선택:**
- 다중 메시 모델용입니다
- 셰이프 키가 포함된 메시를 선택합니다
- 보통 몸 또는 얼굴 메시입니다

## 테스트 모드 {#testing-mode}

두 모드 모두 테스트 기능을 포함합니다.

### 눈 움직임 테스트 {#eye-movement-testing}

**실시간 미리 보기:**
- Blender에서 눈 회전을 테스트합니다
- 눈이 어떻게 움직이는지 확인합니다
- 자연스러운 움직임을 확인합니다

**X/Y축 제어:**
- 수평/수직 움직임을 테스트하는 슬라이더
- 눈을 왼쪽/오른쪽, 위/아래로 움직입니다
- 전체 가동 범위를 확인합니다

**거리 조정:**
- 눈이 얼마나 멀리 움직이는지 테스트합니다
- 모델의 비율에 맞게 조정합니다

**위치 초기화:**
- 눈을 중앙으로 되돌립니다
- 모든 테스트 회전을 지웁니다
- 처음부터 다시 시작합니다

### 깜빡임 제어 {#blinking-controls}

**깜빡임 셰이프 테스트:**
- 윙크 셰이프 키를 테스트합니다
- 눈꺼풀이 올바르게 감기는지 확인합니다
- 양쪽 눈을 개별적으로 확인합니다

**아래 눈꺼풀 애니메이션:**
- 아래 눈꺼풀 움직임을 테스트합니다
- 자연스러운 깜빡임 모양을 보장합니다
- 셰이프 키 할당을 확인합니다

**애니메이션 미리 보기:**
- 전체 깜빡임 주기를 확인합니다
- 타이밍과 부드러움을 확인합니다

## 워크플로 {#workflow}

### 기본 눈 추적 설정 {#basic-eye-tracking-setup}

1. **모드를 선택합니다** (VRChat은 SDK3, 필요한 다른 게임은 레거시)
2. **본을 선택합니다:**
   - 머리 본
   - 왼쪽 및 오른쪽 눈 본
3. **레거시를 사용하는 경우 셰이프 키를 설정합니다:**
   - 왼쪽/오른쪽 윙크
   - 아래 눈꺼풀 (선택 사항)
4. **눈 움직임을 테스트합니다:**
   - X/Y 제어를 사용합니다
   - 자연스러운 움직임을 확인합니다
5. **깜빡임을 테스트합니다:**
   - 깜빡임 셰이프를 확인합니다
   - 필요하면 조정합니다
6. **모델을 내보냅니다**

### 고급 설정 (레거시 모드) {#advanced-setup-legacy-mode}

1. **레거시 모드를 선택합니다**
2. 위와 같이 **본을 구성합니다**
3. **모든 셰이프 키를 설정합니다:**
   - 왼쪽 윙크
   - 오른쪽 윙크
   - 왼쪽 아래 눈꺼풀
   - 오른쪽 아래 눈꺼풀
4. **설정을 조정합니다:**
   - 눈 간격
   - 움직임 범위
   - 회전 한계
5. **철저히 테스트합니다:**
   - 모든 방향
   - 깜빡임
   - 조합
6. **미세 조정합니다:**
   - 거리 조정
   - 셰이프 키 강도 조정
7. **내보냅니다**

## 팁 및 모범 사례 {#tips-and-best-practices}

### 본 설정 {#bone-setup}

**눈 본 위치:**
- 안구 중앙에 위치해야 합니다
- 표면에 있으면 안 됩니다
- 회전 피벗 포인트입니다

**눈 본 회전:**
- 머리와 정렬되어야 합니다
- Z축이 앞쪽을 향해야 합니다 (보통)
- 여러 방향에서 테스트하세요

### 웨이트 페인팅 {#weight-painting}

**눈 메시 웨이트:**
- 눈은 해당 눈 본에 100% 웨이트되어야 합니다
- 다른 본으로 웨이트가 번지면 안 됩니다
- 깔끔한 웨이트 분배

**눈꺼풀 웨이트:**
- 머리 본과 눈 본 사이에 혼합 웨이트를 가질 수 있습니다
- 원하는 변형에 따라 달라집니다
- 깜빡임을 테스트하여 확인합니다

### 셰이프 키 생성 {#shape-key-creation}

**좋은 윙크 셰이프 키:**
- 눈이 완전히 감김
- 자연스러운 눈꺼풀 위치
- 눈 모양과 일치
- 관통이나 틈이 없음

**좋은 아래 눈꺼풀 셰이프 키:**
- 미묘한 움직임
- 윗 눈꺼풀 움직임을 따름
- 자연스러운 눈 찡그림 모양
- 선택 사항이지만 사실감을 더함

### 테스트 {#testing}

**Blender에서:**
- 모든 방향 테스트
- 극단적인 범위에서 확인
- 깜빡임 확인
- 여러 각도에서 확인

**VRChat에서:**
- 실제 눈 추적으로 테스트
- 다른 사람과 함께 확인
- 거울에서 확인
- 필요하면 조정

## 일반적인 문제 {#common-issues}

### 눈이 움직이지 않음 {#eyes-dont-move}

**가능한 원인:**
- 눈 본이 선택되지 않음
- 눈 본에 올바른 웨이트가 적용되지 않음
- 설정에서 움직임이 비활성화됨

**해결 방법:**
- 본 선택을 확인합니다
- 눈 메시의 웨이트 페인팅을 확인합니다
- "눈 움직임 비활성화"가 꺼져 있는지 확인합니다

### 움직일 때 눈이 이상하게 보임 {#eyes-look-weird-when-moving}

**가능한 원인:**
- 잘못된 본 회전
- 잘못된 피벗 포인트
- 잘못된 웨이트 페인팅

**해결 방법:**
- 눈 본 회전을 확인합니다 (머리의 전방 방향과 일치해야 함)
- 본이 눈 메시 중앙에 있는지 확인합니다
- 눈의 웨이트 페인팅을 수정합니다

### 깜빡임이 작동하지 않음 {#blinking-doesnt-work}

**가능한 원인:**
- 셰이프 키가 할당되지 않음
- 잘못된 메시가 선택됨
- 깜빡임이 비활성화됨

**해결 방법:**
- 윙크 셰이프 키가 할당되었는지 확인합니다
- 패널에서 올바른 메시를 선택합니다
- "눈 깜빡임 비활성화"가 꺼져 있는지 확인합니다

### 눈이 사팔뜨기가 되거나 잘못 벌어짐 {#eyes-cross-or-diverge-incorrectly}

**가능한 원인:**
- 눈 간격 설정이 잘못됨
- 본 위치가 잘못됨

**해결 방법:**
- 눈 간격 슬라이더를 조정합니다
- 눈 본이 올바르게 배치되었는지 확인합니다
- 다양한 거리 값으로 테스트합니다

### 눈꺼풀이 눈을 관통함 {#eyelids-clip-through-eyes}

**가능한 원인:**
- 셰이프 키가 너무 과함
- 메시 토폴로지 문제

**해결 방법:**
- 셰이프 키를 덜 과하게 조정합니다
- 눈 주변 메시 토폴로지를 수정합니다
- 셰이프 키 드라이버로 범위를 제한합니다

## 통합 참고 사항 {#integration-notes}

### 머티리얼 결합 및 아틀라스 작업 시 {#with-material-combining-and-atlassing}

> ⚠ **중요:** 머티리얼을 결합하고 아틀라스를 생성한 **후에** 눈 추적을 설정하세요. 구형 Material Combiner 애드온은 눈 추적 설정 후에 실행하면 셰이프 키가 어긋날 수 있었습니다. 내장 [아틀라스 생성기](./Optimization.md#atlas-generator)는 머티리얼과 UV만 변경하지만, 동일한 순서를 유지하세요.

**권장 순서:**
1. 모델 가져오기
2. 머티리얼 결합 / 아틀라스 생성
3. 눈 추적 설정
4. 입 모양 설정
5. 내보내기
