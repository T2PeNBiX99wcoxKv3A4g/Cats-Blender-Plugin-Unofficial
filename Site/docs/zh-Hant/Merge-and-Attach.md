# 合併與附加 {#merge-attach}

**合併與附加**（Merge & Attach）面板（舊稱「自訂模型建立」）提供工具來合併骨架與附加網格，以建立組合式或客製化的模型。

## 概觀 {#overview}

此面板有兩種主要模式：
- **骨架模式** - 將兩個完整的骨架合併在一起
- **網格模式** - 將個別網格附加到既有的骨架上

頂端的教學按鈕會逐步引導你完成整個流程。

---

## 骨架模式 {#armature-mode}

使用骨架模式可將兩個已綁定的模型合併成一個。

### 需求 {#requirements}
- 場景中至少有兩個骨架
- 兩個骨架都應該已附加網格

### 主要設定 {#main-settings}

- **Merge Same Bones** - 自動合併名稱相符的骨骼。當兩個模型共用相似的骨架時最理想（例如兩個 VRChat 標準模型）。
- **Apply Transforms** - 在合併前套用目前的變換。建議使用，可避免縮放／旋轉問題。
- **Join Meshes** - 合併後將網格結合成單一物件。
- **Remove Zero Weight Bones** - 合併後清理未使用的骨骼。
- **Cleanup Shape Keys** - 在合併期間移除重複／未使用的形態鍵。

### 合併選擇 {#merge-selection}

- **Merge Into** - 接收合併內容的目標（基準）骨架（通常是你的主要角色）。
- **To Merge** - 要合併進來的骨架（通常是服裝、配件或額外零件）。
- **Attach to Bone** *（當「Merge Same Bones」停用時）* - 要將合併後骨架附加到的骨骼（例如翅膀附加到脊椎）。

**「Attach to Bone」實際上是怎麼運作的：** 只有合併後骨架的**根**骨骼會被重新設定父系到你選擇的骨骼上。它們底下的所有東西都會保有自己的階層，所以附加到 `Spine` 的尾巴骨架仍然是一條尾巴，只是現在掛在脊椎底下。合併後骨架中名稱與基準骨架衝突的骨骼，會被併入同名的基準骨骼，而其權重會合併到相符的頂點組中。

**物理會自動幫你清理：** 合併時會先從**兩個**骨架中剝除剛體與關節物件，包括巢狀的物理群組，因此你不需要事先執行[移除剛體與關節](./Converters.md#remove-rigid-bodies-and-joints)。

### 使用方式 {#how-to-use}

1. 將兩個模型都匯入你的場景。
2. 選取 **Merge Into** 骨架（你的基準模型）。
3. 選取 **To Merge** 骨架（要加入的模型）。
4. 選擇你的設定：
   - 若骨架相符，啟用 **Merge Same Bones**。
   - 啟用 **Apply Transforms**（建議）。
   - 若想要單一網格的結果，啟用 **Join Meshes**。
5. 若不進行相同骨骼合併，請選擇 **Attach to Bone**。
6. 點擊 **Merge**。

**常見用途：** 基礎身體 + 已綁定的服裝／頭髮、加入已綁定的配件（翅膀、尾巴、道具）。

## 網格模式 {#mesh-mode}

使用網格模式可將獨立網格附加到既有的骨架上。

### 需求 {#requirements-1}
- 場景中至少有一個骨架
- 至少有一個未綁定的網格物件

### 設定與選擇 {#settings-selection}

- **Join Meshes** - 將附加的網格與既有網格結合。
- **Merge Into** - 目標骨架。
- **Attach Mesh** - 要附加的（未綁定）網格。
- **Attach to Bone** - 網格將跟隨的骨骼（例如帽子附加到頭部骨骼）。

### 使用方式 {#how-to-use-1}

1. 確保你有一個骨架與一個未綁定的網格。
2. 切換到**網格模式**。
3. 選取 **Merge Into** 骨架。
4. 選取 **Attach Mesh**。
5. 選擇 **Attach to Bone**。
6. 視需要啟用 **Join Meshes**。
7. 點擊 **Attach**。

**常見用途：** 剛性附件（帽子、眼鏡、道具）與簡單的非變形服裝。

## 提示與最佳實務 {#tips-best-practices}

**合併前：** 正確擺放模型、讓比例相符、儲存備份，並清楚命名骨骼（有助於「Merge Same Bones」）。

**合併期間：** 先以啟用 **Apply Transforms** 開始，盡可能優先使用 **Merge Same Bones**，並在初期保持 **Join Meshes** 關閉，這樣問題會比較容易修正。

**合併後：** 檢查權重繪製、測試動畫、檢視骨骼階層，並視需要透過[最佳化](./Optimization.md)進行最佳化。

### 疑難排解 {#troubleshooting}

- **網格位置錯誤** → 啟用 **Apply Transforms** 後重試。
- **骨骼沒有合併** → 確認名稱完全相符（區分大小寫）且位置相近。
- **網格沒有跟隨骨架** → 確認它已設定權重，且頂點組與骨骼名稱相符。
- **形態鍵消失** → 啟用 **Cleanup Shape Keys**。
- **合併後的部位停在世界原點而不是選取的骨骼上** → 合併後骨架的根沒有被重新設定父系。請重新開啟 **Attach to Bone** 下拉選單並重新選取骨骼，然後再次合併。請確認 **Merge Same Bones** 是關閉的，它會完全忽略 **Attach to Bone**。
- **「Please fix your model」／變換錯誤** → 其中一個或兩個骨架有個父系物件（通常是匯入器產生的 Empty）帶有非預設的變換。請對父系套用變換（Ctrl+A → All Transforms），或啟用 **Merge Same Bones**，它會幫你刪除乾淨的父系。

## 限制 {#limitations}

- 骨架模式至少需要 2 個骨架；網格模式至少需要 1 個骨架與 1 個網格。
- 非常複雜的合併會花時間；部分自訂約束可能需要手動修正。

> ⚠ **合併前務必備份你的模型。** 結果會因模型複雜度而異。
